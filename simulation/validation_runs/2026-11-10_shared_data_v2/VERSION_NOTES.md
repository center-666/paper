# 纠正消融的来源与边界

本轮由独立代码复查触发：初版共享尺度消融的两种 q 没有使用完全同一批正常残差。修正后均从冻结 interval_scale 策略生成的同一正常标定轨迹计算，空间统计、时间中心/协方差、回退字段、样本数量与裁剪阈值逐元素一致。

只比较 interval_scale（共享数据合并尾部）与 tail_shared_scale（共享数据分组尾部）。各自权重灵敏度仍允许用正常验证集以相同预算拟合，测试集不参与。完整开发参考来自前一批已冻结策略，因此比较条件于该标定资产，不能声称覆盖标定不确定性。

新测试种子240000–240127，未使用前一批140000–140127或首轮40000–40031的测试轨迹。模型、通信压力、攻击定义、幅值、窗口和1%主要门槛未变。原结果已见这一事实写入plan.json修订记录，没有冒称整个纠正过程在研究前预注册。

当前主要门槛未通过。不会把小差异或个别探索性区间用作选题成立的依据。
