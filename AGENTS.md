# Repository Workflow

## GitHub Publishing

The user explicitly requests that completed results in this repository be uploaded to GitHub. After verifying a task result, commit and push the task-scoped files to the current branch on `origin` by default.

Stage only files created or changed for the current task. Preserve unrelated modified and untracked files; do not include them in the commit unless they are part of the requested result. Do not submit manuscripts to journals or publish to other services unless separately requested.
