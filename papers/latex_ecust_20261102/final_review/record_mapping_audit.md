# 定理 3.2 下界：完整日志映射、攻击信息与预算的独立复核

复核日期：2026-10-20。对象为 `latex_clarity_20261020` 中的 `theory.tex`、`main_joint_kernel.tex`、`vector_proof.tex`。本报告从模型重新推导所需条件分布和日志映射，不以既有审计结论为依据；未改动稿件，未开展新增仿真。

## 1. 结论与复核范围

在稿件明确给出的模型和日志定义下，未发现足以否定定理 3.2 匹配下界的数学错误。

具体检查包括：

1. 允许攻击依赖真实已发送测量和独立私有种子时，扩充信息集下的条件高斯结构仍然成立。
2. 两拍补偿构造满足因果权限和逐路径峰值约束。
3. 给定完整连续前史后，稿件联合核确实是当前发送分支的实际次概率分布。
4. 当前载荷、下一预测反馈和下一载荷可由同一个不依赖有符号幅值、私有符号及混合标签的映射恢复。
5. 当前静默分支与无攻击分支一致，完整连续前史可按同一基准分布积分。
6. 变差范数转成概率 TV 的 `1/2` 因子使用正确；最终常数为 `Σ_h w_h B_h/4`。
7. 初始私有混合同时线性缩放日志分布差和目标损伤，覆盖全部 `0 < b ≤ b_ref`、`0 ≤ ε ≤ 1`，包括零预算端点。

该结论是针对上述证明链的数学审读，并非定理的机器形式化验证，也不代表已核完全文全部反例、数值附件或文献创新性。

## 2. 扩充信息集下的条件高斯结构

稿件定义

\[
\mathcal G_t^-=\sigma(S,\gamma_{0:t-1},Y_{0:t-1}^{\rm true}),\qquad
\mathcal G_t^+=\mathcal G_t^-\vee\sigma(\gamma_t,Y_t^{\rm true}).
\]

关键是：给定策略及 \(\mathcal G_t^-\)，此前动作、收到的载荷和实际预测 \(m_t^-\) 都可递归重建，因此 \(m_t^-\) 是已知量。当前动作可以依赖当前真实已发送测量；它没有在触发之前改变当前物理测量或当前发送事件。

假定预测条件分布为 \(N(\mu_t^-,P_t^-)\)：

- 发送且给定真实测量 \(y_t\) 后，事件似然 \(1-g(y_t-m_t^-)\) 对状态 \(x_t\) 是常数，归一化后消去。后验等于通常的高斯测量更新。
- 静默时没有额外观察到 \(y_t\)。对测量噪声积分，似然正比于以 \(m_t^-\) 为中心、协方差 \(R+Z^{-1}\) 的高斯核，因此高斯先验与该似然相乘后仍为高斯。
- 独立高斯过程噪声完成下一步预测。独立私有种子 \(S\) 不改变初始高斯分布。

所以条件高斯归纳成立；条件协方差仍只由事件历史确定。条件分布及相关等式按正则条件概率通常意义在几乎处处成立，零概率观察值不影响结论。此处没有将“给定接收日志的状态分布”误认为高斯：证明所用的是包含真实已发送测量及攻击种子的扩充信息集。

由可测性，\(D_t=\mu_t^+-m_t^+\) 对 \(\mathcal G_t^+\) 可测，且 \(x_t-\mu_t^+\) 条件均值为零，故交叉项消失。MSE 分解可用于当前下界构造。

## 3. 从实际物理过程重新得到两拍联合核

用 \(\omega\) 表示攻击前完整日志 \(H_{k-1}\)，\(h=h(\omega)\) 为其中的事件前缀，令

\[
m=m_k^-(\omega),\quad K=K_h,\quad
S_h=P_k^-(h)+R,\quad u_h=AK_hv.
\]

当 \(k=0\) 时，\(\omega\) 为空且 \(m=m_0\)。在目标时刻之前，候选攻击和零动作策略完全一致；完整前史的分布相同，私有符号及初始混合标签与前史独立。

### 3.1 当前发送分支

真实创新 \(u=y_k-m\) 在给定 \(\omega\) 后服从 \(N(0,S_h)\)。计入发送事件后的未归一化密度为

\[
f_h(u)=\phi_{S_h}(u)[1-g(u)],\qquad \int f_h=p_h.
\]

这里不能把 \(f_h\) 当成积分为 1 的条件密度；当前稿始终将相应分支作为质量为 \(p_h\) 的次概率测度，处理正确。

给定当前真实发送测量，真实后验均值为 \(m+K_hu\)，故下一时刻真实条件均值为

\[
\mu_{k+1}^-=A(m+K_hu).
\]

令有符号幅值为 \(t\)。实际当前接收创新和实际下一预测为

\[
z=u+tv,\qquad
m_{k+1}^-=A(m+K_hz)
=A(m+K_hu)+tu_h.
\]

因此下一预测偏差确为 \(d=-tu_h\)，符号一致。

### 3.2 下一时刻的真实创新

令

\[
e=y_{k+1}-A(m+K_hu).
\]

给定 \((\omega,u,\gamma_k=1)\)，高斯更新及独立过程、测量噪声给出

\[
e\sim N(0,S'_h),\qquad
S'_h=AF_1(P_k^-(h))A^\top+Q+R.
\]

该条件分布不依赖 \(u\)；所以在固定前史并限制到当前发送分支后，\(e\) 与 \(u\) 条件独立。虽然 \(e\) 的定义减去了依赖 \(u\) 的条件均值，这正是高斯条件创新，不会留下遗漏的交叉项。对 \(e\) 条件分布的论证也不依赖私有符号。

下一触发器所用创新为

\[
y_{k+1}-m_{k+1}^-=e-tu_h.
\]

下一发送时实施补偿 \(a_{k+1}=tu_h\)，收到的创新因此为

\[
\widetilde y_{k+1}-m_{k+1}^-=e-tu_h+tu_h=e.
\]

所以静默原子与发送连续部分分别为

\[
\mathcal K_{h,-tu_h}(\{\bot\})
=\int\phi_{S'_h}(e)g(e-tu_h)\,de,
\]

\[
\mathcal K_{h,-tu_h}(de)
=\phi_{S'_h}(e)[1-g(e-tu_h)]\,de.
\]

结合 \(z=u+tv\)，得到实际联合核

\[
F_h(t)(dz,d\xi)=f_h(z-tv)\,dz\,
\mathcal K_{h,-tu_h}(d\xi).
\]

这不是将两个无条件边缘分布错误相乘：在固定 \(t,\omega\) 后，当前真实创新与下一真实条件创新具有上述条件独立性。私有正负符号随后应当在整个乘积核上混合，当前稿正是这样处理的。

## 4. 同一个映射完整恢复日志

对固定前史 \(\omega\)，定义映射 \(\Psi_\omega(z,\xi)\)，保留 \(\omega\) 的全部字段，并附加以下两拍记录：

| 字段 | 映射所恢复的值 |
| --- | --- |
| 当前实际预测反馈 | \(m=m_k^-(\omega)\) |
| 当前事件 | \(\gamma_k=1\) |
| 当前接收载荷 | \(\widetilde y_k=m+z\) |
| 下一实际预测反馈 | \(m_{k+1}^-=A(m+K_hz)\) |
| 下一事件 | \(\gamma_{k+1}=\mathbf1\{\xi\ne\bot\}\) |
| 下一接收载荷 | 若 \(\xi\ne\bot\)，为 \(A(m+K_hz)+\xi\)；否则为 \(\bot\) |

映射还可由接收递推恢复后验估计、协方差标签和由这些字段决定的下一预测；这些派生字段不会带来额外依赖。稿件的 \(H_{k+1}\) 只收集截至 \(k+1\) 的事件、实际预测反馈和接收载荷，上表已经完整覆盖。

重要区别是：\(\Psi_\omega\) **可以依赖连续前史 \(\omega\)**；它需要不依赖的是有符号幅值 \(t\)、私有正负符号、选择攻击还是零动作的私有标签。上述公式满足这一要求。若把连续前史先丢弃，只给定离散 \(h\)，就不能直接恢复实际载荷的平移中心；稿件采用先给定完整前史、再积分的做法，避免了这个问题。

当前静默分支的两拍动作都为零。当前事件发生前没有攻击，且此分支下一时刻也不攻击，故该分支的完整两拍日志分布与无攻击运行一致，应作为公共次概率测度加到两边，差值为零。

设 \(\nu_0(d\omega)\) 为共同前史分布，\(Q_h^\eta=[F_h(\eta)+F_h(-\eta)]/2\)，则可将完整日志的差测度显式写成

\[
\mathsf P_\pm-\mathsf P_0
=\int (\Psi_\omega)_\#
\bigl(Q_{h(\omega)}^\eta-F_{h(\omega)}(0)\bigr)\,
\nu_0(d\omega).
\]

这条恒等式同时保留了连续前史、两拍载荷和预测反馈，是稿件从联合核到完整日志的关键步骤。

## 5. 二阶核界、变差系数与前史积分

共同支配测度是

\[
dz\otimes(\delta_\bot+d\xi).
\]

在该测度下，静默部分和连续部分都是关于 \(t\) 的可微密度。下一核的方向导数由常数倍 \(\phi_{S'_h}\) 支配；当前密度的平移则在 \(L^1\) 中二阶连续可微，因为 \(f_h\) 为两个高斯密度的线性组合，其前两阶方向导数可积。

乘积二阶导数包含

\[
f_h''\mathcal K+2f_h'\mathcal K'
+f_h\mathcal K''.
\]

由于 \(\|\mathcal K\|_{\rm var}=1\)、\(\|f_h\|_1=p_h\)，其范数上界正是

\[
B_h=F_{2,h}+2F_{1,h}l_1(u_h)+p_hl_2(u_h).
\]

本次重算未发现交叉项系数遗漏。界对所有实数 \(t\) 成立，而不仅是 \(t\to0\) 的局部界；常数可依赖模型、维数、时刻和方向，但不依赖变化的 \(b,\varepsilon\)。这不应被理解为对所有模型参数、维数或无限时域一致。

中心 Taylor 式给出

\[
\|Q_h^\eta-F_h(0)\|_{\rm var}
\le\frac12 B_h\eta^2.
\]

这里 \(Q_h^\eta\) 与 \(F_h(0)\) 质量均为 \(p_h\)，因此差测度总质量为零。零总质量有限符号测度满足“集合上的最大绝对质量 = 变差范数的一半”，不要求两边本身都是质量为 1 的概率测度。

固定映射不增加变差范数，对共同前史积分并用 \(h(\omega)\) 的分布 \(w_h\) 聚合，得到

\[
\begin{aligned}
\Delta_{\rm full}
&=\frac12\|\mathsf P_\pm-\mathsf P_0\|_{\rm var}\\
&\le\frac12\int
\|Q_{h(\omega)}^\eta-F_{h(\omega)}(0)\|_{\rm var}\,
\nu_0(d\omega)\\
&\le\frac14\eta^2\sum_h w_hB_h.
\end{aligned}
\]

因此 \(C_\pm=\frac14\sum_h w_hB_h\) 的系数正确。连续前史不需要被枚举；其条件核界只依赖有限事件前缀，允许最后归并为有限和。

## 6. 合法攻击、目标损伤与全部预算范围

令

\[
\kappa=\bigl[\max\{1,\max_h\|AK_hv\|_2\}\bigr]^{-1},
\qquad \eta=\kappa b.
\]

两拍动作是当前发送时的 \(\sigma\eta v\)，以及当前、下一拍均发送时的 \(\sigma\eta AK_hv\)。每个分支上分别满足

\[
\|\sigma\eta v\|_2\le b,\qquad
\|\sigma\eta AK_hv\|_2\le b.
\]

所用信息只有事件前缀、当前是否发送、私有符号和已知模型。未来是否发送仅决定届时是否执行已定义动作，并未被提前读取，因果性成立。

目标之前不攻击，目标事件在修改载荷前形成，故目标协方差及其概率分布与无攻击运行相同。当前发送时 \(D_k=-\sigma\eta K_hv\)，静默时 \(D_k=0\)，因此

\[
J_k=L_v\eta^2,\qquad
L_v=\sum_h w_hp_h\|K_hv\|_2^2>0.
\]

\(P_k^-(h)\succ0\)、\(R\succ0\) 保证 \(K_h\) 可逆，故非零单位方向给出严格正的损伤常数。\(k=0\) 时只剩空前缀，论证仍成立。

最后在初始时刻，以与物理过程及触发随机数独立的私有概率

\[
\lambda=\min\left\{1,\frac{\varepsilon}{C_\pm\kappa^2b^2}\right\}
\]

选取上述两拍策略，否则始终零动作。于是实际运行分布严格为两种运行分布的混合：

\[
\mathsf P_\lambda-\mathsf P_0
=\lambda(\mathsf P_\pm-\mathsf P_0),\qquad
J_k(\pi_\lambda)=\lambda J_k(\pi_\pm).
\]

从而

\[
\Delta_{\rm full}(\pi_\lambda)\le\varepsilon,\qquad
J_k(\pi_\lambda)
=L_v\min\{\kappa^2b^2,\varepsilon/C_\pm\}.
\]

- \(\varepsilon=0\) 时 \(\lambda=0\)，得到合法零动作策略，没有除零问题，因为 \(b>0,C_\pm>0,\kappa>0\)。
- \(\varepsilon\ge C_\pm\kappa^2b^2\) 时直接采用两拍策略。
- 其他情形由混合满足预算，逐路径峰值约束不因混合而改变。
- 以上下界并不需要“小幅值 Taylor 余项”假设，因为导数界对全体 \(t\) 有效。主定理的预设有限峰值范围主要用于上界中函数 \(1-e^{-h_*x}\) 在有限区间上的割线下界。

由
\[
\min\{\kappa^2b^2,\varepsilon/C_\pm\}
\ge \min\{\kappa^2,C_\pm^{-1}\}\min\{b^2,\varepsilon\},
\]
得正文给出的下界常数。三类记录的下界同时成立，因为这一个攻击已经满足最强的完整日志 TV 约束。
