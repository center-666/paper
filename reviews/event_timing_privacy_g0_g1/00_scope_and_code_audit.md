# G0/G1 审查范围与SoD代码事实

基线：仓库 center-666/paper，提交 490e5b8f1212004407a0cdbfde224bf90a691da4，独立分支 event-timing-privacy-g0-g1。不读取基线外主工作树改动，不改估计器/引擎/配置，不运行正式轨迹或G2实验。

## 研究对象

本轮只审核：Yang形式分布式估计网络中，一条入站估计通信链路受主动注入后，是否可通过改变目标节点未来公开SoD发送事件，增加观察者对目标私有本地量测信息的推断；并检查“触发仅依可信本地参考时，入站攻击不能改变目标发送事件”的路径不变性质。

不审核或声称解决普遍时序侧信道、全局差分隐私、最优攻击、最优隐私调度或估计MSE效益。

## FACT：引擎里的触发语义

基线 simulation/engine.py 第21–22、30–38、58–78、173–174行；配置 simulation/config.json 第3–15、30–33行：

- schedule参数省略或None时，系统逐节点启用SoD。比较量是本拍循环开始时 hat=estimates[:,t] 与发送端上次发送时的 last_send_value，不是本地量测更新后的值。
- 判据为 sum((hat-last_send_value)^2,axis=-1) > send_delta_squared，严格大于；配置阈值平方为0.12。
- 同时有timeout：(t-last_send_time)>=max_interval，配置最长间隔10。发送条件是crossed OR timeout。t=0强制发送。
- 发送发生时，last_send_value与last_send_time立即更新至本次发送参考/时间。
- 发送是节点级事件 sends[s,t]，并映射到该节点全部出链路：每条edge以 fresh=transmit[:,src] 判断是否有新包。
- 入站新包仅在发送节点真实发送时才fresh。未发送边由接收端沿用缓存payload并做A^age外推。
- 目标入站包攻击在触发发送决定之后、接收端缓存和一致性估计更新之前施加。它不改变本拍发送方触发判定或last-send-reference。攻击最早影响接收节点下一个状态索引的estimate；这之后可经Yang网络递推影响受害节点的后续发送判据。
- max_interval是强制定时发送，若研究阈值事件必须剔除/单独建模。外生schedule若传入，会覆盖SoD；本轮讨论真实SoD语义，但不执行网络pilot。
- 引擎没有通信传输延迟/乱序机制。普通step路径也不是窃听者修改包后观察受害事件的攻防复现实验，而是模拟器在真实发送机会替换接收payload。

FACT：目标边0→1的发送节点0发送决策是节点级；若外部观察者能监测节点1任一出链路，可能看到节点1广播事件。具体公开哪些边/广播标记须在后续模型冻结中声明；本轮不假定读取发送者隐藏状态或私有量测。

## DERIVED：本任务时序对齐

第k拍，节点1发送判定已经完成。0→1包若在本拍被改，节点1估计在k+1更新中首次加入 epsilon A a_k。因此它改变的最早是k+1及以后按“当前估计相对上次发送估计”的下一次阈值判断。若节点1在k+1强制timeout发送，该事件是timeout，不能解释成攻击诱导的SoD阈值穿越。

附件所写 gamma_1(k+1)=1{||z_(k+1)+epsilon A a_k||²>d} 只在以下局部条件下成立：固定既往状态/发送锚点；该拍只有这一入站增量；节点1攻击前估计差记为z；没有其他同拍入站改变；并排除timeout。它是条件化的一拍阈值模型，不是引擎完整事件递推。
