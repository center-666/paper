# 最小历史修正筛选：配置、结果与限制

## 试验登记

**重要口径修正：**本报告首版将 q 时刻的下一包称为“健康包/干净包”，该说法不严谨。准确表述是“该次新发送载荷未经攻击者篡改”。双向拓扑中，发送者状态估计可能已由此前被攻击的反向链路污染，因此新载荷不必等于健康反事实；闭环传播审计已单独量化此效应。

Run ID：`g1r_minimal_screen_20261112_02`。原型代码为 `code/minimal_recovery_screen.py`；同seed首次运行 `..._01` 保留在结果目录。Run 01 的全网 oracle 汇总行误引用了 candidate 的接收节点数组；Run 02 修复该报告索引后用相同配置/seed 重跑，**不是独立复现**，不合并样本。完整配置、逐seed CSV、包审计、运行时源哈希和重算摘要保存在 [results/g1r_minimal_screen_20261112_02](results/g1r_minimal_screen_20261112_02)。

仿真使用现有五节点 Yang-form 双向环、单条边 (0\to1)、异质局部观测模型；(A=[[1,0.1],[0,1.01]], Q=0.02I, P_0=I, R_i=0.05I, \epsilon=0.08)，状态维数2，(T=280)。发送为外生 gap8，节点相位步长1；所有基线共用同一个发送时刻和状态/过程/量测噪声seed。训练64、正常校准48、测试48个独立seed，配对单位是seed。该规模只筛机制，不验证1%效应或期刊级统计保证。

两种攻击都只替换 (r=200) 的一枚真实发送包：

- 突变 FDI：载荷加 ([1.2,-0.8]^T)。
- Replay：选发送者0实际发送历史中第8个先前包；gap8 下内容年龄64步，48/48条测试轨迹都只有1次替换。该载荷在 (q=208) 被下一次未篡改传输替换，但发送者估计可能已由反向边受污染。

迟到修正时刻取 (d=216>q)，最初候选 GLS 只看 (209{:}216) 的本地创新。该窗口内目标缓存载荷已被下一次未篡改发送替换；它不保证发送者估计是健康反事实。筛选已知一个边/时刻单事件。

## 比较方法及公平口径

1. 健康 Yang-form 和受攻无保护 Yang-form，使用同一外生日程。
2. d 后硬隔离该边。q 时目标边已接收到未经再次篡改的新传输，但该 sender estimate 可能间接受污染；d 时再隔离会丢弃这份后续估计输入，却不回滚 r 到 q 期间已进入网络的状态影响。
3. 固定滞后 receiver-only drop-and-replay：从 (r) 前接收节点滤波状态及缓存快照重算；删除 (r) 的受疑包但保留其旧缓存，再用接收端实际保存的其他入边包、局部量测和固定模式前推。它不需要原始合法当前载荷，但会丢弃受疑包所含的健康信息；只报告接收节点，不宣称它已修复全网。
4. 从 (r) 前节点估计继续运行的本地测量滤波器，作为现成恢复/本地估计基线。项目旧基准也显示仅切成本地滤波会损失协同收益：旧报告 [pilot_20261004_01](../../第二篇小论文/第二篇小论文/韧性恢复/results/pilot_20261004_01/实验报告.md) 中，50种子下本地重置在四个场景的恢复期累计误差均高于原始切换；该旧模型不同，作为工程负证据而非同模型结论。
5. 候选后续创新 GLS：训练正常创新完整协方差，单包单位扰动响应得到 (J)，在 (d) 由 (\hat a=(J^T\Sigma^{-1}J)^{-1}J^T\Sigma^{-1}(z-\mu)) 估事件等效偏差，再修正 receiver 当前及后续状态影响；95%正常校准集设置 likelihood-improvement gate。它不读真值或攻击真实幅值，但**已知攻击边与事件时刻**，并假定固定发送模式和正确的正常联合协方差。
6. 理想原包/攻击影响 oracle：用仿真实际偏差完全减去全网灵敏度，仅为可达性能上限。不得将其当成算法。

### 探索结果

恢复窗为 (d+1{:}260)，指标为每状态/节点/时间平方误差均值，相对同seed健康 Yang 的 excess。接收端恢复 excess 的48 seed均值如下：

| 场景/方法 | 接收端恢复 excess MSE | 全网恢复 excess MSE | 说明 |
|---|---:|---:|---|
| 单次FDI，无保护 | 0.000719 | 0.000485 | 单步误差很小；该设置里攻击损失较弱 |
| 单次FDI，迟到后隔离 | 0.014957 | 0.002625 | q 后目标载荷未经再次篡改；该 sender estimate 可能已受反向边污染，迟到隔离又丢掉当期信息 |
| 单次FDI，固定滞后删包重算 | 0.000154 | 未计算 | 接收端，只丢事件包，不恢复其健康信息 |
| 单次FDI，后续GLS receiver | 0.001485 | 0.000470* | 反而比不处理的接收端 excess 更高；*全网值需修正广播 |
| Replay，无保护 | 0.816381 | 0.244695 | 一枚64步陈旧包造成明显残余损失 |
| Replay，迟到后隔离 | 1.158405 | 0.314621 | 丢弃未再次篡改、但估计可能间接受污染的新包；仍不回滚既有状态误差 |
| Replay，固定滞后删包重算 | 0.146311 | 未计算 | receiver-only；不使用原合法包 |
| Replay，本地滤波器重启 | 0.062821 | 未计算 | 牺牲邻居协同信息的基线 |
| Replay，后续GLS receiver | 0.010072 | 0.002813* | *全网结果额外依赖修正广播，当前未实现/未计费 |
| 两种攻击，已知影响 oracle 全网 | 约0 | 约0 | 只作性能上限 |

后续创新设计矩阵在固定模式下满秩，奇异值为0.0861和0.0455；跨另一个训练seed的单位输入响应最大线性误差 (1.5\times10^{-14})，说明数值传播代码符合固定模式线性恒等式。候选的正常校准误修正率为2/48（4.17%），正常测试为1/48（2.08%）；后者正常receiver MSE变化均值 (+0.000763)，配对95%描述区间 ([-0.000772,0.002297])。Replay的GLS gate触发38/48（79.17%）；单步FDI仅1/48（2.08%）。这些检测率是筛选观察，不是经过完整事件扫描校准的安全保证。

候选 post-cache GLS receiver recovery excess 相对无保护配对差为 \(-0.8063\)，48 seed t 区间 \([-1.1226,-0.4900]\)；相对 receiver-only fixed-lag drop-and-replay 的配对差为 \(-0.1362\)，区间 \([-0.1968,-0.0757]\)。全网带广播版本相对无保护差为 \(-0.2419\)，区间 \([-0.3369,-0.1468]\)。这些描述区间未作多重比较校正，且所有方法均使用 oracle 已知事件边/时刻；不能证明新颖性。

随后新增 Run ID g1r_attack_input_tracker_20261112_02，对同一48个seed比较两个估计器：完整 \(r{:}d\) 残差的因果白化递推攻击输入跟踪，与只使用 \(q+1{:}d\) 的 post-cache GLS。两者使用相同的已知事件边/时刻、模型灵敏度和独立正常联合协方差校准；该递推器是标准序贯 GLS/未知输入跟踪结构，**不是 Deghat 2019 H∞/LMI 论文的完整适配或复现**。递推终值与完整窗口 batch GLS 最大差 \(2.84\times10^{-14}\)。

Replay 下，完整窗口递推跟踪的 receiver/network recovery excess 分别为 \(-0.00328/-0.00129\)，post-cache GLS 为 \(0.01007/0.00281\)；完整窗口递推跟踪减 post-cache GLS 的配对差分别为 \(-0.01335\)（95%区间 \([-0.02387,-0.00283]\)）和 \(-0.00411\)（\([-0.00792,-0.00029]\)）。突变 FDI 下 full-prefix 跟踪也把接收节点 excess 从 \(0.000719\) 改为 \(-0.00250\)，但正常测试误修正率为6.25%；post-cache GLS 正常误修正率为2.08%。这些结果说明更长历史和标准序贯估计足以解释 post-cache GLS 收益，不能当作 Deghat 方法优势，因为事件位置仍已知、日程固定且测试规模小。

每seed共有179次广播、358个有向边包、5,728载荷字节；所有估计基线共享。候选对全网修正还需至少一次事件/边/时刻及二维等效影响量广播，协议头、路由和认证成本尚未实现或计入。receiver-only版本不收费广播，但不修正其他节点。

**运行与存储口径。** Run 02 整套最小仿真在记录环境下耗时约0.97 s；没有逐算法 profiling，不能将这个时间写成单次在线延迟。实现结构估算：固定滞后 receiver replay 保存 (r{:}d) 的17个二维本地量测约272 B、两条入边在该段的5个二维包约80 B、checkpoint 状态/缓存约48 B，另有时刻/索引；合计约420 B原始数值，未计序列化头。GLS batch 方式另存8个二维后缓存创新128 B；递推信息式可用 (2\times2) 信息矩阵与二维得分约48 B，加当前传播灵敏度（receiver-only约32 B，全网约160 B）。其 (16\times16) 正常协方差和 (16\times2) 灵敏度矩阵可按模型/日程离线共享，约2.3 KB，不必每事件重复存储。以上是数组形状估算，不是实测 RAM/FLOPs；全网修正广播也未实测/计费。

**新增闭环传播与强基线结论：**“直接替换输入结束”仅指攻击者不再改目标边当前载荷，不代表 sender estimate 回到健康反事实。双向环里该发送者可已受反向边影响。新增完整残差窗递推攻击输入估计在该已知事件筛选下比post-cache GLS更强，进一步削弱该GLS写法的独立方法价值。

### 新增映射审计和 Deghat 风格输出对照

有效的独立传播审计为 Run ID g1r_deghat_mapping_audit_20261112_04：递推器仅在事件 r 注入攻击载荷差，之后每一未篡改发送都使用递推器预测的 sender estimate 差，再逐拍与完整攻击/健康仿真对照。仿真器在 age=0 的发送迭代 r 即消费包，直接项进入状态索引 r+1；age=0 不是“无影响”。全网络差分递推最大误差为 \(7.9\times10^{-14}\)。q 后停止的是攻击者直接替换目标载荷；新 sender estimate 可能已因双向反馈带有污染。Run 01/02 的公式核验将两边用同一表达式构造，是循环核验；Run 03 虽递推估计差，但把实际攻击/健康sender差回灌，不能称独立预测。三个失败/诊断运行都保留，04是有效验证。

另做 Run ID g1r_deghat_output_channels_20261112_02，比较接收节点本地创新与 Deghat 文献中本地创新加邻居分歧两类输出。Run 01 因窗口名未触发分歧特征分支，实际上两组均只用了本地创新，保留为失败运行，不作证据。修正 Run 02 下，Replay 完整窗口“本地创新+邻居分歧”的 receiver/network recovery excess 为 \(-0.000636/-0.000314\)，仅本地创新为 \(-0.003048/-0.001216\)；post-cache augmented 为 \(0.004258/0.000268\)。正常误修正率约4.17%（完整窗两组相同）。配对 seed 差分析中，Replay 完整窗 augmented 减 local 的 receiver excess 均值为 \(+0.00241\)、95%区间 \([-0.00319,0.00802]\)；network excess 差 \(+0.00090\)、区间 \([-0.00097,0.00277]\)，均未显示邻居分歧输出有稳定 MSE 增益。其 offset 参数估计误差均值从 local 的2.812降到augmented的0.840，但这并未转化成可识别的 MSE 改善。该比较仍为已知事件位置下的标准 GLS/输出选择，不是 Deghat H-infinity tracker 复现；特征维数从34增至68，额外修正广播仍未计费。

## 解释边界与失败结果

- **攻击可达性：** Replay 源时刻由模拟器审计为 (s<r) 且该发送时刻在外生日程上；每seed攻击机会、替换次数均为1。候选估计没有使用 `replay_source`、真实攻击向量或真状态；source 时间仅作攻击合法性评价。
- **事件信息权限：** 灵敏度 (J,S) 用模型/触发模式计算，但试验把受疑 (e,r) 直接指定。部署方法尚不能在多个历史包中定位事件，故这是有利条件。
- **数据/模型：** 主模型每个节点本地可观且局部增益全时刻可用。单步FDI无明显影响说明该模型下局部观测足以吸收脉冲，不能据此宣称普遍。Replay 是强烈的陈旧单包；不代表全部Replay。
- **防御对照：** receiver-only fixed-lag rerun 使用接收节点已记录的局部量测与实际入包，可在当前接口下复算；其网络MSE未报。全网候选修正用公共模式下的灵敏度传播，但需要事件广播，尚未计费。oracle知道真实影响，不作为公平基线。
- **独立性：** 48个测试seed为统计单位；一个seed内的16个创新、280个时步不是独立样本。正常门限在独立校准seed上设定；不是跨模型阈值。没有大规模样本量或正式统计检验。
- **保留失败：** 突变FDI场景里GLS gate大多不触发，整体MSE没有收益；q后即使新传输未再次篡改，sender estimate 仍可能间接受污染，迟到隔离仍会丢失这份有用但不等于健康反事实的信息；固定模式精确灵敏度不能直接代表闭环 Send-on-Delta，因为攻击会改变未来发送机会。
- **运行复核：** Run 01 的派生摘要将“oracle global receiver”误关联到 candidate global 行；Run 02 保留相同seed和结果后修复索引。Run 01 不作为独立试验，也没有覆盖。

实验支持：被替换载荷的直接缓存输入结束后，双向反馈仍可令后续未再次篡改的sender estimates携带间接污染；迟到隔离不等于回滚且可能有害。标准完整窗口递推GLS和加入邻居分歧的标准输出回归均能在已知事件位置下估计影响；该结果削弱post-cache GLS的独立方法主张。Deghat网络tracker尚未忠实适配。当前没有支持独立立题的证据。
