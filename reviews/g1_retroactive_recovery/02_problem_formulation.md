# 历史估计包、信息集与污染传播模型

## 系统与通信协议

`LITERATURE/PROJECT`: 按仓库当前 Yang-form 工程模型，网络共享状态满足

\[
x_{k+1}=Ax_k+w_k,\qquad y_i(k)=H_i x_k+v_i(k),\quad i=1,\ldots,N.
\]

发送节点 (j) 在发送时刻 (s_j(k)=1) 时产生真实包 (m_j(k)=\hat x_j(k))。被攻击有向边 (e=(j,i)) 的接收包为

\[
\tilde m_{ji}(k)=m_j(k)+a_{ji}(k),
\]

其中单次 FDI 是 (a_{ji}(r)=b)；Replay 是 (\tilde m_{ji}(r)=m_j(s), s<r)，且 (s) 必须是攻击者实际截获过的真实发送时刻。攻击者不能改本地 (y_i)、触发器、未发送的估计或未来量。包未带不可伪造的新鲜度标签。

接收端维持消息缓存 (c_{ji}) 与最后接收时刻 (\tau_{ji})：

\[
c_{ji}(k)=\begin{cases}\tilde m_{ji}(k),&\text{当期收到 }j\to i;\\c_{ji}(k-1),&\text{否则},\end{cases}\qquad a^{\rm age}_{ji}(k)=k-\tau_{ji},\quad \bar m_{ji}(k)=A^{a^{\rm age}_{ji}(k)}c_{ji}(k).
\]

更新遵循仓库约定：时刻 (k) 使用 (y_i(k)) 及当前/缓存的邻居包，得到 (\hat x_i(k+1))，不额外插入独立 predict 步骤。其典型项为

\[
\hat x_i(k+1)=A\hat x_i(k)+K_{p,i}(k)[y_i(k)-H_i\hat x_i(k)]
+\varepsilon A\sum_{j\in\mathcal N_i}w_{ji}(k)[\bar m_{ji}(k)-\hat x_i(k)].
\]

事件发送时刻由 Send-on-Delta 或预先固定的外生日程确定。一个未再次篡改的新传输在 (q>r) 到达并替换该缓存后，被替换包的直接缓存输入已结束；但发送节点的估计可能已通过反向边受污染，因此“载荷未被再次篡改”不等于“后续包内容是健康反事实”。检测在 (d>q) 才发出警报，污染还可继续通过估计递推和下游节点缓存传播。

## 攻击者与接收端信息

截至 (d)，受攻击接收节点合法可用：自身历史本地量测 (y_i(0{:}d))、各邻居实际收包的载荷及本地接收时刻、公开的 (A,H_i)、已实现通信/融合模式和自己的滤波状态。若历史发送包已按协议保留，则可查到本边此前实际收到的载荷；没有另行认证的情况下，不能从内容判定某个包必为真实历史值。

节点不能读取物理真状态 (x)、邻居未发送的内部估计、恶意包被篡改前的原始当前载荷，或未来数据。候选修正可用一个受疑事件的时刻和边作为**筛选条件**，但部署方法若把该事件标签当作已知输入，就没有完成攻击定位问题。下文实验采用已知边/事件时刻来隔离“能否利用后续量测修正”的机制，明确属于 `ORACLE-LOCALIZATION CONDITION`。

**术语修正：**本文及初始筛选配置中的“干净/健康新包”应读作“该次传输未再次被攻击者篡改”。它不表示 sender estimate 等于健康反事实。双向闭环的后续 sender estimates 可能已受反向边污染，因而 \(q\) 后相对健康轨迹的缓存差通常不归零；归零的只是“攻击者仍在直接替换该缓存载荷”这一输入事件。

**实现时序和缓存口径修订：**当前代码在发送迭代 r 立即消费 age-0 包，并在计算 \(\hat x(r+1)\) 时加入共识项。因此直接扰动为 \(\Delta u_i(r)=\varepsilon A\Delta m\)，第一次变化在估计状态索引 r+1；age=0 不是乘法零。驻留后第 a 次迭代直接项是 \(\varepsilon A A^a\Delta m\)。在 q 时结束的是攻击者直接替换目标载荷；q 的传输虽未被再次篡改，sender estimate 可能已被反向边污染，故它相对健康反事实的载荷差并不必为零。不能一般性地说完整缓存状态差在 q 清零。

## 增广系统及精确影响恒等式

令网络完整增广状态

\[
z_k=\operatorname{col}(x_k,\hat x_1(k),\ldots,\hat x_N(k),c_{e_1}(k),\ldots,c_{e_E}(k)).
\]

缓存年龄和发送/接收组合属于离散模式 (\sigma_k)；在给定模式下 (A^{a^{\rm age}}) 已知。固定模式和线性更新可写为

\[
z_{k+1}=M_{\sigma_k}z_k+B_{\sigma_k}u_k+G_{\sigma_k}\omega_k.
\]

`DERIVED` 若只有时刻 (r) 一个包替换，且健康反事实和受攻轨迹具有相同的模式序列，则

\[
\delta z_{r+1}=D_{e,r}\theta_r,\qquad
\delta z_{d+1}=\Phi(d,r+1)D_{e,r}\theta_r,
\]

其中 (\theta_r) 是包扰动 (a_{ji}(r)) 或 Replay 与当前包的载荷差，
\(\Phi(d,r+1)=M_{\sigma_d}\cdots M_{\sigma_{r+1}}\)。这只是线性系统的变参数传播恒等式，**本身不构成创新**。

需要区分攻击输入与后续网络状态：在 (q) 时攻击者停止替换目标边的载荷，但下一包只是“本次传输未被再次篡改”，不一定等于健康反事实的 sender estimate。双向链路可使 sender 已受回传污染，因此增广缓存的反事实差一般仍不为零；接收节点估计差和下游缓存差也可继续传播。仅当新 sender estimate 等于健康反事实时，缓存分量差才归零。

新闭环传播审计显示，之后的未篡改包可继续携带间接污染，因此增广状态必须包含 sender estimates 及其反向边反馈，而不能只包含目标 receiver 的 cache 和 estimate。

精确恒等式要求两条轨迹使用同一 (\sigma_k)。在外生固定日程、固定节点增益和相同缓存更换模式下可精确成立；闭环 Send-on-Delta 时，受攻轨迹会改变估计值，进而改变未来发送决定、缓存寿命和接收模式。此时

\[
\delta z_{k+1}=M_{\sigma_k^a}\delta z_k+(M_{\sigma_k^a}-M_{\sigma_k^0})z_k^0+\cdots,
\]

需额外处理模式差项。把固定日程灵敏度直接外推到闭环触发结果属于 `APPROXIMATION`，除非重新逐次计算分支触发模式。

## 后续量测的统计模型

在事件边/时刻已知、攻击在 (r) 后无新增、消息模式固定且条件噪声模型正确时，可把接收端后续创新堆叠为

\[
z_{r+1:d}=\nu_{r+1:d}^{(0)}+O_{e,r:d}\theta_r,
\]

其中 (O) 由攻击到本地预测误差的灵敏度与 (H_i) 组成。\(\nu^{(0)}\) 含正常估计误差、过程噪声与本地测量噪声。**不能**把它自动视为独立同分布高斯：各行共享同一缓存估计误差并受滤波反馈相关。原型使用独立正常轨迹的完整 8 个创新向量经验协方差，属经验模型，不是定理。

若事件时刻、边、攻击持续模式未知，应堆叠候选事件矩阵 (O_{e,r}) 并做联合选择/多模型推断；简单对每个时刻重复 GLS 后挑最大值会产生选择偏差，阈值必须对整个候选扫描校准。该多事件算法本轮没有实现。

```text
发送端 j                          攻击链路 e=j->i                       接收端 i
  xhat_j(r) --[仅实际发送 s_j(r)=1]--> 当前原包 m_j(r) --+                |
                                                         | 攻击者只可在此后替换
  过去已发送/截获 m_j(s), s<r --------------------------+--> tilde_m_ji(r)
                                                              |
  y_i(r), xhat_i(r) ------------------------------------------+--> 更新 xhat_i(r+1)
                                                                   cache c_e=tilde_m(r)
  后续本地 y_i(r+1:q-1) --------------------------------------------> cache外推/融合
  未再次篡改的新传输 m_j^a(q), q>r -------------------------------> c_e <- m_j^a(q); 直接替换载荷结束
                                                                    | 发送者估计仍可能间接受污染
  后续本地 y_i(q:d) ------------------------------------------------> 产生迟到证据
                                                                    d>q: 检测并尝试修正
```

## 原型中的时间口径

**勘误：**下面原型参数句中的“健康包下一次”和“缓存干净之后”是指下一次传输载荷未被再次篡改、直接替换载荷已经离开目标缓存；它不是健康反事实的发送者估计，也不表示双向网络的估计状态已恢复。精确发送与融合索引见上文时序修订。

G1-R 最小筛选采用外生 gap8 日程：r=200 是边0到1的真实发送机会；发送者0下一次未经再次篡改的传输在 q=208 替换目标缓存，但该 sender estimate 可能已受反向边污染。迟到修正时刻 d=216，候选 GLS 使用209到216的本地创新；该窗口位于目标载荷被替换之后，但不表示全网估计已回到健康轨迹。FDI替换一次，偏置[1.2,-0.8]；Replay替换一次，来源为实际发送历史第8个先前包，内容年龄64步。候选估计不使用未来数据、未发送内部估计或攻击真值；仿真真值只用于离线评价。
