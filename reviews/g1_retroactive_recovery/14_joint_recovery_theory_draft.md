# 联合回写的数学陈述草稿：固定日程、单次Replay

状态：**条件性推导；非新颖性证明、非投稿定稿**。本文件整理冻结任务要求的三个结果，不重算或重复验证既有传播矩阵。传播矩阵的构造及全时域验证见 [P0报告](07_full_horizon_propagation_audit.md) 和对应结果 `g1r_p0_verified_20261113_v1`。这里单独写清时间索引、信息条件、真实误差交叉项与影子对照的关系。

## 1. 模型及信息

考虑 `x_(k+1)=A x_k+w_k`、`y_i(k)=H_i x_k+v_i(k)`；五个节点使用项目中的Yang-form名义增益及固定、外生、所有方法一致的发送日程。第k拍先使用当前节点估计和发送日程替换各接收缓存，再以实际缓存的 `A^age` 外推值、本地 `y_i(k)` 与名义增益计算 `hat{x}_i(k+1)`。零年龄的新包在当拍生效。

记 `z_k=col(hat{x}_1(k),…,hat{x}_N(k), c_1(k−1),…,c_E(k−1))`，其中 `c_e(k−1)` 是第k拍接收更新**之前**的原始缓存载荷；因此 `z_(k+1)` 同时包含第k拍生成的各节点估计及接收更新后的 `c_e(k)`。缓存接收时间/年龄由固定外生日程确定，不需要作为随机攻击输入，也不能从未经发送的邻居状态推断。

健康过程与攻击过程使用同一初始状态、同一本地量测序列、同一固定日程和同一增益。单次Replay只在真实发送的边 `e*` 和时刻 `r` 替换载荷；其攻击载荷差 `a` 可随机、可依赖已截获历史包，但部署算法不能读取 `a`、真状态、真实攻击标签、历史来源或未发送的发送端内部状态。单次Replay前不存在更早攻击；若先前已经发生攻击或额外修改包，需另外写出对应多输入模型。

对固定调度和增益，既有P0给出确定性线性递推矩阵 `F_k`、单次载荷差输入矩阵 `B_(r,e*)`，以及 `T_(k;r,e*)`，使得 `T_r=0`，`T_(r+1)=B_(r,e*)`，`T_(k+1)=F_k T_k`（`k≥r+1`）。`T_k` 同时包含估计状态与原始缓存的响应，不假设后续合法发送包等于健康轨迹的包。

设接收端在完成第d拍量测和缓存处理后作出决策，`r≤d`。它由自身合法信息和事件假设产生 `hat{a}`；无报警时取零。目标要求事件链路及起点由检测和接收记录获得，但**当前调试只使用预先指定的 `e*=0→1,r=200`，尚不满足未知事件定位要求**。以下正确归责结论仅条件于事件假设与真实事件一致，不把r或攻击标签作为部署算法已知信息。

## 2. 结果一：单次Replay的污染传播

**DERIVED / CONDITIONAL；继承P0线性传播结果。** 对任意有限时刻、任意满足上述单次攻击模型的载荷差 `a`，逐样本有

```math
z_k^a-z_k^0=T_(k;r,e*) a.
```

其中上标0代表健康轨迹，a代表受攻击轨迹。这个结果对Replay载荷差是否高斯、是否与系统噪声相关没有独立性要求；它要求两条轨迹的输入量测、发送日程及线性增益相同。缓存替换是 `F_k` 的一部分，后续新包即便不再被攻击者篡改，也可能携带已传播的估计偏差。确定性日程不能替换成闭环Send-on-Delta而不重新分析。

## 3. 结果二：理想联合回写

**DERIVED / CONDITIONAL。** 假设目标事件归责正确，且在第d拍计算和接收更新结束后、下一拍开始前，对完整增广状态可靠且同步地执行

```math
z_(d+1)^rec = z_(d+1)^a - T_(d+1;r,e*) hat{a}.
```

若 `hat{a}=a`，则 `z_(d+1)^rec=z_(d+1)^0`，以后若输入量测、固定通信日程和增益保持相同且没有再次攻击，对全部 `k≥d+1` 有 `z_k^rec=z_k^0`。

**证明。** 由结果一，`z_(d+1)^a=z_(d+1)^0+T_(d+1) a`，代入回写式即可得到当前相等。此后健康与恢复过程从同一增广状态出发，接受同一输入及同一线性更新，归纳得到所有后续时刻相等。此处 `hat{a}=a` 是理想假设；仿真oracle使用真实a仅作参考，不是部署输入。可靠同步向各节点传递修正参数需要额外协议，[资源核查](12_joint_recovery_resource_audit.md)没有证明该协议已实现。

## 4. 结果三：不准确归责与不准确载荷估计

**DERIVED / CONDITIONAL。** 正确归责时，令 `q=a-hat{a}`，则对所有 `k≥d+1`，

```math
z_k^rec-z_k^0=T_(k;r,e*) q.
```

设 `P_i` 选出增广状态中的第i个节点估计，定义 `e_i^0(k)=x_k-P_i z_k^0`，`u_i(k)=P_i T_k q`。只要相关二阶矩有限，真实均方误差精确满足

```math
J_i^rec(k)-J_i^0(k)
 = E||u_i(k)||² - 2 E[(e_i^0(k))^T u_i(k)].
```

无需假定 `q` 与正常误差独立，且正常误差、Replay差和GLS估计通常相关。由Minkowski与算子范数，可以得到有限时刻保守界

```math
sqrt(J_i^rec(k)) ≤ sqrt(J_i^0(k))
                 + ||P_i T_k||_2 sqrt(E||a-hat{a}||²).
```

因此，只有在能够另行界定 `E||a-hat{a}||²` 和相关传播响应时才得到可计算界；这个不等式本身不能证明恢复MSE小于攻击过程MSE或正常过程MSE。若进一步假设增广状态转移满足统一指数界 `||F_(k-1)…F_(d+1)||≤M rho^(k-d-1)`，`0<rho<1`，则增广恢复差的二阶矩至多为 `M² rho^(2(k-d-1)) ||T_(d+1)||² E||q||²`。这是**额外假设下**对恢复差的界；本次没有证明冻结模型具有该统一指数界，有限时域等式不需此假设。

若定位结果 `(~e,~r)` 错误，其回写响应为 `~T_k`，则不能沿用上述 `T_k(a-hat{a})`；在线更新继续使用同一固定模式时，实际残差为 `T_k a-~T_k hat{a}`。误归责的发生概率和损失当前均未测量，仍为OPEN。

**反例：准确攻击抵消也不一定降低相对于攻击轨迹的MSE。** 标量单时刻令真实状态 `x=1`、健康估计 `hat{x}^0=0`、攻击影响恰为 `1`、受攻击估计 `hat{x}^a=1`。准确抵消攻击后恢复健康估计0，平方误差从0变为1。故真实攻击影响oracle是恢复名义轨迹的理想参照，不是所有方法实际MSE的必然上界。

## 5. 与GLS影子基线的精确关系

令 `z_k^shadow=z_k^a-T_(k;r,e*) hat{a}`，其为对未经回写轨迹的虚拟输出，使用与联合回写相同的估计量、事件、响应和报警结果。将上述回写作为初始条件并沿相同线性模式递推，有 `z_k^rec=z_k^shadow`（所有 `k≥d+1`）；投影到节点估计后，逐样本输出和MSE相同。即使候选事件是错的，只要双方使用同一个候选响应且后续传递一致，此影子等价仍成立；错误归责改变的是两者与健康轨迹的偏差。

原P0影子仅在仿真中离线计算全网输出，没有实际分发信息；联合回写调试也通过共享内存理想完成同步写回。不能声称二者已在同通信成本下完成部署比较。该等价不否认写回真实内部状态和缓存的工程差别，但**仅凭固定模式下的估计MSE不能建立联合回写优于这个全网影子基线**。
