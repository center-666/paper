# P1-B Task C：有限时域攻击响应矩阵

## 定义和维数

**FACT** 配置指定单条链路 `0→1`，攻击时刻 `t=200,...,249`，输出状态索引 `k=201,...,300`。全网状态维数为 `Nn=10`。见 [`simulation/config.json`](../../../simulation/config.json#L30) 和 [`simulation/engine.py`](../../../simulation/engine.py#L76)。

令 `B=(I−εL)⊗A`、`K_k=blockdiag(K_i(k))`、`H_b=blockdiag(H_i)`、`F_k=B−K_kH_b`。接收节点 1 的单链路输入矩阵为：

```text
G = ε(e_1⊗A) ∈ R^(10×2),
G 的节点 1 行块 = εA = 0.08×1.01 I_2 = 0.0808 I_2，其他行块为零。
```

这里 `e_1` 对应以 0 开始编号的节点 1。攻击者在编码域加入 `a_t∈R²`，接收端解码后扰动为 `M_t a_t`。

定义 `Φ(k,s)=F_(k−1)...F_s`，并约定 `Φ(s,s)=I_10`。条件于水印序列 `M_200:249`：

```text
a = col(a_200,...,a_249) ∈ R^100,
d = col(Δ_201,...,Δ_300) ∈ R^1000,
d = R(M) a，R(M) ∈ R^(1000×100).
```

每个时间块 `R_(k,t)` 为 10×2：

```text
R_(k,t) = 0，                         k ≤ t,
R_(k,t) = Φ(k,t+1) G M_t，           k ≥ t+1。
```

当 `k=t+1` 时空乘积为单位阵，`R_(t+1,t)=GM_t`。所以 t 时注入进入估计 `t+1`，不会再乘本步 `F_t`。所有 100×50 个时间块由该式逐项确定。

## 节点块传播结构

Baseline-Y5 双向环的 `F_k` 对角块是 `0.84A−K_i(k)H_i`，相邻节点块是 `0.08A`，其余块为零。由图距离得到：

| 延迟 `ℓ=k−(t+1)` | 可达节点块 |
|---:|---|
| 0 | 节点 1 |
| 1 | 节点 0、1、2 |
| ≥2 | 五个节点均进入图可达锥 |

**DERIVED** 节点块若距节点 1 的图距离大于 `ℓ`，则响应严格为零；图可达锥内块由 `Φ(k,t+1)GM_t` 给出精确矩阵值，偶然代数抵消除外。无需额外添加攻击反馈项，后续污染已包含在 `F_k`。响应矩阵条件于水印实现，不是对水印取平均的常矩阵。

## 确定性复核

**NUMERICAL** `verify_p1b.py` 构造 1000×100 响应矩阵，以确定性 `M_t` 和固定攻击向量比较矩阵乘法与逐步递推：首块误差为 0、因果零块最大值为 0、完整响应误差为 `6.94e-18`。滞后 0、1、2 的节点支撑验证为 `[1]`、`[0,1,2]`、`[0,1,2,3,4]`。本项不是随机轨迹或水印统计仿真。

## 适用条件

**DERIVED** 线性响应要求增益固定为健康名义协方差预计算序列、全链路同步、无权重/检测门控切换，且攻击只作为接收端解码估计的加性扰动。若攻击后重估增益，或事件触发/缓存改变更新算子，必须重建响应矩阵；本轮不含这些机制。
