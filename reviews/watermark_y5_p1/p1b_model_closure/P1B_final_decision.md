# P1-B：模型闭合与理论准入裁决

## 裁决：CONDITIONAL GO（仅准入 P2-0，不准入 P2 攻击优化）

本轮没有修改估计器、引擎、配置或正式论文；没有生成随机轨迹、运行正式 Monte Carlo 或攻击优化。只新增本目录审查报告和确定性验证脚本。

## 已通过的核验

- **FACT / NUMERICAL** 冻结 Baseline-Y5 全同步估计器、10×10 联合误差协方差递推、链路 `0→1` 注入位置和 P1-A 有限响应递推相符。
- **NUMERICAL** 非对称 `H_i`、非对角正定 `R_i` 下，代码增益与独立块 LMMSE 公式误差 `1.11×10⁻¹⁶`，联合协方差显式组装误差 `2.78×10⁻¹⁷`。
- **FACT / DERIVED** 冻结基线标量各向同性结构使交叉协方差转置方向相同；当前基线未触发一般矩阵索引差异。
- **NUMERICAL** 201–300 全网偏移对 200–249 的 50 个二维攻击输入由 1000×100 条件响应矩阵表示，递推对照误差 `6.94×10⁻¹⁸`。
- **DERIVED / NUMERICAL** 候选水印矩为 `E[M]=I_2`、`E[MᵀM]=1.75I_2`、`E||M||_2²=3.25`；路径级编码域预算与解码域随机幅值已区分。
- **DERIVED** OL/H/C 因果信息结构及单包可行策略已形式化；未证明不同信息权限有严格损害排序。

## 进入 P2-0 的条件

1. 将主张范围限制为冻结的 `H_i=h_iI`、`R_i=r_iI`、`A,Q,P_0∝I`、无向双向环 Baseline-Y5。一般矩阵公式作为代码的局部 LMMSE 推广，不得不加限定地称为 Yang 2014 式（9）的字面推广。Yang 第 2072 页式（9）按 `P_i,s=E[e_i e_sᵀ]` 使用 `P_i,s`；代码一般公式出现 `P_s,i`。若 P2-0 扩大矩阵类别，须先由研究负责人决定模型口径；本轮不改代码。
2. 固定全同步 `q=1` 和有限时域输出 201–300。Yang 原文稳定性假设 `0<q<1` 不能用作此模型的无限时域证明。若 P2 研究固定有限窗口，长期有界性可保留为 OPEN；不得写“稳态”或“长期稳定”。
3. 冻结候选水印 `λ=0.5`、`Σ_β=0.5I` 及路径级编码域预算 `Σ||a_t||²≤E_b`，并指定 `E_b>0` 的数值、密钥共享方式和链路时序。不能把有限编码能量说成有限解码峰值。
4. 策略仅依决策时可见的编码报文和既往信息，不得读取隐藏 `β`、真值或接收端私有量测；动作造成的未来估计及报文反馈必须保留。

这些条件满足后，可以进入 P2-0 的有限时域定理建模。本裁决不授权 50 步最优因果攻击、正式仿真、Monte Carlo 或论文主张定稿。
