# P1-B Task D：水印与预算合同

## 候选水印

**FACT** 本任务预审配置：

```text
M = λI_2 + ββᵀ，λ=0.5，β ~ N(0, Σ_β)，Σ_β=0.5I_2。
```

因此 `M≻0` 且可逆。以下矩是单次新鲜水印的无条件矩。

## 编码、篡改、解码次序

发送节点以秘密水印计算 `z=M⁻¹ xhat_0^a` 并发送。攻击者在编码域加 `a`，接收端解码：

```text
z^a = z+a,
receive = M(z+a) = xhat_0^a + Ma.
```

接收端实际扰动是 `Ma`，不是 `M⁻¹a`。观察编码报文 `z` 不等于持有 `β` realization 或密钥矩阵 `M`。

## 矩推导

零均值高斯下 `E[ββᵀ]=Σ_β`，且由 Isserlis 公式：

```text
E[(ββᵀ)^2] = E[||β||² ββᵀ]
           = tr(Σ_β)Σ_β + 2Σ_β²。
E[M] = λI + Σ_β = I_2。
E[MᵀM] = λ²I + 2λΣ_β + tr(Σ_β)Σ_β + 2Σ_β²
       = 1.75I_2。
E[||M||_2²] = E[(0.5+||β||²)²] = 3.25。
```

**DERIVED** 若当前 `a` 与当前新鲜 `β` 独立，则 `E||Ma||²=1.75 E||a||²`。C 类策略可依赖当前 `z=M⁻¹xhat`，令 `a` 与 `M` 相关；该等式不能直接套用。对单包且 `||a||²≤E_b`，无论这种相关性如何，`E||Ma||²≤3.25E_b`。

## 硬预算与无界水印

使用编码域路径级硬约束：

```text
Σ_(t=200)^249 ||a_t||² ≤ E_b    almost surely。
```

这是每条攻击轨迹的总预算，不是每包预算，也不限制水印 realization。高斯 `β` 无界，故 `λ+||β||²` 无界；任意固定非零 `a` 的解码扰动 `Ma` 支持无界，不存在有限的确定性解码峰值界，但其二阶矩有限。对最多 m 个受攻击包，即使动作依赖当前报文：

```text
Σ_t ||M_ta_t||² ≤ E_b max_t ||M_t||_2²，
E Σ_t ||M_ta_t||² ≤ 3.25 m E_b。
```

后一式使用 `E max_t X_t ≤ Σ_t E X_t`，无需假定 `a_t` 与 `M_t` 独立，是偏松的有限上界。因此有限时域响应二阶矩可控，但不能声称物理峰值有界或无限期有统一界。
