# P1-B Task E：攻击者信息与因果合同

## 时序与观察权限

目标边 `0→1` 每步全同步发送。时刻 t 顺序为：节点由当前受攻击估计产生 `xhat_0^a(t)`；发送端用秘密 `M_t` 编码 `z_t=M_t⁻¹xhat_0^a(t)`；攻击者在接收端采用前可观察原报文并选 `a_t`；接收端解码 `M_t(z_t+a_t)`，在本步一致性更新中使用并产生 `xhat^a(t+1)`。链路即时、无排队；接收节点 1 的私有量测不开放给攻击者。

令 `θ` 包含公开模型、拓扑、增益/协议、攻击时窗、预算和水印分布，但不包含当前秘密水印 realization。记目标边当前原始编码报文为 `z_t`，过去动作为 `a_(200:t−1)`。一种因果信息结构为：

```text
I_t^OL = σ(θ, a_200,...,a_(t−1)),
I_t^H  = σ(θ, a_200,...,a_(t−1), z_200,...,z_(t−1)),
I_t^C  = σ(θ, a_200,...,a_(t−1), z_200,...,z_t)。
```

若允许私人随机策略，可将独立随机种子并入三个信息集。动作 `a_t` 必须对对应 `I_t^s` 可测，不能依赖未来报文、`β_t`、真实状态 `x_t` 或节点 1 私有量测。H 能看到以前受攻击闭环实际产生的报文，故历史信息会内生反映过往污染，不是外生健康数据。

信息结构逐步嵌套，只能推出允许策略类的包含关系和最优值弱单调，不能推出 `V_C>V_H>V_OL`。当前报文 `z_t` 可能统计地泄露关于 `M_t` 与 `xhat_0^a(t)` 的信息，但它不等于获取密钥或唯一反演水印；后续条件概率必须保留此依赖。

## 单包因果可行策略

令 `v_0=(1,0)ᵀ`，`u(z)=z/||z||`（若 `z≠0`），否则 `u(z)=v_0`。以下各策略仅在 t=200 注入，其余时刻为零：

- OL：`a_200=√E_b v_0`，只用公开预算和固定方向。
- H：`a_200=√E_b u(z_199)`，时刻 199 的编码报文已截获，且攻击从 200 开始。
- C：先观察未经修改的当前报文 `z_200`，再取 `a_200=√E_b u(z_200)`；不读取 `M_200`、真实状态或接收端量测。

三者都恰好满足总编码域预算 `E_b`，且只使用决策时可得的信息。这个例子只证明策略可行，不证明其最优或具有严格信息价值。污染第一次出现在状态索引 201：

```text
Δ_201 = G M_200 a_200。
```

之后受攻击估计会生成未来发送端报文，并进入 H/C 的后续历史信息，形成“过去动作—估计污染—未来报文”的内生反馈。

## 开放项

**OPEN** P2-0 需冻结攻击者能否实时访问目标边、报文是否为精确实数或量化值、当前水印与解码的先后顺序，以及其他未攻击边的水印独立性。本合同暂按精确实数报文、目标边即时可观察、攻击者不能读取 `β` 的理想链路抽象。
