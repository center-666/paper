# P1-B Task B：均方有界性审查

## 目标与证据等级

**FACT** 冻结模型的误差协方差服从确定性、时变递推 `P_(k+1)=F(P_k)P_kF(P_k)ᵀ+W(P_k)`，因为每步增益由当前联合协方差计算。Yang 2014 第 2072 页的稳定性分析列出 Assumption 2：`0<q<1`，并在该假设下建立有界性结果。Baseline-Y5 全同步对应 `q=1`，不满足该假设。`A=1.01I` 开环不稳定，不能用开环性质替代滤波闭环证明。

## 可验证的严格充分条件

**DERIVED** 若能证明存在 `X≻0`、`0<ρ<1` 和 `K_0`，使所有 `k≥K_0` 满足：

```text
F_kᵀ X F_k ≼ ρX,
sup_(k≥K_0) tr(X W_k) < ∞,
```

并且有限前缀协方差有限，则

```text
tr(X P_(k+1)) ≤ ρ tr(X P_k) + tr(X W_k).
```

几何级数界给出 `sup_k tr(P_k)<∞`。也可用具有一致正定上下界的时变 Lyapunov 矩阵。当前没有得到对无限未来成立的 `X,ρ,K_0`，也没有证明协方差映射全局收缩。

## 对 P2-0 的影响

**DERIVED** 若单包信息价值只定义于固定 201–300 有限时域，可直接使用有限矩阵响应、有限联合协方差和有限二阶矩，无需先证明无限时域均方有界。此缺口不阻断有限时域 P2-0，但阻断“长期稳定”“稳态损害”或无期限运行保证。

**OPEN** 若扩展至无限时域，必须取得严格矩阵不等式/收缩证书，或独立证明此确定性 Riccati 型递推有界。不得引用 `0<q<1` 的原文定理作为 `q=1` 的证明。
