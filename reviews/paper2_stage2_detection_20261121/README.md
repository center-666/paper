# 第二篇论文阶段 2：持续同向攻击的检测功效研究

基准提交 8cf49e73，日期 2026-11-21。本包按用户提供的正式研究方案开展代码核查、理论推导和冻结实验，正式稿保持原样。

**阶段结论：本轮保守双层混合检测器未通过工程门。** 全部24组独立确认中，D3均为0/50,000检出；它没有实现报警前暴露的改善。更强的成果是原事件记录的信息限制：弱信号的一阶变化消失，并能给出独立于具体检测器的功效上界。起点200、b=0.25、2048拍、误报预算1%时，最终样本支持的95%同时置信上界为S1约5.35%、U1约31.06%。这些数值针对无条件事件型检出率，不覆盖连续载荷、相位或码字记录。

后续工程重点应转向更有信息量的合法记录，并与标准创新残差作同信息比较；本包不再把叠加事件-only检测器当作主要突破口。详见最终结果报告。

## 关键区别

1. 持续篡改只发生在真实发送后，不能假设静默期间每拍有正注入。因此逐拍统一正偏差或正KL下界不成立。发送后的下一可信事件则有可计算的正信息下界。
2. D3的起点和强度双层混合有全时域误报保证；D4使用有限时域联合校准。未知起点没有通过读取真实攻击标签来“解决”。
3. 新停止规则有自己的偏差能量界，不能原样继承旧Azuma界，也不能把它解释成完整MSE恢复保证。
4. 利用偏差不变区间和相位平均核，可对任意事件型检测器给出信息上界，而不只是观察一个候选算法失败。弱攻击信息量至多为O(b⁴)，可靠检测需要至少b⁻⁴尺度的时域。

最后一点的来源是当前对称触发核及相位平均后的事件记录；它不是“量化独有的普遍缺陷”。即使量化误差趋零，对称事件核的一阶变化仍可能消失。读取载荷、相位、码字或改变可信反馈信息可以形成不同问题，不能套用本包的事件-only功效上界。

## 复现入口

[protocol.json](protocol.json) 和 [freeze.json](freeze.json) 固定模型、幅值、起点、种子、候选、阈值及样本数。核心为 [core.py](core.py)、[run_experiment.py](run_experiment.py)。确认阶段通过 [parallel_confirmation.py](parallel_confirmation.py) 调度相同冻结batch函数和种子，只改变并行执行顺序。

确定性预检包括 [全二值树枚举](detector_enumeration_checks.json)、[误差坐标等价检查](error_coordinate_checks.json)、[发送条件常数](constants.json)。实装候选的对数增量范围后来补充于 [constants_actual_candidate.json](constants_actual_candidate.json)；[更正记录](deterministic_correction.json)保留冻结期间并发理论修订、精确恢复原证据及实验输入未改变的核验。

本轮分别进行24组×20,000条初筛、24组×50,000条独立确认，以及两模型各20,000/50,000条8192拍健康筛查/确认。共1,820,000个独立episode单位；配对健康轨道不额外当成独立样本，三个嵌套时域也不重复计数。

[supplementary_analysis_plan.json](supplementary_analysis_plan.json) 在初筛启动后、最终确认前记录信息上置信界的新增分析计划。它不修改检测器，使用所有24×3格并合的95%置信覆盖，不筛选有利单元。

最终表与图由 [analyze.py](analyze.py) 生成，统计汇总位于 analysis 及 results。复现运行需 NumPy 2.4.6、SciPy 1.17.1；绘图使用 Matplotlib 3.11.2，实际Python与环境写入冻结记录。运行脚本保留“已有输出不覆盖”检查，重新抽样应使用独立副本目录并明确新的run身份。

## 方法边界

当前只检测、不恢复，各检测器的总MSE共享同一monitor输出。报警前损失只是暴露长度的截断指标，不是实际降损。连续随机相位仍是理想模型；有限字长、模型失配、信任链和真实通信成本未验证。混合e-process、CUSUM及信息论不等式属于标准工具，本文的协议特化结果尚需近邻全文排重。
