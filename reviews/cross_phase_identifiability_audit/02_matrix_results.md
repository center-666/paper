## 3. 奇异值和信息：有精度收益，不能写成完全无收益

下表均为0→1。s为白化观测矩阵的最小奇异值，I为相应设计信息的最小特征值；对确定FDI位置族才解释为Fisher。

|条件|s_C / s_P / s_J|min eig I_C / I_P / I_J|
|---|---|---|
|主gap8|1.620147 / 0.141120 / 1.623321|2.624878 / 0.019915 / 2.635170|
|主irregular|0.663538 / 0.069473 / 0.668263|0.440283 / 0.004827 / 0.446575|
|秩亏gap8|0 / 0.009279 / 0.010226|0 / 0.00008610 / 0.00010457|
|秩亏irregular|0 / 0.004699 / 0.004774|0 / 0.00002208 / 0.00002279|

主gap8中联合相对C的最小信息特征值增加约0.392%；在固定强FDI方向[1.2,−0.8]上，
\(\theta^T I_C\theta=7.997674\)、
\(\theta^T I_P\theta=0.061332\)、
\(\theta^T I_J\theta=8.718084\)，
联合相对C的方向信息增加约9.01%。**应同时保留这个正面证据，不能只挑最小特征值的小增量。**

half和quarter对应2.179521、0.544880，分别为联合强方向量的1/4、1/16。它们是同一模型下的解析能量缩放，不是检出率提升。所有原始/白化奇异值、完整2×2信息矩阵、跨阶段交叉块均保存在逐事件NPZ。

这些变化符合标准Schur条件信息累积。没有新的方向并不等于没有更好的有限噪声精度；但本轮没有证明这种精度变化超出同信息标准多通道GLS。

## 5. Replay和低幅攻击如何解释

响应矩阵由事件、公共模型和固定日程决定，不由载荷差大小、来源或攻击名字决定。故以上“没有联合独有方向”对该h下的强/half/low FDI及合法Replay扰动均成立。

主gap8的第8个历史真实包为s=136，r−s=64，满足实际发送。其余行保存第8前包来源、年龄、64步来源合法性和80步matched-gap来源合法性；不合法就记False，不使用未发送包。

Replay幅值与健康噪声相关，所以信息数字只作设计几何；未计算Replay条件Fisher、真实检出功效或受攻MSE。其限制见03号。

## 6. 验收、失败和可复现

代码：[phase_matrix_audit.py](code/phase_matrix_audit.py)。
从仓库根用项目现有.venv/Scripts/python.exe执行，指定一个新的输出目录；程序拒绝覆盖已有Run。

    & ./.venv/Scripts/python.exe -X utf8 reviews/cross_phase_identifiability_audit/code/phase_matrix_audit.py --out reviews/cross_phase_identifiability_audit/results/c_phase_geometry_reproduction_01

复现时若该目录已存在，另取新的Run ID；不要删除旧结果后复用名称。

- 主实例与旧已验收state_response/cache_response逐元素差均为0，未重做完整仿真。
- 当前v反馈的两拍解析协方差检查误差0；漏掉−Kv的算法不会通过。
- 全部Schur信息恒等式最大相对残差5.36e−16。
- 最小联合噪声特征值约0.05；使用Cholesky，无ridge。
- 初次用miniconda启动缺少NumPy发生在模型运算前，保留 [启动失败记录](results/launcher_failure_20261114.json)，之后用已有项目环境，无安装/依赖修改。

结果目录保存60个逐事件NPZ、共同坐标NPZ、CSV、全部配置/日程/名义增益、源文件哈希与汇总。主Run耗时约2.77秒，不能把它称为新Monte Carlo或独立性能确认。
