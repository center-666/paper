# 可信本地尺度的可辨识边界与虚警推导

## 性质一：链路攻击下本地参考不变

**DERIVED** 固定同一物理状态/可信本地量测路径、相同本地参考初值和模型参数，令参考递推只依赖 `y_i`：

```text
xbar_(i,k+1) = A xbar_(i,k) + Kloc_i(y_(i,k)−H_i xbar_(i,k)),
chat_(i,k) = G(u_(i,0:k), public model).
```

若攻击只改邻居链路且估计器输出不反馈物理过程/本地量测，则健康与攻击耦合路径上逐时有 `xbar_i^a=xbar_i^0`、`u_i^a=u_i^0`、`chat_i^a=chat_i^0`。这是数据隔离的代数性质，不是独立噪声假设，也不保证 `u_i` 足以观测目标链路协方差变化。

## 最小不可辨识反例

**DERIVED** 取两节点一维线性高斯单次量测。共同静态状态 `x~N(0,P)`，接收端 i 的本地参考预测为 `xbar_i=0`，本地量测 `y_i=x+v_i`，发送节点 j 的本次估计取 `xhat_j=y_j=x+v_j`。本地可信创新为 `u_i=y_i`，链路残差为 `r_ji=y_j−xbar_i`。令噪声独立：

```text
P=1, R_i=1,
H0: R_j=1,
H1: R_j=4.
```

则在两个正常工况下 `u_i~N(0,2)` 完全同分布，而 `r_ji` 的方差分别为 `2` 和 `5`。任何只用本地序列 `u_i` 的校准器 `chat=g(u_i,0:n)`，在H0/H1下输出分布相同；增加本地样本数也不能一致地识别邻居测量噪声改变。这个例子不属于完整Yang动态网络，但严格证明“所有噪声改变都可由接收端本地创新估计”不成立。

因此，候选必须额外假设噪声变化属于本地创新可辨识的共同尺度族，或存在可信量测覆盖所有变化源的结构条件。仅写 `S_ji(c)=cS0` 不足以推出本地 `u_i` 对 c 有信息。

## 受限共同尺度模型下的阈值上界

### Baseline-Y5 本身也有同一限制

**DERIVED** 保持物理过程、接收端1量测和参考递推相同，只把发送节点0的测量协方差在t=200从R0改为4R0。本地参考及其创新的整个路径/分布完全不变。接收前的r_201使用发送节点估计hat_x0(201)，因此新增独立噪声贡献是 `K0(200)(3R0)K0(200)ᵀ`。用冻结矩阵复算得到 `0.02918122517 I2`，严格正定（见 `results/analytic_checks.json`）。这证明当前五节点模型也存在“本地校准看不到、链路残差却变化”的正常工况。这里没有生成新随机轨迹，没有改变主配置；它是指定矩阵上的两种噪声假设对照。

### 正常变化与攻击同时出现的最小例子

**DERIVED** 为单独展示机制，考虑标量独立时序模型 `u_k=sqrt(c)eta_k`、`r_k=sqrt(c)xi_k+b`，eta、xi为独立标准Gaussian。工况从c=1变为c=4，同时链路偏置b=2；本地u不含b。历史均方尺度在固定工况窗口内的期望分别为 `E[chat_link]=c+b²=8`、`E[chat_local]=c=4`。无限窗口极限下，使用自身受攻二阶矩标准化的分数均值为1，可信标准化为2。有限窗口分数是比值，不能把该均值结论照搬为有限样本检出率。这是标准均值污染二阶矩例子，不是新理论，也不替代Yang试验。

以下概率界只针对指定共同尺度模型，不能因上述路径隔离就默认它成立。

**DERIVED** 设健康链路残差边际分布 `r~N(0,cS0)`，定义 `X=r^T(cS0)^−1 r~chi²_d`。统计量 `T=r^T(chat S0)^−1r=(c/chat)X`。若事件 `E={chat/c≥1−rho}` 满足 `P(E)≥1−delta`，则无需假设 X 与 chat 独立：

```text
{T>tau} ∩ E ⊆ {X>tau(1−rho)},
P(T>tau) ≤ P(chi²_d>tau(1−rho)) + delta.
```

要保证单次检验 `P_FA≤alpha`，须 `delta<alpha` 并选 `tau≥F_chi²_d^−1(1−(alpha−delta))/(1−rho)`。若一次episode检验 M 个时刻，直接用并集界得到 `P(any FA)≤Σ_k[P(chi²_d>tau_k(1−rho_k))+delta_k]`；单时刻界不能直接当episode界。

**OPEN** 该界不新颖，增量只能来自可部署的信息通道确能给 `chat/c` 的覆盖事件。若 `u_i` 与目标c无关（上述反例），覆盖事件不可能对任意 `c` 成立；若 c 为常值共同尺度且参考滤波器正确、创新白化序列成立，可以用卡方样本界建立估计覆盖。噪声突变瞬态、独立变化的各 `Q,R_j` 或自适应Yang增益改变后，`S_t=cS0` 和局部NIS分布须重新推导。

**DERIVED：一个实际可证但受限的校准器。** 设从初始化起P0、Q和全部R都乘相同未知常数c；增益固定为名义序列。取最近w个本地创新的堆叠U，令其完整名义联合协方差为Omega0（含时间相关，已知且正定），则 `U~N(0,c Omega0)`。设p=dim(U)，`chat=UᵀOmega0⁻¹U/p`，有 `p chat/c~chi²_p`。因此可以直接用其分位数计算delta，或用下尾界 `P(chat/c<1−rho)≤exp(−p rho²/4)`，带入上述并集界。它不要求本地创新与本拍链路残差独立，但要求共同尺度和完整Omega0正确。这个标准构造说明常尺度受限版本数学可行，不能推广到任意未知切换；pilot的30拍逐项平均也没有被此证明自动认证。

**DERIVED：突变索引。** 过程/测量噪声在t=200开始变大时，发送估计hat_x(200)与参考xbar(200)均来自此前数据，所以 `S_200=S0_200`，不是4S0_200。`S_(t+1)=C(F_t P_t F_tᵀ+c_t W_t)Cᵀ` 才给真正过渡协方差。把每个t的S直接置为c_t S0会使Oracle本身错误。

## 标准适用条件不能隐藏

- 正常本地创新须零均值高斯/已知有限矩，参考滤波器参数正确，且使用的参考创新协方差为真实协方差。
- 共同尺度假设必须覆盖初始误差、过程噪声及所有相关节点量测噪声；只对目标链路另一端的 `R_j` 变化时反例成立。
- 调参窗口、异常数据剔除、变化点延迟会改变 `chat` 的偏差和覆盖率；需在理论中显式计入，不可由“参考通道不读邻居报文”自动推出。
- 若异常由真实系统物理输入/状态反馈引起而非通信链路，`y_i` 可受物理状态影响，逐路径不污染性质不再成立。
