# 唯一条件问题：包级相关隐私噪声下的融合风险证书

**HYPOTHESIS / OPEN；非立项、非新算法完成。** 只保留F供数学可实施性核查。本轮没有防御实现、随机仿真或旧结果改动。Ye/Wang已审至取得版本；Gao未取得。

## 1. 具体问题与必要约束

Yang节点得到含隐私随机化的邻居包，多拍缓存复用会产生跨拍与跨节点相关。仅公开边缘噪声协方差范围时，能否从实际接收历史给一次邻居融合的真实MSE风险一个足够紧的上界，且在收益可证时保留非零邻居贡献？

这不是检测所有假噪声，也不是重启GLS。Wang已覆盖未知协方差检测校准，Ye已有历史残差熵FNAD；新操作若存在，须改变融合风险能力并超出标准最坏方差替换/CI。

## 2. 噪声按包生成，不能每拍独立重抽

$$x_{k+1}=Ax_k+w_k,\qquad y_i(k)=H_ix_k+v_i(k).$$

在j实际发送时刻r生成隐私噪声，攻击仅改实际发送后的载荷：

$$m_{ji}(r)=\hat x_j(r)+\xi_j(r)+a_{ji}(r),\qquad
\bar m_{ji}(k)=A^{k-r}m_{ji}(r),\quad r=r_{ji}(k).$$

ξⱼ表示一次广播共用噪声；若按接收者独立生成，需明确改用ξⱼᵢ与相应报文结构。攻击不改本地量测，不读接收端当前私有量测/未来数据。若将来包含Replay，必须引用真实历史含噪发送包，不能给攻击者免费未加噪sender估计。

固定公开日程与固定r、Cov ξᵣ=Vᵣ时，同包噪声nₖ=A^(k−r)ξᵣ满足

$$\operatorname{Cov}(n_k,n_\ell)=A^{k-r}V_r(A^{\ell-r})^T.$$

这是固定日程无条件公式；r由SoD和历史噪声共同决定时，条件分布另证。广播噪声跨接收边共用；反馈使Cov(eₖ⁰,ξᵣ)通常非零。不可将每次融合当一次独立新测量。

公开集合0≼Vunder≼Vᵣ≼Vover必须有来源：可信机制、可靠正常校准，或统计覆盖集合。攻击者自报方差不可信。噪声矩范围、差分隐私(ε,δ)、互信息指标不能互换；加Gaussian噪声不自动提供完整隐私保证。攻击能量/交叉矩约束同样需说明来源，不能为证明临时假定在线已知。

## 3. 两种决策时序

### 3.1 融合前冻结增益

令𝒢ₖ只含当前量测/包进入前的合法历史，B为𝒢ₖ可测。e⁰是基线不用该邻居贡献时的下一拍误差，d是对齐邻居差向量，更新后e=e⁰−Bd。真实条件**二阶矩**含均值：

$$S_k=\mathbb E\left[\begin{pmatrix}e^0\\d\end{pmatrix}
\begin{pmatrix}e^0\\d\end{pmatrix}^{T}\middle|\mathcal G_k\right]
=\begin{pmatrix}P&C\\C^T&D\end{pmatrix}\in\mathcal S_k.$$

新量测噪声独立于过去不意味着e⁰和d互不相关。对W≽0，单拍风险差为

$$q(B,S)=\operatorname{tr}\{W(BDB^T-BC^T-CB^T)\}.$$

唯一待审操作：

$$B^*\in\arg\min_{B\in\mathcal B}\sup_{S\in\mathcal S_k}q(B,S),\qquad 0\in\mathcal B.$$

假设集合真实覆盖条件矩、上确界有限且最优解存在。零融合q=0使最优值≤0，对集合内每个真实S均不增单拍条件MSE；最优值严格负且B*非零才有非平凡收益。

**DERIVED / STANDARD：** 平方展开、凸性及零动作证书均为标准鲁棒估计。q对B凸、对S线性；是否可转SDP取决于集合支持函数，不能对任意集合称“可解SDP”。真正缺口是用同权限信息构造有效、紧且保留包噪声/反馈相关的𝒮，并证明比标准相关性鲁棒融合更有信息。当前OPEN，没有把此框架当新理论。

### 3.2 增益若已读取当前包/innovation

𝓘ₖ含实际d，条件期望中d已知，此时

$$\Delta J=(Bd)^TW(Bd)-2\mu_e^TWBd,\qquad
\mu_e=\mathbb E[e^0\mid\mathcal I_k].$$

缺的是μₑ的合法条件集合，不是仅估边缘V。不能用无条件P/C/D给B(d)套条件保证；不能把当前量测噪声条件化后的交叉项消去。该信息构造OPEN。

### 3.3 不自动扩展为有限窗

上述只是一拍差。有限窗须描述后续缓存、增益和发送模式，以完整响应替代B；SoD、cap及门控随动作改变后续模式，不能简单套固定线性映射。非平凡的有限窗结论仍需模式变化与信息条件证明，不是加一个求和号。

## 4. 两项必须保留的反例

**最坏总风险下降不等于逐模型不劣。** 合法标量联合矩(P₁,C₁,D₁)=(100,10,1)、(P₂,C₂,D₂)=(1,0,1)均PSD。γ∈[0,1]时总风险P−2γC+γ²D的minimax选γ=1，将最坏100降至81，但第二模型从1升至2。逐模型不劣需风险差目标或显式约束。

**不可检测不等于不能融合。** ξ~N(0,V)与ξ₀+a（独立Gaussian方差V₀、V−V₀）同律时标签不可识别。但x~N(0,p)、d=x+n、总噪声独立零均值且Var n≤V时，标准λ=p/(p+V)>0给最坏MSE pV/(p+V)<p，不必分辨噪声成分。此为STANDARD，不能当新机制。只匹配单拍方差也不能声称整个闭环历史同分布，反例须匹配全部生成条件。

真正失败可能是𝒮中的C符号无法限制，最坏风险差仅允许B=0；或有用非零增益已经由标准CI/最大方差替换给出。无条件能量界不自动支持条件覆盖；高概率覆盖事件也需尾部条件才能推出无条件MSE。
