## 结论

用户定义的 \(L_{\rm cert}(k)\) 可通过至多 \(n\) 个窗口、\(2^{k+1}\) 个事件历史上的矩阵秩检验精确确定（输入精确且可进行精确代数运算时）。它是**所选逐历史外包证书的最短充分窗口**。通过后，对 \((P_k^+,1_{E_L})\) 和任何包含该记录的完整未来事件串有全策略 TV—MSE 界。

它不是最短全策略安全窗口。已有非退化因果反例甚至满足 \(L_{\rm cert}=\infty\)，而长度 1 的最小记录已经满足全策略线性 TV—MSE 界。旧的单拍隐蔽攻击定理也只提供一个可验证的失效充分条件；一般必要充分策略条件仍无计算解。

在健康协议独立重复条件下，所用归一化全静默统计量的方差可证明至少以 \(\rho^{-L}-1\) 增长，其中 \(\rho=\det(I+R^{1/2}ZR^{1/2})^{-1/2}<1\)。这是**该统计量和重复采样方案**的代价，不是所有可能审计器或所有 TV 估计方法的样本复杂度下界。

充分证书与反例分别继承既有报告，窗口计算及统计量代价在本报告中推导；尚未完成 Liu 2024 全文定理级排重，不主张全球新颖性。本轮按用户停止门结束，不修改现有论文。
