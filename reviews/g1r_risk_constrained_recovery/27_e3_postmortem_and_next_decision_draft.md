## 2. G1-R 研究路线和阶段时间线

### 2.1 G1：从历史 Replay 到污染传播

**FACT。** 早期工作研究了单次历史 Replay 数据包进入缓存后，如何在固定外生通信日程和 Yang 型递推中传播。完整传播审计使用固定 gap-8 日程、名义增益和保存的配对 Seed，将递推结果与完整仿真比较，最大误差约为 (10^{-13})。证据见 [g1_retroactive_recovery/07_full_horizon_propagation_audit.md](../g1_retroactive_recovery/07_full_horizon_propagation_audit.md)。

**可继承问题定义。** 在通信时刻 (	au) 将历史包写入链路缓存后，接收节点在后续时刻使用缓存值并外推。令 (Delta_k) 表示受攻 Yang 估计与同初态、同噪声的健康反事实估计之差，则在固定日程下可以写成分段线性递推：


\[
\Delta_{k+1}=F_k\Delta_k+G_k\delta_k,
\]

其中 (delta_k) 表示缓存替换或重放输入造成的污染，(F_k,G_k) 由 Yang 递推、网络反馈和缓存更新时刻决定。

**边界。** 这是传播分析，不是攻击检测，也不是恢复性能保证。固定 gap-8、固定网络和固定目标时刻不能外推为任意间歇通信日程或任意网络拓扑的普遍结论。

### 2.2 G1-R 早期：内部回写与影子输出修正

**FACT。** 研究曾实现检测后的内部状态与通信缓存联合回写，并与影子输出修正比较。固定线性通信模式、相同合法信息和输出轨迹一致时，两者 MSE 没有体现出稳定差异。结项意见见 [g1_retroactive_recovery/20_research_closeout_no_go.md](../g1_retroactive_recovery/20_research_closeout_no_go.md)。

**DERIVED。** 对只读取当前输出的上层任务，内部变量写回的位置不是自动的统计创新。如果回写后的输出轨迹与影子修正轨迹一致，后续 MSE 也可能一致。

**边界。** 该结果不能推出内部回写在所有控制或缓存联动工程中都无价值；它只否定把“写回内部状态”本身包装成当前估计性能创新。若未来要研究回写，必须引入当前 MSE 之外的不可替代工程目标，并重新定义公平基线。

### 2.3 任务 1—2：联合统计模型

**FACT。** G1-R 对 8 个候选事件和 3 个 Replay 年龄建立了攻击影响、创新和健康估计误差的联合 Gaussian 模型，保留了交叉协方差。核心推导见 [07_replay_joint_probability_model.md](07_replay_joint_probability_model.md) 第 1—5 节。

令 (e_0=\hat x^0_{217}-x_{217})，令 (Delta) 为 Replay 污染，令 (z) 为 211—216 窗口的 12 维创新，则受攻估计误差为

\[
e_a=e_0+\Delta,
\qquad
L_a^u=\|e_0+\Delta-u(z)\|^2.
\]

**DERIVED。** Soft Average 的 (E[\Delta\mid z]) 是污染残差平方损失的条件最优动作；真实状态损失的条件最优动作应涉及

\[
E[e_0+\Delta\mid z],
\]

因此“污染影响估计最优”不能直接称为“真实状态 MSE 最优”。这一边界写在 [07_replay_joint_probability_model.md](07_replay_joint_probability_model.md) 第 6 节。

### 2.4 任务 3：正常风险证书收紧

**FACT。** 初始风险分析使用了较保守的交叉项界，得到 (U\approx0.011323)，并判断在 1% 正常风险预算下无法支持预设的 1% 攻击收益。该结论只针对保守幅度证书，不是对整个风险预算或集合方法的普遍否定，见 [08_budget_precheck_and_stage_decision.md](08_budget_precheck_and_stage_decision.md)。

**DERIVED。** 因为动作只依赖 (z)，健康误差中与动作相关的部分可以写为

\[
m_0(z)=E[e_0\mid z]
\]

并得到正常工况的精确风险恒等式：

\[
J_c-J_0
=E_0\left[\|u(z)\|^2-2m_0(z)^Tu(z)\right].
\]

在冻结模型、(R/J_0=1\%)、非零动作概率上界 5% 的条件下，新的统一证书给出 (U_{new}\approx0.051261)，而达到 1% 攻击收益所需的必要幅度约为 (0.014917)。证据见 [09_exact_normal_risk_refinement.md](09_exact_normal_risk_refinement.md)。

**边界。** 该结论说明“原来的保守上界排除了动作”这一障碍被解除；它不说明某一种动作一定改善真实状态 MSE，也不自动构成原创基础理论。底层工具是条件期望、Gaussian 条件分布和尾部重排，研究价值来自其对当前缓存 Replay 决策口径的正确适配。

### 2.6 E2：共同候选影响集合覆盖

**FACT。** E2 主场景覆盖率为 200/200，单侧 95% Clopper–Pearson 下界为 0.98513；Set 的攻击非零动作数为 136/200，正常非零动作数为 0/200。Hard 和 Soft 也通过相同的 E2 门槛。独立程序对 4800 个唯一 Seed—事件—年龄组合复算，与原覆盖记录零差异，证据见 [21_e2_final_report_20261116.md](21_e2_final_report_20261116.md) 第 3、6 节和 [22_e2_independent_coverage_audit.md](22_e2_independent_coverage_audit.md)。

## 3. E3 后的性能诊断

### 3.1 三种方法的总体差异

**FACT。** 主场景中 Soft 的 MSE 最低，Hard 次之，Set 最高；三者都优于未补偿 Yang。主场景的非零动作数分别为 Hard 157/200、Soft 164/200、Set 142/200；全部实际动作达到共同幅度上限的比例分别为 78.5%、82.0%、71.0%。来源为 [26_e3_formal_experiment_report.md](26_e3_formal_experiment_report.md) 第 3 节。

**DERIVED。** Set 的问题不是“完全拒绝所有攻击”。它在主场景仍有 142 次非零动作，也能取得 2.40% 的相对 Yang 改善；但它执行动作更少，且在执行时对不确定集合采用的中心不如 Hard/Soft 的动作接近真实状态方向。由于所有方法共享 (U)，Set 的差距不能简单归因于幅度上限比别人更小。

**FACT。** 在全部 4800 个 Replay 场景中，Hard、Soft、Set 非零动作分别为 1719、1872、1195；Set 的 3605 条零动作均为 `ZERO_OR_UNRESOLVED` 并被 gate 拒绝，没有出现 `SOLVER_REJECT` 或正式执行异常。来源为 [26_e3_formal_experiment_report.md](26_e3_formal_experiment_report.md)，第 8 节。

### 3.2 按事件和 Replay 年龄观察的现象

**FACT。** E3 的 24 个事件—年龄单元均保留在 [event_age_metrics.csv](results/g1r_e3_completion_audit_20261116_r01/event_age_metrics.csv)。报告指出，较早事件如 ((0,176))、((3,178)) 上 Set 几乎总是拒绝非零动作；主事件和后续事件的 Set 触发率逐步升高。age32、64、96 是配对压力诊断，确认性判据仍固定在 age64 八事件最坏风险。

**DERIVED。** 该模式与传播可观测性有关：较早 Replay 事件经过更长的缓存和反馈传播后，创新窗口对具体影响的反演可能更不确定，集合更容易变宽、包含零或无法给出稳定的非零中心。后续事件在目标时刻留下更强的创新信号，因此触发率提高。这是由现有数据和传播递推支持的解释，但尚未被单独的几何统计分析证明，标为 HYPOTHESIS。

**FACT。** 在某些事件和年龄上，Set 的 MSE 甚至略高于未补偿 Yang；报告明确保留这些结果，没有只展示有利主场景。来源为 [26_e3_formal_experiment_report.md](26_e3_formal_experiment_report.md)，第 7 节。

### 3.3 Set 方法失败机制的分层判断

**FACT。** 已确认的直接机制包括：

1. Set 的大量零动作来自 `ZERO_OR_UNRESOLVED`，不是求解器失败；
2. E2 集合覆盖成功，但 E2 没有保证集合不含零、集合半径足够小或中心方向接近真实 (Delta)；
3. 共同 (U) 下主场景动作大多达到上限，说明幅度约束确实参与了动作形成；
4. Set 的最坏事件风险点估计略高于 Hard 和 Soft，而不是只在置信区间意义下无法分辨。

证据分别见 [02_mathematical_audit.md](02_mathematical_audit.md)，第 3—5 节；以及 [26_e3_formal_experiment_report.md](26_e3_formal_experiment_report.md)，第 3—5、8 节。

**DERIVED。** 当前 Set 的失败可以分成三个层次：

- **可识别性不足**：多个历史事件或参数解释在当前 (z) 下产生相近响应，集合无法收缩到一个方向；
- **决策目标不匹配**：Chebyshev 中心优化的是集合到健康反事实影响的最坏距离，不直接优化真实损失
  (|e_0+Delta-u|^2)；
- **风险门控过于保守**：集合包含零、方向冲突或评分不足时，算法选择零动作，避免误修正但同时放弃了可获得的攻击收益。

这三层不能混为“Set 算法实现错误”。现有审计显示没有正式仿真异常、结果损坏或统计复算错误。

**OPEN。** 现有结果还不能给出以下更细的因果分解：在每个 Seed 上，性能差距究竟有多少来自集合包含零、多少来自集合中心偏差、多少来自 gate 拒绝、多少来自 (U) 饱和。原始结果保存了所需字段，但需要一个新的只读几何分层分析；本任务不启动该分析。

### 3.4 真实恢复收益分解

**FACT。** 主场景 Set 的攻击真实 MSE 收益约为 0.23778329，其中污染收益约 0.23556171，健康误差交叉项约 0.00222157，配对健康收益约 -0.00006904，净收益约 0.23785232。来源为 [26_e3_formal_experiment_report.md](26_e3_formal_experiment_report.md)，第 5、6 节。

逐样本恒等式为

\[
L_a-L_a^u
=\left(2\Delta^Tu-\|u\|^2\right)+2e_0^Tu.
\]

**DERIVED。** 主场景 Set 的改善主要来自降低 Replay 污染，而不是正常场景额外滤波收益；但污染收益较大仍不意味着 Set 比 Hard/Soft 更优，因为 Hard/Soft 的污染收益更大。主场景攻击 MSE 收益为 Hard 0.24280207、Soft 0.24536527、Set 0.23778329。

**FACT。** 独立正常组中 Set 为 0/200 非零动作，Hard 为 9/200，Soft 为 15/200；这只能作为本组诊断，不能把它解释成 Set 的总体正常动作概率为零，也不能用低误动作替代攻击恢复优势。来源为 [26_e3_formal_experiment_report.md](26_e3_formal_experiment_report.md)，第 6 节。

## 4. 已有成果和未解决问题的边界

### 4.1 已有理论成果

**FACT / DERIVED。** 已有理论资产包括：

1. 固定外生通信日程下缓存 Replay 污染的线性传播递推；
2. 影响、创新和健康误差的联合协方差构造；
3. 基于 (E[e_0\mid z]) 的正常风险恒等式和统一幅度证书；
4. 置信椭球并集的边际覆盖口径；
5. 有限集合条件中的秩/核约束；
6. “集合覆盖不推出真实 MSE 下降”的具体反例；
7. E2/E3 的配对 Seed、健康交叉项和最坏事件风险评价。

主要依据为 [02_mathematical_audit.md](02_mathematical_audit.md)、[07_replay_joint_probability_model.md](07_replay_joint_probability_model.md)、[09_exact_normal_risk_refinement.md](09_exact_normal_risk_refinement.md)、[23_e3_mathematics_and_implementation.md](23_e3_mathematics_and_implementation.md)。

### 4.2 尚未解决的问题

**OPEN。** 仍缺少一个能独立支撑论文核心贡献的结果，至少包括以下一种：

- 给定通信日程、响应矩阵和攻击字典时，何时可以从有限创新窗口唯一辨识攻击影响，而不只是覆盖一个集合；
- 不可辨识时，任意在线补偿器都必须承受多大的最坏真实 MSE 损失；
- 如何在不改变现有信息权限的前提下，把可辨识性条件转成动作接受、拒绝和风险界；
- 为什么一种新决策能够在同一正常风险预算下稳定优于 Soft/Hard，且优势不是来自额外信息、不同校准或测试后调参。

**DISPROVED / COUNTEREXAMPLE。** 仅凭以下任一条件不能得到真实状态 MSE 优势：

- 真实影响被集合覆盖；
- Chebyshev 半径较小或集合远离零；
- 影响方向估计准确；
- 正常非零率很低；
- 相对未补偿 Yang 的主场景 MSE 改善。

证据见 [02_mathematical_audit.md](02_mathematical_audit.md) 第 5 节和 [12_v2_mathematical_and_fairness_audit.md](12_v2_mathematical_and_fairness_audit.md) 的反例审计。

## 5. 三个候选方向的竞争性分析

### 5.1 A：历史事件归责不确定条件下的风险约束恢复决策

**科学问题。** 当多个历史 Replay 事件都与当前创新窗口相容时，如何在同一合法信息、同一正常风险预算下选择非零补偿或拒绝，使真实状态 MSE 相对 Hard GLS 和 Soft Average 获得稳定优势？

**数学问题。** 给定候选影响集合 (D(z))、健康误差条件统计 (m_0(z))、动作约束 (|u|\le U) 和正常风险约束，直接研究

\[
\min_{u(z)}\ \text{真实状态损失或其风险上界}
\]

同时控制非零动作概率和覆盖失败事件。现有 [02_mathematical_audit.md](02_mathematical_audit.md) 第 7 节已经给出一个标准的“损伤差证书”方向，但明确标为标准凸稳健优化，尚未批准替代 Set 算法。

**G1-R 已解决。** 已有候选集合、Hard、Soft、Set、统一 (U)、正常风险证书和真实 MSE 评价合同。

**还缺少。** 需要一个与 Chebyshev 中心不同、能直接针对真实损伤差的决策机制，并证明它在信息权限不变时有非平凡的接受条件和风险保证；还必须解释为什么它能超过已经很强的 Soft Average。

**与现有方法关系。** Hard 是单一解释，Soft 是影响条件均值，Set 是候选集合的最坏距离中心。新方法若只是换成另一个标准中心、普通 Bayesian 平均或一般鲁棒优化，仍可能只是标准适配。

**竞争文献边界。** [01_scope_and_competitors.md](01_scope_and_competitors.md) 已核查 Deghat 2019 的攻击跟踪/输出切换、Tabatabaei 2025 的重构和恢复、Gupta 2026 的多策略条件估计，以及 Mao 2026 的多模型后验融合。它们没有在当前离散缓存权限下逐字覆盖本问题，但“多解释融合”和“攻击恢复”本身不能再作为新意。

**可能的中心定理。** 只有在建立类似下述结果时才有研究意义：在集合 (D(z)) 的投影分离、健康误差条件界和攻击尾部矩条件成立时，某一动作规则同时给出正常风险上界和受攻真实损伤差的非正证书，并且该规则对某类不可辨识集合严格优于 Hard/Soft 的风险上界。

**实验假设。** 在不增加信息和不改变 (U) 的情况下，新决策在 8 个 age64 事件的最坏 Seed 均值风险上低于 Hard/Soft，并在正常组满足冻结风险界。

**工作量与停止条件。** 高。需要新理论、新算法、公平重校准和新的独立 E2/E3。若证明退化为标准凸优化、无法给出相对 Soft 的严格条件，或只能通过改变预算和门槛取得优势，应停止 A。

**判断。** `OPEN / 高风险`。现有 E3 已经说明当前 Set 的核心动作选择不够强，继续做 A 不能沿用“集合覆盖”作为创新理由。

### 5.2 B：历史污染的可恢复性、不可辨识性与恢复难度理论

**科学问题。** 在固定间歇通信和有限创新窗口下，什么条件决定历史 Replay 污染是可唯一恢复、只能集合恢复，还是原则上不可辨识？不可辨识时，任何只使用接收端合法信息的补偿器至少要承受多大的恢复风险？

**数学问题。** 对事件 (h)、攻击参数 (\theta)、影响映射 (G_h\theta)、创新响应 (O_h\theta) 定义等价关系：

\[
(h,\theta)\sim(h',\theta')
\quad\Longleftrightarrow\quad
O_h\theta=O_{h'}\theta'.
\]

需要研究：

1. **影响可辨识性**：不同解释产生相同创新响应时，是否仍产生相同目标影响；
2. **有限集合条件**：现有审计指出，单候选模型下需满足类似
   (\ker O_h\subseteq\ker G_h)
   才能避免影响沿不可观测方向无界；
3. **集合半径和日程关系**：缓存年龄、传播矩阵和窗口长度如何改变等价类大小；
4. **不可辨识下界**：若两个候选解释给出相同 (z) 但不同 (Delta)，任何在线动作都无法同时精确抵消两者，因而可推导最小最坏损失；
5. **恢复难度指标**：用响应矩阵的最小奇异值、事件间分离度或集合直径定义可计算难度。

**G1-R 已解决。** 已有传播矩阵、候选事件字典、创新响应、椭球集合构造、核空间有限性条件和具体反例。见 [02_mathematical_audit.md](02_mathematical_audit.md) 第 2—5 节及 [03_problem_and_implementation_contract.md](03_problem_and_implementation_contract.md) 第 3 节。

**还缺少。** 目前只是若干条件和反例，还没有把事件等价类、影响等价类、目标时刻恢复风险和通信日程统一成定理；也没有证明不可辨识下界与 E3 的 Hard/Soft/Set 性能差异之间的关系。

**与现有方法关系。** Hard、Soft、Set 都可以被解释为在同一个不确定影响集合上做不同决策；B 不把它们重新命名为新算法，而是研究它们共同面对的可辨识性边界。Hard/Soft/Set 可以作为定理的实例和实验基线。

**竞争文献边界。** Deghat、Tabatabaei、Gupta、Mao 等工作提供攻击跟踪、重构、多模型后验或融合机制，但现有项目审计没有证明它们给出了本项目“固定缓存 Replay + 离散间歇日程 + 有限创新窗口 + 目标状态影响等价类”的完整不可辨识下界。这个差别仍须由负责人进行定向公式核查，不能仅凭系统模型差异宣布创新。

**可能的中心定理。** 一个有意义的定理应具有如下结构：

> 对给定通信日程和事件字典，若存在两个合法攻击解释产生相同在线观测 (z)，但目标影响相差至少 (d>0)，则任何只依赖 (z) 的补偿器，在至少一个解释下的目标状态残差不小于 (d/2)（再根据健康误差和动作约束给出平方损失版本）。若所有等价解释的目标影响相同，则影响可以被唯一恢复，即使攻击事件本身不能被唯一归责。

这个结果会把“事件不能唯一定位”和“目标影响仍可恢复”区分开，也能解释为什么 E2 覆盖不等于 E3 优势。

**实验假设。** 只使用已有传播矩阵和 E3 结果，按事件、年龄、窗口构造可辨识性指标，检验指标是否与 Set 的零动作率、最坏事件风险和 Hard/Soft 差距相关。若需要新增实验，优先做小规模确定性验证，不先进行大规模性能重跑。

**工作量与停止条件。** 中等到高。若可以在现有矩阵上完成等价类、核空间和两点下界的统一证明，且竞争文献没有已经给出同一结果，则值得继续；若最终只是标准满秩/秩亏 GLS 条件，或无法得到任何与 Replay 缓存和年龄相关的非平凡结论，应停止 B。

**判断。** `最值得先审查 / 仍未立项`。它最能利用已经完成的研究资产，也不依赖把当前 Set 失败包装成成功。

### 5.3 C：历史攻击定位、污染传播和恢复统一框架

**科学问题。** 能否把事件定位、污染传播和风险受限恢复放入一个统一的时序估计框架，并给出从检测信息到目标状态风险的端到端保证？

**数学问题。** 需要同时处理事件假设 (h)、参数 (\theta)、缓存状态、传播矩阵、正常风险和真实状态损失，形成一个联合状态空间或混合观测模型。

**G1-R 已解决。** 传播递推、Hard/Soft/Set 决策、正常风险和真实 MSE 评价已经分别存在。

**还缺少。** 缺少真正的耦合定理：定位错误概率如何进入传播误差，传播不确定性如何进入补偿动作，补偿动作如何影响正常与攻击风险。还需要确定统一模型是否增加了新的可观测信息，而不是只把已有公式放进更大的记号系统。

**与现有方法关系。** C 可能吸收 Deghat 的攻击跟踪、Tabatabaei 的重构、Gupta 的多模型条件估计和 Mao 的多模型融合。若没有一个新的端到端保证，很容易成为标准模块拼接。

**可能的中心定理。** 需要一个从事件响应矩阵和风险约束直接推出目标时刻损失上界的端到端递推，并能明确区分定位不可辨识、传播放大和动作误修正三种风险来源。

**实验假设。** 在同一 Seed 配对条件下，统一模型应能预测事件/年龄分层的零动作率、污染收益和最坏风险排序。

**工作量与停止条件。** 很高。需要重新组织全部模型和大量文献排重，可能还要新增实验。若统一公式只是现有传播递推、联合 Gaussian 和三个动作的拼接，或者不能给出比现有分阶段分析更强的结论，应停止 C。

**判断。** `暂不推荐 / 高风险`。C 适合作为长期框架整理，不适合作为当前有限时间内的首选论文主线。

## 6. 当前最值得保留和继续审查的问题

**推荐给负责人审查的问题（不是立项决定）：**

> 在固定间歇通信的缓存 Replay 模型中，如何根据事件响应矩阵和合法创新窗口，刻画“攻击事件不可唯一归责但目标污染仍可恢复”的条件；当目标污染本身也不可辨识时，如何给出任意在线补偿器的恢复风险下界？

推荐理由：

1. **继承性最强。** 传播矩阵、候选事件、年龄响应、集合有限性条件和 E3 配对结果都已存在；
2. **不依赖当前 Set 胜出。** Hard、Soft、Set 都可作为同一不确定性边界下的决策实例；
3. **能解释失败。** 它可以解释为何 E2 覆盖成功而 Set 仍可能零动作、为何主场景改善不能推出最坏事件优势；
4. **避免伪创新。** 研究重点是可辨识性和不可辨识性下界，而不是把 GLS、Bayes 平均或 Chebyshev 中心重新命名；
5. **实验压力较小。** 第一阶段可只使用已保存矩阵和 E3 结果进行确定性验证，不消耗新的正式 Seed。

**HYPOTHESIS。** 事件间“目标影响响应的分离度”或响应矩阵的条件数，可能比单纯的集合覆盖率更能解释 Set 的零动作率和相对 Hard/Soft 的性能差距。该假设尚未由当前报告直接验证。

**停止条件。** 若完成公式级排重和现有矩阵审查后发现：

- 目标影响等价类的下界已被直接竞争文献完整覆盖；
- 只能得到普通 GLS 的满秩/秩亏条件；
- 不可辨识下界与缓存年龄、通信日程无关；或
- 无法将定理与现有 E3 的事件/年龄差异建立可检验联系，

则 B 也应停止，报告“现有资产不足以形成新增机制”，不转而启动 C。

## 7. 下一阶段任务建议（仅供审批）

本节不是执行授权。若负责人批准继续审查 B，建议按以下顺序：

1. **公式级文献复核。** 只核查 Deghat 2019、Tabatabaei 2025、Gupta 2026、Mao 2026 以及已有直接竞争报告中是否已有同类不可辨识下界；不做大范围文献搜索。
2. **矩阵级只读分析。** 从现有传播矩阵计算事件对之间的目标影响差、创新响应差、核空间和条件数；不生成新随机轨迹。
3. **两点不可辨识反例。** 构造同一合法 (z) 对应两个不同目标影响的最小反例，验证任何 (u(z)) 的最坏残差下界。
4. **可恢复性定理草稿。** 明确事件唯一识别、影响唯一识别和风险可控三者的区别，给出充分条件和必要反例。
5. **最小数值检查。** 只在已有 E2/E3 保存矩阵和结果上检验理论指标与零动作率、MSE 差距的对应关系。

**HYPOTHESIS。** 如果上述理论指标能够解释至少一个 E3 中的稳定现象（例如早期事件 Set 高拒绝、后期事件触发率上升或最坏事件风险差），则 B 具备形成分析型论文主线的可能；否则不应继续增加算法模块。

## 8. 仍然存在的不确定性

**OPEN。**

- 现有直接竞争文献是否已经在别的模型下给出等价的“影响可恢复而事件不可识别”定理，尚未完成本方向的公式级排重；
- E3 的 `ZERO_OR_UNRESOLVED` 是否主要由集合包含零、集合宽度、候选冲突或门限评分造成，当前报告只保存总状态，没有完成逐因素分解；
- 事件响应分离度与真实 MSE 差距之间是否存在稳定相关性，当前没有预注册相关性检验；
- 固定 gap-8、五节点和目标时刻 217 下的结论能否推广到其他通信日程，当前没有证据；
- 当前 Soft 模型是名义 age64 模型，age32/96 属于先验失配压力测试，不能把这些结果包装成任意年龄下的 Bayesian 最优性；
- 正常风险证书是边际期望意义下的保证，不是每一份固定校准集上的条件保证。

## 9. 结论与停止声明

**FACT。** G1-R 已经完成了可复核的传播分析、风险建模、工程运行器、E2 和 E3；E3 的 `NO_GO_PERFORMANCE` 是对冻结 Set 机制相对 Hard/Soft 预注册优势的否定，不是对数据完整性或整个 Replay 研究问题的否定。

**DERIVED。** 现有成果最适合被整理为“固定间歇通信下历史 Replay 污染传播、风险受限补偿与配对评估”的分析型研究材料。若要继续寻找一个科学问题，B 的可恢复性/不可辨识性理论比 A 的新补偿算法和 C 的大一统框架更值得先做公式级可行性审查。

**OPEN。** B 尚未通过文献排重和中心定理可行性审查，因此当前不能称为已批准的新研究方向、不能启动新算法、不能增加 Seed，也不能改写 E3 的 No-Go。

本轮到此停止。旧结果、失败记录、E2/E3 报告和哈希证据均应继续保留。
