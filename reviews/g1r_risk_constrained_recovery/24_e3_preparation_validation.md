# E3 准备验收与 Seed 审计

结论：E2 独立覆盖复核通过；独立 E3 实现和确定性工程验收通过，**可提交负责人审批，尚不可执行正式 E3**。

## 确定性验收

最终记录：[R08 summary.json](results/g1r_e3_preparation_tests_20261116_r08/summary.json) 和 [完整测试日志](results/g1r_e3_preparation_tests_20261116_r08/tests.log.txt)。43 项通过，零失败、零错误；R08 使用最终 R02 碰撞扫描绑定。

测试覆盖在线白名单、12维有限输入、真实状态和 Δ 时刻/符号、三种冻结动作一致性、先落盘后离线评价、零动作分母、手工 MSE 与收益恒等式、整 Seed 重采样、最大事件均值风险、两项 97.5% 下端点、独立向量/频数权重统计复算、不可变结果与摘要、文件/损失损坏、模拟/评价/磁盘故障、中断后跳过已完成 Seed 恢复、无授权拒绝、E2 授权拒绝、E3 绑定变化失效。

额外使用同一个 Seed 0 已生成 context 检查 24 个 Replay 场景，核验共享真状态、健康状态、噪声与发送日程摘要，以及各来源和缓存替换时刻。人工端到端批处理使用手工向量和非研究标识，不生成这些标识的随机轨迹。有效授权测试只用内存文件 mock；没有写入有效 E3 JSON。

测试进程在数据生成器边界拦截所有非零 Seed，在 RNG 边界禁止 400 个 E3 轨迹 Seed 与预留 Bootstrap Seed。最终记录 `generated_trajectory_seeds=[0]`、正式轨迹数 0、正式 E3 执行 false。原仿真器自身调用的固定随机辅助标识不属于新的研究轨迹，均记录在 RNG 调用表。

历史工程失败完整保留：[R01](results/g1r_e3_preparation_tests_20261116_r01/summary.json) 中 32 项有 3 个错误，均来自新统计代码对二维主场景数组多写一维索引。修复后 R02 的39项、R03/R04的40项、R05/R06/R07的42项均通过。不存在用正式样本调整算法或门限的情形。另一个扫描器首轮环境错误为 Windows 默认 GBK 解析 UTF-8 路径；显式使用 UTF-8 后完成扫描。两者均为工程问题，不是算法性能负结果，也不覆盖旧实验。

## Seed 碰撞审计

[R01 扫描汇总](results/g1r_e3_seed_audit_20261116_r01/summary.json)及[文件摘要目录](results/g1r_e3_seed_audit_20261116_r01/inventory.json)覆盖两个可访问工作区：主工作区与隔离工作区，含 tracked/untracked/ignored 结果、旧 Run、v1、Debug、归档、NPZ/NPY 数组以及所有可达 Git 历史 blob。

R01 统计：29,515 个工作区文件、2,567 个数组容器、47 个归档、17,429 个 Git blob；401 个预留标识均无消耗记录，碰撞 0、扫描错误 0、未解析项 0。协议/代码/文档中的 Seed 预留声明与真实结果消耗区分记录。目录/归档成员名称中的 Seed 也需检查，收尾 R02 补扫加入该检查；最终 E3 配置绑定 R02 结果。

[R02 最终扫描](results/g1r_e3_seed_audit_20261116_r02/summary.json)覆盖 29,534 个工作区文件、2,567 个数组容器、47 个归档与 17,429 个 Git blob，仍为 0 碰撞、0 未解析、0 错误。

归档内容递归读取，不以超出固定字节上限为由静默跳过；遇到不可解析归档、数组或访问错误即不能通过。外部磁盘、不可访问备份、虚拟环境和 Python 缓存不在研究结果扫描范围，不宣称已覆盖这些位置。

## 冻结资产与执行边界

E3 的配置加载核验 E2 原清单和全部 E2 文件、独立覆盖结果、碰撞扫描、协议、正常校准门限、公共矩阵及冻结源码摘要。环境继续按 Task5/R12 的原规范实时比对 Python/NumPy/SciPy/BLAS，纳入 E3 实验配置绑定。

E2 正式结果、原三算法、B.1适配器、E2统计、`simulation/engine.py` 与 `model.py` 均保持原字节。未重新校准，未增加候选方法、门槛或正式 Seed，未调用正式 E3 入口。新增成果只在本研究目录，主工作区 G5 与 G2 未触碰。

本轮数学一致性检查没有发现尚未修复的符号、分解或整 Seed 统计实现错误；该结论限于列出的测试与审计，不能代替正式 E3 性能结果。最终源文件、依赖、结果和审批绑定的 SHA256 见准备资产清单；收到负责人独立 E3 批准后仍需重新做只读环境/绑定核对，不能复用 E2 回执。
