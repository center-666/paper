# **第二篇论文·阶段四：从攻击检测推进到可认证的污染校正**

我建议这次直接推进两个理论命题，而不是继续设计检测器。

**新的核心发现是：我们可能根本不需要准确定位攻击起点，就能够恢复当前估计状态。** 因为攻击起点的影响会逐渐衰减，但攻击幅值仍可能通过连续载荷被持续辨识。

这使研究问题从“攻击历史识别”转变为“当前污染量的功能辨识与安全校正”。

## **一、先证明一个此前没有充分利用的性质**

阶段三已经得到攻击参数 \\(\vartheta=(k,b)\\) 下的条件观测核：

\\[ \begin{aligned} G\_\vartheta&=s\exp\left[-\frac{(d-r)^2}{2V}\right],\\\ f\_\vartheta(u)&=\phi_S(u-b_t-d)h(u-b_t-r), \end{aligned} \\]

其中 \\(b_t=b\mathbf1\_{\\{t\ge k\\}}\\)，且

\\[ h(v)=1-e^{-Zv^2/2}. \\]

它具有一个很特别的结构：发送载荷密度在

\\[ u=r+b_t \\]

处有零点。

### **1. 不同攻击幅值具有不同的观测分布**

如果两个候选的当前注入幅值不同，即 \\(b_1\ne b_2\\)，那么两个发送密度的零点分别位于：

\\[ u=r+b_1,\qquad u=r+b_2. \\]

高斯密度在有限位置严格为正，所以两个发送密度不可能几乎处处相同。

因此：

\\[ \boxed{ b_1\ne b_2 \Longrightarrow K\_{d_1,b_1}\ne K\_{d_2,b_2}. } \\]

这个结论甚至不要求两个候选具有相同的历史预测偏差 \\(d\\)。

它意味着，在理想的精确连续载荷模型下，历史污染造成的创新均值变化无法完全掩盖当前发送载荷中的攻击幅值差异。

进一步，定义两核的 Hellinger 亲和度：

\\[ \mathcal A(K_1,K_2) = \sqrt{G_1G_2} +\int\_{\mathbb R}\sqrt{f_1(u)f_2(u)}\\,du. \\]

两个核不同，所以：

\\[ \mathcal A(K_1,K_2)<1. \\]

若将 \\(S,r,d,b\\) 限制在已有 Riccati 和偏差递推给出的紧区间内，并要求：

\\[ |b_1-b_2|\ge\eta>0, \\]

则由亲和度的连续性和紧性，可得到统一分离：

\\[ \boxed{ \sup\_{|b_1-b_2|\ge\eta} \mathcal A(K_1,K_2) =a\_\eta<1. } \tag{A} \\]

这是后面证明攻击幅值可被持续识别的重要依据。

但此定理依赖精确中心与连续载荷可见。如果载荷存在舍入或离散码字投影，移动零点的论证必须重做。

## **二、反过来，攻击起点可能无法被精确一致辨识**

考虑两个攻击假设：

\\[ \vartheta_1=(k_1,b),\qquad \vartheta_2=(k_2,b),\quad k_1\<k_2. \\]

两者攻击幅值完全相同，只是开始时间不同。

在 \\(k_2\\) 之后，它们都以同一幅值持续攻击。

设两条条件预测偏差的差为：

\\[ \Delta_t=d_t^{(1)}-d_t^{(2)}. \\]

由现有偏差递推：

\\[ \Delta\_{t+1} = A(1-K\_{\gamma_t})\Delta_t. \\]

对于 S1/U1，已有界保证存在 \\(\rho<1\\)，使得：

\\[ \boxed{ |\Delta\_{k_2+n}|\le\rho^n|\Delta\_{k_2}|. } \tag{B} \\]

也就是说，不同起点造成的当前污染差异会指数衰减。

更重要的是，两个模型在 \\(k_2\\) 之后使用相同的当前攻击幅值 \\(b\\)。它们的联合事件—载荷核都可以视为对高斯创新实施同一个随机选择与平移通道。

利用 KL 的数据处理不等式：

\\[ D\_{\mathrm{KL}}(K_1\Vert K_2) \le \frac{\Delta_t^2}{2S_t}. \\]

若 \\(S_t\ge S\_{\min}>0\\)，则：

\\[ \boxed{ \sum\_{t=k_2}^{\infty} D\_{\mathrm{KL}}(K\_{1,t}\Vert K\_{2,t}) \le \frac{\Delta\_{k_2}^2} {2S\_{\min}(1-\rho^2)}. } \tag{C} \\]

这说明：两个不同起点在后续观测中提供的可区分信息总量是有限的。

加上 \\(k_1\\) 到 \\(k_2-1\\) 之间有限时长的信息，整个无限观测历史的 KL 仍然有限。

因此，对于这两个固定起点假设，不可能保证随着观测时间增加，二元判别的两类错误概率都趋于零。可以利用 Bretagnolle–Huber 型不等式给出严格正的错误概率下界。

**这是一个很值得写进论文的结果：攻击起点可能无法精确恢复，但当前状态污染仍可以越来越准确地校正。**

换句话说：

\\[ \text{攻击历史辨识} \ne \text{当前污染辨识}. \\]

我们应当把第二篇论文的主要目标放在后者，而不是要求检测器同时准确回答“何时攻击、攻击多大、每拍造成多少污染”。

## **三、正式建立全时域污染置信集合**

这是现在最值得落地的理论构件。

令：

\\[ \vartheta=(k,b),\qquad k\ge0,\quad b\in[0,b\_{\max}], \\]

另外允许无攻击假设。

根据阶段三精确条件观测核，可以计算每个假设下的完整历史似然：

\\[ p\_{\vartheta,t} = p\_\vartheta(O\_{0:t}). \\]

用健康历史似然 \\(p\_{0,t}\\) 归一化，定义：

\\[ \Lambda_t(\vartheta) = \frac{p\_{\vartheta,t}}{p\_{0,t}}. \\]

### **定理 1：任意有效预测分布均可构造污染置信序列**

取一个固定的、归一化的序贯预测分布 \\(Q\\)，其历史密度为 \\(q_t\\)，并定义：

\\[ E_t=\frac{q_t}{p\_{0,t}}. \\]

这里有一个重要发现：**参考分布&#x20;**\\(Q\\)**&#x20;不必等于真实攻击分布。**

它可以使用阶段三已经验证的 P1 或 J1 检验过程诱导的合法预测分布，只要每一步确实归一化且整条历史分布一致。

定义：

\\[ \boxed{ C_t^\delta= \left\\{ \vartheta: \Lambda_t(\vartheta)>\delta E_t \right\\}. } \tag{1} \\]

则对任意固定真实参数 \\(\vartheta^\star\\)：

\\[ \boxed{ \Pr\_{\vartheta^\star} \left( \forall t\ge0,\  \vartheta^\star\in C_t^\delta \right) \ge1-\delta. } \tag{2} \\]

**证明：**

在真实假设 \\(\vartheta^\star\\) 下：

\\[ \frac{E_t}{\Lambda_t(\vartheta^\star)} = \frac{q_t}{p\_{\vartheta^\star,t}} \\]

是非负、初值为 1 的似然比鞅。

因此：

\\[ \Pr\_{\vartheta^\star}\left( \sup_t \frac{q_t}{p\_{\vartheta^\star,t}} \ge\frac1\delta \right) \le\delta. \\]

其补事件正好对应真实参数始终保留在 \\(C_t^\delta\\) 内。证毕。

这条结论有一个很有用的工程性质：即使真实攻击幅值不在 P1/J1 的候选网格中，覆盖证明仍成立，因为真实参数使用的是分母的精确似然，而不是将真实参数强制投影到候选网格。

但是，**覆盖有效不代表集合收缩速度有保证**。对于网格外幅值，仍需另行证明认证效率。

### **由参数集合转换为当前污染下界**

令：

\\[ \theta_t(\vartheta) = bH\_{k,t}^{+}. \\]

构造：

\\[ \boxed{ L_t= \max\left\\{ 0,\ \inf\_{\vartheta\in C_t^\delta} \theta_t(\vartheta) \right\\}. } \tag{3} \\]

若置信集合为空或数值计算无法认证，则规定 \\(L_t=0\\)。

这就得到：

\\[ \boxed{ \Pr\_{\vartheta^\star} \left( \forall t,\quad 0\le L_t\le\theta_t^\star \right) \ge1-\delta. } \tag{4} \\]

这是真正可以用于恢复的统计证书。

## **四、一个必须修正的评价指标：认证正值不等于有用恢复**

上一轮提出了“首次污染下界大于零”的认证时间。但现在可以进一步看出，单纯要求：

\\[ L_t>0 \\]

可能没有多少工程意义。

原因是：当 \\(Q\\) 就取自阶段三的检测预测分布，并设 \\(\delta=\alpha\\) 时，检测器超过阈值意味着：

\\[ E_t>\frac1\delta. \\]

此时健康假设的似然比为 1，因此它被排除：

\\[ 1<\delta E_t. \\]

同样，任何在已观测历史中尚未造成实际污染的假设，其历史似然也等于健康似然，因而被排除。

在固定有限时刻、参数紧集和似然连续等条件下，如果置信集合非空，严格越阈通常也意味着污染下界严格大于零。

换句话说，**检测报警与出现一个极小的正污染证书，可能几乎发生在同一时刻。**

但此时：

\\[ L_t=10^{-6} \\]

也可能满足数学意义上的正值认证，却只有：

\\[ L_t^2=10^{-12} \\]

的条件风险改善保证。

所以不能把这当成恢复成功。

我建议定义一个真正有工程含义的指标：

\\[ \boxed{ \tau\_{\mathrm{safe}}(g) = \inf\left\\{ t:L_t^2\ge g \right\\}. } \tag{5} \\]

其中 \\(g>0\\) 是预先指定的最小单拍风险改善水平。

它与普通检测时间不同：

\\[ \tau\_{\mathrm{detect}} \le \tau\_{\mathrm{safe}}(g) \\]

在采用相同参考分布、相同阈值且 \\(g>0\\) 的设置下成立。

**真正需要缩短的是&#x20;**\\(\tau\_{\mathrm{safe}}(g)\\)**，而不只是检测延迟。**

这也解释了为什么阶段三 99.9% 的检测率，还不足以宣布恢复问题已经解决。

## **五、进一步证明：污染置信集合为何有希望及时收缩？**

我建议利用刚才发现的“幅值可辨识、起点影响遗忘”性质，而不是直接对整个参数向量要求一致估计。

### **定理 2：有限幅值字典下的污染功能收缩**

先考虑一个可严格分析的模型：

- 真实持续攻击幅值 \\(b^\star>0\\) 属于有限候选字典；
- 真实攻击起点 \\(k^\star\\) 固定；
- 参考分布 \\(Q\\) 使用**精确物理候选似然的混合**，且对真实 \\((k^\star,b^\star)\\) 赋予正权重 \\(\pi\_\star\\)；
- 协方差、相位残差和候选偏差具有阶段三已证明的紧集界；
- 不同幅值之间具有正间隔。

注意，这里使用精确候选混合，是为了证明集合收缩速度。P1/J1 的 warm 近似可以保证置信覆盖，但不能直接继承这一收缩证明。

由式(A)，任何与真实当前注入幅值相隔至少 \\(\eta\\) 的假设，其逐拍 Hellinger 亲和度统一不超过：

\\[ a\_\eta<1. \\]

对于一个错误候选 \\(\vartheta'\\)，若它在 \\(n\\) 个观测时刻持续与真实当前注入幅值分离，则：

\\[ \mathbb E\_{\vartheta^\star} \sqrt{ \frac{p\_{\vartheta',t}} {p\_{\vartheta^\star,t}} } \le a\_\eta^n. \\]

由于精确混合参考分布满足：

\\[ q_t\ge\pi\_\star p\_{\vartheta^\star,t}, \\]

错误候选仍然留在置信集合的必要条件是：

\\[ p\_{\vartheta',t}> \delta\pi\_\star p\_{\vartheta^\star,t}. \\]

使用 Markov 不等式：

\\[ \boxed{ \Pr\_{\vartheta^\star} \left( \vartheta'\in C_t^\delta \right) \le \frac{a\_\eta^n} {\sqrt{\delta\pi\_\star}}. } \tag{6} \\]

这条不等式将不同攻击幅值的排除概率与累计观测时间联系了起来。

### **对不同攻击起点怎么办？**

把候选分成两类。

**第一类：很早就开始的候选。**

对于与真实幅值相同、并且至少在最近 \\(L\\) 拍内都已处于攻击状态的候选，由偏差收缩性质：

\\[ \left| \theta_t(k,b^\star) - \theta_t(k^\star,b^\star) \right| \le B\_{\max}\rho^L. \\]

即使我们无法排除这些起点，也不严重影响当前污染的估计。

**第二类：最近才开始的候选。**

如果候选直到最近 \\(L\\) 拍才开始攻击，而真实攻击已经持续很久，那么在这段较早的攻击期内：

- 真实模型具有正向发送后注入；
- 晚起点候选仍处于健康模式。

它们的当前载荷核可以利用式(A)区分，因而这类错误候选的保留概率会随此前的攻击持续时间指数下降。

因此可以形成这样的结论：

\\[ \boxed{ \Pr\_{\vartheta^\star} \left( \theta_t^\star-B\_{\max}\rho^L \le L_t\le\theta_t^\star \right) \ge 1-\delta-\varepsilon\_{t,L}. } \tag{7} \\]

其中 \\(\varepsilon\_{t,L}\\) 是通过对错误幅值候选和过晚起点候选使用式(6)及并合界得到的显式排除失败概率。

对于有限幅值字典，它具有如下类型的上界：

\\[ \varepsilon\_{t,L} \le C(t+1) \left[ a\_\eta^{\\,t-k^\star+1} + a_0^{\\,t-k^\star-L} \right], \\]

其中 \\(a_0<1\\) 是真实正幅值与尚未开始攻击的候选之间的统一亲和度上界，\\(C\\) 包含字典大小、起点权重和置信水平。

该式要求 \\(t\ge k^\star+L\\)；它仍是理论候选界，需要在正式证明中精确处理末端索引、候选个数及未启动起点的共同尾质量。

若选择 \\(L\to\infty\\)，且 \\(L=o(t-k^\star)\\)，则：

\\[ B\_{\max}\rho^L\to0, \qquad \varepsilon\_{t,L}\to0. \\]

于是，除去预先分配的置信失效概率 \\(\delta\\)，当前污染下界可以逼近真实污染量。

这意味着我们有希望证明：

**即使攻击起点本身不能被一致精确辨识，当前污染量仍具有可认证的渐近精度。**

这比单纯证明检测器会报警更接近第二篇论文的真正理论贡献。

## **六、从污染下界得到真正的恢复风险定理**

现在我们不需要再另设一个恢复滤波器。直接在原 monitor 旁边建立一条**输出校正支路**：

\\[ \boxed{ m_t^r=m_t^a-L_t. } \tag{8} \\]

注意：校正后的 \\(m_t^r\\) 暂时只作为输出，**不能立刻反馈给下一拍的事件触发器或量化中心**。

否则原来已经证明的条件观测核会改变，置信序列及风险保证都需要重新推导。

### **定理 3：污染下界校正的最坏情况风险改善**

给定合法接收历史 \\(\mathcal I_t\\)，原 monitor 的条件估计风险为：

\\[ R_t^a=P_t+(\theta_t^\star)^2. \\]

实施任意非负校正量 \\(c_t\\) 后：

\\[ R_t^r=P_t+(\theta_t^\star-c_t)^2. \\]

两者差为：

\\[ \Delta R_t=2\theta_t^\star c_t-c_t^2. \\]

如果污染置信集合给出：

\\[ \theta_t^\star\in[L_t,U_t], \\]

那么，在所有与该集合相容的真实污染值中，校正量 \\(c\ge0\\) 能保证的最小风险改善是：

\\[ \inf\_{\theta\in[L_t,U_t]} (2\theta c-c^2) = 2L_tc-c^2. \\]

对校正量优化：

\\[ \max\_{c\ge0}(2L_tc-c^2). \\]

其最优解恰好是：

\\[ \boxed{c_t^\star=L_t.} \\]

于是：

\\[ \boxed{ \inf\_{\theta\in[L_t,U_t]} \Delta R_t=L_t^2. } \tag{9} \\]

这说明，**使用污染下界进行校正，最大化了所有置信集合相容模型中的最坏情况条件风险改善**。

这里需要区分两种优化目标：若要最小化最坏情况绝对平方误差，可能选择区间中点；但若要求相对于原 monitor 的改善具有下界，最优保守选择就是 \\(L_t\\)。

### **从高概率保证进一步得到期望 MSE 条件**

设已知最大污染上界为 \\(B\_{\max}\\)，并强制：

\\[ 0\le L_t\le B\_{\max}. \\]

由全时域置信覆盖：

\\[ \Pr\left( \forall t,\ L_t\le\theta_t^\star \right)\ge1-\delta. \\]

在覆盖成立的路径上：

\\[ \Delta R_t\ge L_t^2. \\]

在覆盖失败时，由 \\(\theta_t^\star\ge0\\) 仍有：

\\[ \Delta R_t\ge-L_t^2\ge-B\_{\max}^2. \\]

因此对固定评价时域 \\(T\\)：

\\[ \boxed{ \mathbb E\sum\_{t=1}^{T} (R_t^a-R_t^r) \ge \mathbb E\sum\_{t=1}^{T}L_t^2 - 2\delta TB\_{\max}^2. } \tag{10} \\]

这比单纯的高概率风险改善更进一步。

它给出期望累计 MSE 真正下降的一个充分条件：

\\[ \boxed{ \mathbb E\sum\_{t=1}^{T}L_t^2 > 2\delta TB\_{\max}^2. } \tag{11} \\]

对 S1/U1，若沿用阶段二的偏差不变区间并规定 \\(b\_{\max}=0.25\\)，则可以使用：

\\[ B\_{\max}^{S1}\approx0.239234, \qquad B\_{\max}^{U1}\approx0.265324. \\]

例如 \\(\delta=0.01\\) 时，式(10)中的保守失效惩罚折合每拍约为：

| 模型 | 每拍风险预算惩罚 \\(2\delta B\_{\max}^2\\) |
| -- | ---------------------------------- |
| S1 | 0.001145                           |
| U1 | 0.001408                           |

这些是由理论上界计算的预算，不是已经测得的恢复收益。

而且，式(10)比较的是**同一受攻击观测历史下，校正支路与原 monitor 的 MSE**，并未证明恢复到健康系统的 MSE 水平。

## **七、如何把理论转化成可计算的算法？**

现在还有一个关键问题：无限多攻击起点、连续攻击幅值的置信集合，能否实际计算？

这里可以利用当前模型的特殊结构。

对于固定起点 \\(k\\)，污染系数 \\(H\_{k,t}^{+}\\) 与攻击幅值 \\(b\\) 无关。

因此：

\\[ \theta_t(k,b)=bH\_{k,t}^{+}. \\]

假设我们希望认证：

\\[ L_t\ge z \\]

其中 \\(z\ge0\\) 是指定的污染下界。

只需要检查所有满足：

\\[ bH\_{k,t}^{+}\le z \\]

的候选参数是否已经被排除。

定义：

\\[ \mathcal P_t(z) = \sup\_{\substack{k,b\\\bH\_{k,t}^{+}\le z}} \log\Lambda_t(k,b). \\]

如果：

\\[ \boxed{ \mathcal P_t(z)<\log(\delta E_t), } \tag{12} \\]

则所有污染不超过 \\(z\\) 的候选都不属于置信集合，从而认证：

\\[ L_t\ge z. \\]

### **关键计算简化**

对每个给定起点 \\(k\\)，约束变成：

\\[ 0\le b\le \min\left\\{ b\_{\max}, \frac{z}{H\_{k,t}^{+}} \right\\}, \\]

当 \\(H\_{k,t}^{+}=0\\) 时单独处理。

因此，原来的二维联合搜索可以分解为：

**逐个起点枚举 + 一维幅值似然优化。**

可以采用区间分支定界，并通过二分搜索 \\(z\\) 来求污染下界。

由于发送载荷密度存在移动零点，似然函数未必处处具有良好的凸性或凹性；不能依靠粗网格扫描就声称获得严格认证下界。必须对幅值区间的最大似然给出可靠上包络。

如果优化器无法认证某个区间，就保留该候选，不允许为了提高下界而擅自删除它。

现在已经不需要再盲目扩大轨迹数量。下一步应该针对现有模型完成四项确定性工作。

我建议在以上理论证明完成后，才用阶段三冻结的数据或新的预注册验证，回答三个工程问题：认证下界是否显著大于零、达到指定 \\(g\\) 的时间是否可接受，以及真实累计 MSE 是否下降。

**目前的阶段性结论：** 我们已经有一条比“检测器＋回滚”更清晰的理论路线——**攻击起点遗忘、污染功能认证、风险约束校正**。本轮给出了候选定理和主要证明路径，但尚未完成无限参数集合的认证计算，也尚未获得校正后的 MSE 实验结果，因此不能宣布恢复算法已经成功。

这条路线值得继续深入，而且应当优先证明，而不是马上写论文。
