# **第二篇论文阶段四：攻击起点遗忘与可认证恢复**

这次把研究推进到一个更具体的数学结果：**不要求准确找回攻击起点，而是证明当前污染量能够被逐步认证，并进一步建立期望 MSE 严格下降的充分条件。**

我沿用 GitHub `e1c55269` 中已经核实的精确中心可见、连续载荷可见模型。本轮先做理论推导，不新增性能仿真，也不修改正式稿。

## **一、先建立攻击历史与当前污染的精确关系**

令 \\(k\\) 为持续同方向攻击的起点，\\(b>0\\) 为攻击幅值。定义当前后验污染量

\\[ \theta_t(k,b)=m_t^a-\mu_t^{k,b}, \\]

其中 \\(\mu_t^{k,b}\\) 是在参数 \\((k,b)\\) 正确时、给定合法接收记录的条件状态均值。

根据阶段三的精确递推：

\\[ \theta_t(k,b)=bH\_{k,t}, \\]

\\[ H\_{k,t} = a_tH\_{k,t-1} +\gamma_tK\_{1,t}\mathbf1\_{\\{t\ge k\\}}, \qquad a_t=A(1-K\_{\gamma_t,t}). \\]

攻击开始前 \\(H\_{k,t}=0\\)。

展开递推可以得到：

\\[ \boxed{ H\_{k,t} = \sum\_{j=k}^{t} \gamma_jK\_{1,j} \prod\_{s=j+1}^{t}a_s. } \tag{1} \\]

这条公式有两个重要性质。

**性质一：对于固定攻击幅值，越早开始的攻击，当前污染不会越小。**

因为 S1/U1 模型下所有系数非负：

\\[ k_1\<k_2 \Longrightarrow H\_{k_1,t}\ge H\_{k_2,t}. \\]

**性质二：较早的攻击起点之间，其当前污染差异会指数衰减。**

阶段二已证明存在统一收缩系数 \\(0<\rho<1\\)，使 \\(a_t\le\rho\\)。假设两个起点均不晚于 \\(t-L\\)，则

\\[ \boxed{ |\theta_t(k_1,b)-\theta_t(k_2,b)| \le bc_B\rho^L, } \tag{2} \\]

其中 \\(c_B\\) 是已证明的单位幅值污染不变区间上界。

两模型的已有常数为：

| 模型 | \\(\rho\\) | \\(c_B\\) |
| -- | ---------- | --------- |
| S1 | 0.724253   | 0.956938  |
| U1 | 0.868202   | 1.061296  |

这意味着，对于已经持续足够长时间的攻击，我们可以容忍攻击起点存在误差，而不一定损失当前状态校正的精度。

这也明确了下一条主线：

\\[ \boxed{ \text{不必精确辨识攻击历史} \quad\Longrightarrow\quad \text{仍可能精确恢复当前污染}. } \\]

但仅有式(2)还不够。它没有告诉我们怎样从接收记录中排除错误攻击幅值，以及那些实际上刚刚开始攻击的候选解释。

下面给出这个缺失的统计环节。

## **二、核心新结果：当前污染量可以在不识别准确起点的情况下收缩**

下面给出一个可写成论文定理的有限候选版本。它比上一轮的定性讨论更进一步，因为能够给出明确的概率误差项。

### **定理 1：当前污染置信集合的有限时间收缩**

先假设真实攻击幅值属于预先规定的有限集合：

\\[ \mathcal B=\\{b_1,\ldots,b_J\\}, \qquad b_j>0. \\]

真实参数为 \\((k\_\star,b\_\star)\\)。

我们使用阶段三的**精确物理候选似然** \\(p\_{k,b,t}\\)，构造固定混合参考分布：

\\[ Q_t= \pi_0p\_{\varnothing,t} + (1-\pi_0) \sum\_{k=0}^{\infty}w_k \sum\_{b\in\mathcal B}\pi_b p\_{k,b,t}. \\]

这里 \\(p\_{\varnothing,t}\\) 是永久无攻击模型的历史密度，各权重非负且总和为 1。

记真实参数在参考混合中的权重为：

\\[ \pi\_\star=(1-\pi_0)w\_{k\_\star}\pi\_{b\_\star}>0. \\]

构造置信集合：

\\[ C_t^\delta= \left\\{ (k,b): p\_{k,b,t}>\delta Q_t \right\\}, \\]

并包含无攻击候选。定义当前污染下界：

\\[ L_t=\inf\_{\vartheta\in C_t^\delta}\theta_t(\vartheta), \\]

空集合时取 \\(L_t=0\\)。

由似然比鞅可得：

\\[ \boxed{ \Pr\_{k\_\star,b\_\star} \left( \forall t,\ 0\le L_t\le\theta_t^\star \right)\ge1-\delta. } \tag{3} \\]

这条覆盖结论适用于任意时刻，包括检测器根据数据选择的报警时刻。

### **新增的收缩结论**

令：

\\[ n=t-k\_\star+1 \\]

表示攻击已持续的观测拍数。

由于精确连续发送密度在 \\(u=r+b\\) 处有与攻击幅值对应的零点，两个不同的当前注入幅值对应不同观测核。

在阶段三已有的参数紧集上，定义：

\\[ \eta= \min\left\\{ b\_\star,\ \min\_{b_j\ne b\_\star}|b_j-b\_\star| \right\\}>0. \\]

于是存在 \\(a\_\eta<1\\)，使所有当前注入幅值至少相差 \\(\eta\\) 的候选核满足：

\\[ \int\sqrt{dK_1\\,dK_2}\le a\_\eta. \\]

现在将错误候选分为两类。

- **错误幅值候选：** 从真实攻击起点到当前时刻，每拍的当前注入幅值都与真实幅值至少相差 \\(\eta\\)。
- **正确幅值但过晚起点候选：** 若 \\(k'>t-L\\)，则它在真实攻击开始后的至少 \\(n-L\\) 拍内仍宣称没有攻击。

由逐拍条件 Hellinger 亲和度的乘积界：

\\[ \mathbb E\_{\star} \sqrt{ \frac{p\_{\vartheta',t}}{p\_{\star,t}} } \le a\_\eta^m, \\]

其中 \\(m\\) 是两候选当前注入幅值保持分离的拍数。

另一方面，如果错误候选仍保留在置信集合中：

\\[ p\_{\vartheta',t}>\delta Q_t \ge\delta\pi\_\star p\_{\star,t}. \\]

对平方根似然比使用 Markov 不等式，得到：

\\[ \Pr\_\star(\vartheta'\in C_t^\delta) \le \frac{a\_\eta^m}{\sqrt{\delta\pi\_\star}}. \\]

再对错误幅值与过晚起点候选使用并合界，得到一个保守的显式界：

\\[ \boxed{ \varepsilon\_{t,L} \le \frac{ (J-1)(t+1)a\_\eta^n + (L+2)a\_\eta^{n-L} }{ \sqrt{\delta\pi\_\star} }. } \tag{4} \\]

这里把所有尚未开始攻击的候选合并成一个共同的健康历史似然类；否则直接对无限多未来起点求和会错误地得到发散上界。

当 \\(n>L\\) 时，在置信覆盖且错误候选排除成功的事件上，集合中剩余的攻击解释具有相同幅值 \\(b\_\star\\)，且起点均不晚于 \\(t-L\\)。

再利用式(2)，得到：

\\[ \boxed{ \Pr\_\star\left( 0\le\theta_t^\star-L_t \le b\_\star c_B\rho^L \right) \ge 1-\delta-\min\\{1,\varepsilon\_{t,L}\\}. } \tag{5} \\]

这就是本轮最重要的理论推进。

**它证明的是当前污染量的功能收缩，而不是攻击起点的一致估计。**

对于固定 \\(L\\)，式(4)随攻击持续时间增长趋于零；进一步让 \\(L\\) 缓慢增长，可以使式(5)中的污染估计误差也趋于零，剩余的是预设的覆盖失效概率 \\(\delta\\)。

需要明确：式(4)目前是有限幅值字典的结论。连续攻击幅值区间不能直接用有限候选个数 \\(J\\) 替代，必须另证连续参数下的统一似然控制。

## **三、继续推进到期望 MSE 的严格改善**

这一步是对上一轮风险定理的加强。

采用保守校正：

\\[ m_t^r=m_t^a-L_t. \\]

监测支路、事件触发中心和下一拍反馈保持原样，校正仅作用于输出。

令：

\\[ R_t^a=\mathbb E[(x_t-m_t^a)^2\mid\mathcal I_t], \\]

\\[ R_t^r=\mathbb E[(x_t-m_t^r)^2\mid\mathcal I_t]. \\]

则有精确恒等式：

\\[ R_t^a-R_t^r = 2\theta_t^\star L_t-L_t^2. \\]

置信覆盖时 \\(0\le L_t\le\theta_t^\star\\)，因此：

\\[ R_t^a-R_t^r\ge L_t^2. \\]

但这一保证有 \\(\delta\\) 的覆盖失效概率，需要将失效风险计入无条件 MSE。

### **定理 2：最终能够获得正的期望 MSE 收益**

设所有允许攻击幅值满足 \\(b\le b\_{\max}\\)，由污染不变区间定义：

\\[ B\_{\max}=b\_{\max}c_B. \\]

强制实施的校正量满足 \\(0\le L_t\le B\_{\max}\\)。

则：

\\[ \boxed{ \mathbb E(R_t^a-R_t^r) \ge \mathbb E L_t^2-2\delta B\_{\max}^2. } \tag{6} \\]

接下来利用持续攻击的一个特性。

每次真正发送时，当前污染满足：

\\[ \gamma_t=1 \Longrightarrow \theta_t^\star\ge b\_\star k\_-, \\]

其中：

\\[ k\_-=\frac{p\_-}{p\_-+R}>0. \\]

而阶段二已经证明条件发送概率具有统一下界：

\\[ \Pr(\gamma_t=1\mid\mathcal I_t^-) \ge p_s>0. \\]

选择整数 \\(L\\)，使：

\\[ c_B\rho^L\le\frac{k\_-}{2}. \\]

那么由式(5)，在置信覆盖和收缩成功的事件上，只要本拍发生真实发送，就有：

\\[ L_t\ge\frac{b\_\star k\_-}{2}. \\]

所以：

\\[ \mathbb E L_t^2 \ge \left(\frac{b\_\star k\_-}{2}\right)^2 \left[ p_s-\delta-\varepsilon\_{t,L} \right]\_+. \\]

代回式(6)：

\\[ \boxed{ \begin{aligned} \mathbb E(R_t^a-R_t^r) \ge{}& \left(\frac{b\_\star k\_-}{2}\right)^2 [p_s-\delta-\varepsilon\_{t,L}]\_+\\\ &-2\delta B\_{\max}^2. \end{aligned} } \tag{7} \\]

这已经是一个**有限时域、含覆盖失败预算和候选排除误差的期望 MSE 改善下界**。

它不是仿真观察，而是由前面的定理推出的数学结论。

### **什么时候能够保证严格改善？**

令：

\\[ v\_\star= \left(\frac{b\_\star k\_-}{2}\right)^2. \\]

若：

\\[ \boxed{ \delta< \frac{v\_\star p_s} {v\_\star+2B\_{\max}^2}, } \tag{8} \\]

则由于 \\(\varepsilon\_{t,L}\to0\\)，存在一个有限但可能很大的时间 \\(T\_\star\\)，使所有 \\(t\ge T\_\star\\) 满足：

\\[ \boxed{ \mathbb E(R_t^r)<\mathbb E(R_t^a). } \tag{9} \\]

也就是说：

**在规定的有限幅值字典、持续同方向攻击和精确观测模型下，我们可以证明恢复输出最终具有严格更低的无条件 MSE。**

这比此前的“报警前偏差能量有界”更进一步，因为式(9)直接比较了实施校正前后的真实均方误差。

不过，该结论是最终正收益的存在性与充分条件，不是 512 拍内恢复成功的保证。

## **四、把定理代入 S1/U1，得到一个重要的设计结论**

使用上一阶段已经证明的常数，暂取 \\(b\_{\max}=0.25\\)。

满足：

\\[ c_B\rho^L\le k\_-/2 \\]

的最小整数 \\(L\\) 为：

| 理论量                  | S1       | U1       |
| -------------------- | -------- | -------- |
| 遗忘长度 \\(L\\)         | 6 拍      | 12 拍     |
| \\(k\_-\\)           | 0.316334 | 0.409183 |
| 发送概率下界 \\(p_s\\)     | 0.205719 | 0.227800 |
| 最大污染 \\(B\_{\max}\\) | 0.239234 | 0.265324 |

这说明两个系统的起点影响都有相当明确的遗忘速度。

但要特别注意：**6 拍和 12 拍只控制历史起点对当前污染的影响，不是认证所需的检测时间。** 要把错误候选排除，还必须付出式(4)中的统计证据积累时间。

进一步计算式(8)允许的置信失效预算上限：

| 真实攻击幅值       | S1 的 \\(\delta\\) 上限 | U1 的 \\(\delta\\) 上限 |
| ------------ | -------------------- | -------------------- |
| \\(b=0.05\\) | 0.0112%              | 0.0169%              |
| \\(b=0.10\\) | 0.0449%              | 0.0675%              |
| \\(b=0.25\\) | 0.2772%              | 0.4156%              |

这给出了一个很有意义的理论结论：

**检测的 1% 误报预算，不应直接等同于恢复校正的置信失效预算。**

对强攻击，选择恢复置信失效水平 \\(\delta=0.1\\%\\) 可以满足上述保守充分条件；但对弱攻击 \\(b=0.05\\)，这一水平尚不足以通过当前的期望 MSE 证明。

这不意味着弱攻击无法恢复，而是说明要证明弱攻击下的严格收益，需要更高置信度、更紧的风险界或额外观测信息。

## **五、算法层面可以直接形成“污染证书”，不必先估计整个参数向量**

为避免对所有参数反复生成完整置信集合，可以直接认证污染是否超过某个指定值 \\(z\\)。

定义污染不超过 \\(z\\) 的复合假设：

\\[ \Theta_t(z)= \\{\vartheta:\theta_t(\vartheta)\le z\\}. \\]

计算其最大历史似然：

\\[ M_t(z)= \sup\_{\vartheta\in\Theta_t(z)} p\_{\vartheta,t}. \\]

如果：

\\[ \boxed{ M_t(z)<\delta Q_t, } \tag{10} \\]

则所有当前污染不超过 \\(z\\) 的参数都被置信集合排除，因此可以认证：

\\[ L_t\ge z. \\]

这提供了一种直接计算下界的方式。

而且：

\\[ \theta_t(k,b)=bH\_{k,t}, \\]

所以对固定 \\(k\\)，只需要求解带约束的一维幅值最大似然：

\\[ \sup\_{\substack{0\le b\le b\_{\max}\\\bH\_{k,t}\le z}} p\_{k,b,t}. \\]

然后在不同起点之间取最大值。

这不是简单网格扫描。若采用连续幅值搜索，必须证明数值优化得到了可靠的最大似然上界；否则可能错误地排除真实参数，破坏风险保证。

另外，式(10)里的比值不是一个可以随意当作 e-process 的统计量，因为复合约束集合 \\(\Theta_t(z)\\) 随观测历史变化。它的全时域有效性来自已经证明的参数置信集合，而不是声称最大似然分母本身构成鞅。

## **七、我的阶段性研究判断**

这次已经得到三个实质性理论结果：

1. 不同攻击起点的当前污染具有明确的指数遗忘性质。
2. 在有限幅值字典下，可以通过精确似然和 Hellinger 分离建立污染置信下界的有限时间收缩保证。
3. 在规定置信预算下，保守校正能够最终获得严格更低的期望 MSE，而不只是减少报警前暴露。

但我仍然不会把它称作一篇已经完成理论证明的论文。尤其是式(4)–(9)这条新证明链，还需要独立逐式复核、数值认证 \\(a\_\eta\\) 的实际大小，并检验保证在 512–2048 拍内是否具有工程意义。

**下一阶段最值得攻克的不是再增加攻击场景，而是连续攻击幅值下的污染功能置信集合收缩。**

如果能够在 \\(b\in[b\_{\min},b\_{\max}]\\) 上建立可计算的统一认证时间界，随后证明恢复后的实际累计 MSE 降低，那么第二篇论文就有望形成相对完整的理论闭环：

\\[ \boxed{ \text{可信记录} \rightarrow \text{参数证据} \rightarrow \text{污染功能认证} \rightarrow \text{保守校正} \rightarrow \text{MSE 改善保证} } \\]

这才应该是下一轮的主攻问题，而不是继续优化 J1 的检测率。
