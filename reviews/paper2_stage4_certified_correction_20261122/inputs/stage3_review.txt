## **二、我建议重新定义下一阶段的核心问题**

不再研究：

> 如何设计更复杂的联合序贯检测器？

而研究：

> 在持续发送后 FDI 攻击下，能否通过已有通信记录，在线构造攻击污染幅值的可信集合，并据此实施不会任意放大条件估计风险的状态校正？

这个问题有三个优点。

第一，它直接利用阶段三已经得到的精确联合概率模型，不需要更换物理系统或攻击权限。

第二，它可以避开上一轮已经失败的过期检查点回滚机制。

第三，它有机会形成一个可证明的**检测—污染认证—校正—MSE 降损**闭环，而不只是再增加一个检测统计量。

## **三、从原有偏差动力学出发，可以直接构造校正器**

这部分不需要重新发明模型。阶段三已经推导了持续正向攻击下的精确偏差递推。

记真实攻击参数为

\\[ \vartheta=(k,b), \\]

其中 \\(k\\) 是攻击起点，\\(b>0\\) 是持续攻击幅值。

令 \\(m_t^a\\) 是当前被攻击的 monitor 估计，\\(\mu_t^\vartheta\\) 是在真实参数 \\(\vartheta\\) 下、给定接收记录的状态条件均值。

定义污染量：

\\[ \theta_t=m_t^a-\mu_t^\vartheta. \\]

按照上一轮的符号，\\(\theta_t=-D_t\\)。

### **1. 污染系数完全由可信事件历史决定**

定义攻击影响系数 \\(H\_{k,t}\\)，其先验递推为：

\\[ H\_{k,t+1}^{-} = A\left[ (1-K\_{\gamma_t})H\_{k,t}^{-} + \gamma_tK_1\mathbf1\_{\\{t\ge k\\}} \right]. \\]

相应的后验系数为：

\\[ H\_{k,t}^{+} = (1-K\_{\gamma_t})H\_{k,t}^{-} + \gamma_tK_1\mathbf1\_{\\{t\ge k\\}}. \\]

在攻击开始前取零初值。

于是有精确关系：

\\[ \boxed{ \theta_t=bH\_{k,t}^{+}. } \\]

这条关系非常重要，因为 \\(H\_{k,t}^{+}\\) 只需要：

- 可信发送/静默事件；
- 已知系统参数；
- 实际滤波增益；
- 假设的攻击起点 \\(k\\)。

它不需要真实状态，也不需要攻击前的原始载荷副本。

因此，只要能够识别或约束 \\(k,b\\)，就能够得到当前状态污染量的估计或上下界。

### **2. 不需要回滚，可以直接校正 monitor**

考虑恢复输出：

\\[ \boxed{ m_t^r=m_t^a-\widehat\theta_t. } \\]

这里 \\(\widehat\theta_t\\) 是从合法接收记录得到的污染估计。

如果参数完全正确：

\\[ \widehat\theta_t=bH\_{k,t}^{+}, \\]

则：

\\[ m_t^r=\mu_t^\vartheta. \\]

也就是说，在当前理想模型下，精确攻击污染校正可以恢复到给定接收记录及真实攻击参数的条件均值。

这与旧的检查点回滚不同。

它不需要回到几十或几百拍之前，也不会因为开环预测时间过长而直接产生 \\(A^{2\ell}\\) 型检查点误差放大。

当然，实际问题在于 \\(k,b\\) 未知。不能把这一理想结果直接当成可实现算法的恢复保证。

## **四、进一步推导：什么条件下，校正一定比不校正好？**

我认为这是下一阶段最适合形成正式命题的地方。

令：

\\[ \mu_t^\vartheta= \mathbb E\_\vartheta[x_t\mid\mathcal I_t], \\]

\\[ P_t^\vartheta= \operatorname{Var}\_\vartheta(x_t\mid\mathcal I_t), \\]

其中 \\(\mathcal I_t\\) 是接收端合法观测历史。

由于：

\\[ m_t^a=\mu_t^\vartheta+\theta_t, \\]

所以不进行恢复时的条件 MSE 是：

\\[ R_t^a=P_t^\vartheta+\theta_t^2. \\]

校正后的条件 MSE 是：

\\[ R_t^r = P_t^\vartheta+ (\theta_t-\widehat\theta_t)^2. \\]

两者相减：

\\[ \boxed{ R_t^a-R_t^r = 2\theta_t\widehat\theta_t- \widehat\theta_t^2. } \tag{1} \\]

因此，只要：

\\[ \boxed{ 0<\widehat\theta_t<2\theta_t, } \\]

校正就能严格降低条件 MSE。

这给出一个清楚的理论目标：我们不一定需要非常精准地估计攻击幅值，只需要给出一个有可靠依据、方向正确且不过度的校正量。

### **新的定理候选：基于污染下界的风险认证**

假设在线算法能够给出：

\\[ 0\le\underline\theta_t\le\theta_t. \\]

直接选择：

\\[ \widehat\theta_t=\underline\theta_t. \\]

由式(1)：

\\[ R_t^a-R_t^r = 2\theta_t\underline\theta_t- \underline\theta_t^2. \\]

因此：

\\[ \boxed{ R_t^a-R_t^r \ge\underline\theta_t^2. } \tag{2} \\]

这个结论有两个值得关注的性质。

第一，即使污染下界很保守，只要它严格大于零，便能保证相应的条件风险改善。

第二，风险改善不依赖于两个估计支路之间未知的交叉协方差，因为我们校正的是同一条 monitor 的条件偏差，而不是把 monitor 与过期检查点任意融合。

但最关键的问题变成了：

**怎样在不知道真实攻击起点和幅值的情况下，合法地产生具有统计覆盖保证的&#x20;**\\(\underline\theta_t\\)**？**

这就是下一步需要解决的数学问题。

## **五、把阶段三的联合似然用于攻击污染置信集合**

我建议使用一条与之前检测器不同的理论路线：

**不只是用似然比拒绝健康假设，而是反演整个攻击参数集合，获得污染量下界。**

### **1. 构造联合参数集合**

设：

\\[ \Theta= \\{(k,b):k\in\mathbb N_0,\ 0\le b\le b\_{\max}\\} \\]

并包含无攻击模型。

对每个候选 \\(\vartheta=(k,b)\\)，使用阶段三已经建立的精确联合核构造接收记录概率：

\\[ p\_\vartheta(O\_{0:t}). \\]

然后预先选定一个归一化的参考混合分布：

\\[ q(O\_{0:t}) = \int\_\Theta p\_{\vartheta'}(O\_{0:t}) \Pi(d\vartheta'). \\]

定义：

\\[ M_t(\vartheta) = \frac{q(O\_{0:t})} {p\_\vartheta(O\_{0:t})}. \\]

在真实参数为 \\(\vartheta\\) 时，只要各候选条件核精确归一化、具有所需的共同支持：

\\[ \mathbb E\_\vartheta[ M_t(\vartheta)\mid\mathcal I\_{t-1} ] =M\_{t-1}(\vartheta). \\]

所以我们可以得到一个全时域置信集合：

\\[ \boxed{ C_t= \left\\{ \vartheta: M_t(\vartheta)<\frac1{\delta} \right\\}. } \\]

并利用 Ville 不等式证明：

\\[ \boxed{ \Pr\_\vartheta \left( \forall t\ge0,\ \vartheta\in C_t \right) \ge1-\delta. } \tag{3} \\]

这不是普通的固定时刻置信区间，而是能够适应数据依赖停止时间的置信序列。

### **2. 由参数集合投影到污染集合**

既然：

\\[ \theta_t=bH\_{k,t}^{+}, \\]

我们就定义：

\\[ \boxed{ \underline\theta_t= \inf\_{(k,b)\in C_t} bH\_{k,t}^{+}. } \tag{4} \\]

当集合为空或计算未能得到认证下界时，保守地取零，不实施校正。

由式(3)，以至少 \\(1-\delta\\) 的整体概率，有：

\\[ \forall t,\qquad \underline\theta_t\le\theta_t. \\]

再结合污染非负性和式(2)，得到：

\\[ \boxed{ \Pr\_\vartheta \left( \forall t,\ R_t^r\le R_t^a \right) \ge1-\delta. } \tag{5} \\]

这里是一个值得研究的**全时域高概率条件风险保证**，而不是声称每条轨迹都无条件改善。

### **3. 这与原来的恢复研究有何区别？**

| 原恢复方法         | 新理论候选          |
| ------------- | -------------- |
| 检测后立即回滚检查点    | 检测后认证当前污染幅值    |
| 使用检查点年龄判断恢复风险 | 使用污染下界约束校正量    |
| 过期检查点可能放大 MSE | 保守校正量限制过度校正    |
| 固定软融合可能失效     | 从同一估计支路中去除认证偏差 |
| 主要约束报警前偏差能量   | 直接约束校正后的条件 MSE |

这可能成为第二篇论文的核心转变。

不过，需要特别说明：式(3)的置信集合需要每个候选攻击起点和幅值对应的**精确概率模型**。目前阶段三使用的 O(J) warm 近似检测器，并不自动提供这些参数的有效置信区间。

如果直接把 J1 的混合检测分数反演成攻击幅值置信区间，可能得到错误的覆盖保证。

因此我们必须保留精确候选库作为理论基准，再单独研究低复杂度近似怎样保持覆盖性质。

## **六、这条理论路线还必须解决三个难点**

### **难点一：检测到攻击，不等于污染下界大于零**

即使 J1 已经报警，置信集合 \\(C_t\\) 也可能包含健康模型，或者包含一个刚刚开始攻击的参数解释。

这时：

\\[ \underline\theta_t=0. \\]

根据我们的校正规则，系统不会采取恢复动作。

所以新的研究目标不能只是提高检测率，而应增加一个指标：

\\[ T\_{\mathrm{cert}} = \inf\\{t:\underline\theta_t>0\\}. \\]

它表示**首次能够认证当前污染严格为正的时刻**。

这比报警时间更贴近恢复问题。

下一轮需要研究：

\\[ T\_{\mathrm{detect}} \quad\text{与}\quad T\_{\mathrm{cert}} \\]

之间的关系，并确定是否存在一个工程上可接受的认证延迟。

### **难点二：高概率条件风险不等于无条件 MSE 保证**

式(5)是一个高概率结论。置信集合失去覆盖时，过度校正仍可能增加 MSE。

若攻击幅值有已知上界，且污染量和实施校正量均约束在 \\([0,\Theta\_{\max}]\\)，则单拍在覆盖失败时的额外条件风险至多为 \\(\Theta\_{\max}^2\\)。

因此，可推导一个有限时域的期望风险差下界：

\\[ \begin{aligned} \mathbb E\sum\_{t=1}^{T}(R_t^a-R_t^r) \ge{}& \mathbb E\left[ \mathbf1\_{\mathcal C} \sum\_{t=1}^{T}\underline\theta_t^2 \right]\\\ &-\delta T\Theta\_{\max}^2, \end{aligned} \\]

其中 \\(\mathcal C\\) 是置信集合对所有时刻保持覆盖的事件。

这给出了一个可检验的充分条件：**累计认证校正收益必须超过置信失效带来的风险预算。**

如果这个下界始终为负，就不能把高概率安全性包装成期望 MSE 降损保证。

### **难点三：精确参数集合的计算代价**

阶段三的 J1 只需 O(J) 状态，因为它采用共享 warm 候选状态。

但是精确参数集合需要同时考虑不同攻击起点、不同攻击幅值。不同起点的真实污染轨迹通常不同，不能直接共享全部似然。

因此可以研究两层实现：

| 层次   | 方法            | 要求             |
| ---- | ------------- | -------------- |
| 理论基准 | 完整起点—幅值候选库    | 精确置信覆盖和风险认证    |
| 在线近似 | 有限窗口候选＋历史污染包络 | 必须证明近似不会排除真实参数 |

尤其不能仅为降低复杂度，就直接删除较早的攻击起点。删除可能有效的参数会人为抬高污染下界，破坏恢复保证。

这将是一个真正的算法设计问题。

## **八、下一阶段应当交付什么**

我建议冻结 `e1c55269` 作为检测阶段基准，正式开启阶段四理论研究，暂不运行新的大规模性能仿真。

| 任务 | 具体内容           | 验收条件            |
| -- | -------------- | --------------- |
| T1 | 精确起点—幅值似然和污染递推 | 与现有联合核完全一致      |
| T2 | 攻击参数全时域置信集合    | 严格证明覆盖概率        |
| T3 | 污染下界与条件风险定理    | 得到式(2)类型的改善保证   |
| T4 | 认证延迟与检测信息量分析   | 证明何时能出现正污染下界    |
| T5 | 低复杂度认证算法       | 有明确的近似误差或集合包含保证 |
| T6 | 现有补偿/恢复论文排重    | 确定具体增量而不是方法拼接   |

**我的阶段性研究决策**

保留 P1/J1 作为有效检测基线；不继续增加事件混合层数；优先研究污染置信集合与保守校正。

只有当污染下界在实际攻击中能够及时变为正，并且校正后的累计 MSE 确实下降，才进入正式的恢复方法验证阶段。

这样推进还有一个优势：第二篇论文不会因为检测算法已有直接近邻就失去主线。检测提供证据，置信集合负责认证，恢复模块负责降损，三者各有明确的数学角色。

**下一轮最关键的理论命题就是：能否在未知攻击起点与未知幅值下，构造一个可计算、具有全时域覆盖保证，并且足够快收缩的当前污染置信集合。**

如果这条命题成立，而且认证速度足够快，我们就有机会真正闭合第二篇论文此前一直缺失的 MSE 恢复保证；如果认证过慢，也能及时判断这条路线是否值得继续，而不再重复前几轮“理论可行、工程无效”的问题。
