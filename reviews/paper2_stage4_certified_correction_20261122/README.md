# 阶段四：攻击起点遗忘、污染功能认证与输出校正

基准提交e1c55269，日期2026-11-22。按用户三份方案推进理论与确定性计算，**零新增随机性能样本，正式稿未改**。本包限定精确中心可见、可信事件与连续发送载荷、正确S1/U1模型、固定正向持续攻击。

## 主要结果

1. **起点未必可一致识别，污染却可收缩。** 同幅值不同固定起点的全历史KL有统一有限上界，故二元错误和有严格正下界；其当前污染差却按rho指数遗忘。有限反演幅值字典下，精确参考混合给出含候选计数、未启动尾类的显式功能收缩界。
2. **校正证书可覆盖连续幅值。** 任意正规化、序贯一致的Q可作参考分子，但参数分母必须是精确物理似然。反演得到全时域覆盖；污染下界L用于同一monitor输出m−L，在覆盖事件上条件MSE至少改善L²，且期望累计改善至少为EΣL²−2epsilon T Bmax²。
3. **连续幅值的理论收缩有新推进。** 固定可数稠密精确参考、低于半阶的交叉分数矩和连续幅值区间包络，支持污染函数渐近收缩。有限参考下包络可保留覆盖和最终收缩，但收缩常数与长期在线求解效率尚未数值认证；不能移植到任意固定三档Q。
4. **可计算认证原型。** 对每个起点做连续幅值区间上界，未排除区间全部保留，任何无法认证时返回0。固定起点似然在相邻移动零点之间严格凹，为后续降成本提供结构。原型仍显式枚举起点，不是O(J)在线恢复器。
