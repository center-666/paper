## 2. 基础区间运算的包络方向

输入字符串先解释为精确 Decimal 实数，禁止从 Python float 隐式构造精确区间。加、乘、倒数端点分别在 ROUND_FLOOR 和 ROUND_CEILING 下以50位有效数字计算。平方显式处理跨零区间，下端为0，上端取两个端点平方较大者。负号用 copy_negate，不触发外层默认精度舍入。

exp、ln（以及新增 sqrt）使用 Decimal 的正确舍入操作，再分别用 next_minus、next_plus 向外扩一ULP。给定正确舍入合同，这足以包住对应真实初等函数值。正函数的下端以0截断是使用已证明非负性收紧包络，不是把密度强制变为正数。

需要保留的数值范围条件：当前实现没有扩展无限大的 Decimal 指数范围，也没有自动捕获所有资源/算术异常。溢出或异常应由调用端停止认证并返回零动作，不能继续使用缺失上界。已有有限短记录不触发这些情况；原型不声称任意长记录均能在固定精度下高效完成。

## 3. 触发对数密度在零点处仍保守

令 \(h(v)=1-\exp(-Zv^2/2)\)。它是 \(v^2\) 的单调递增函数；因此先包住 \(v^2\)，再对两个平方端点计算 \(h\) 和 \(\log h\)，方向正确。

当输入区间跨越0，下界取 \(-\infty\)，但上界由最大平方端点计算，仍能有效排除整个区间。输入恰为0时上下端均为 \(-\infty\)。候选密度零点没有被替换为epsilon。

健康分母的 log_trigger(u-r) 若下界为 \(-\infty\)，构造器拒绝该记录。这包含真实零点和当前精度无法确认严格正的情况，是保守拒绝。对于已经证明正的分母，减去其区间时用分母下界形成似然上界，方向正确。

## 4. 精确起点库和似然递推

记录长度为 \(n\)，当前物理时刻是 \(t=n-1\)。候选 \(k=0,\ldots,n-1\) 分别维护其污染系数；在 \(s<k\) 时其历史核与健康完全相同，log似然贡献0。

从 \(s=k\) 起，先验偏差是 \(d_s=-A H_{k,s-1}b\)，发送的联合log比为

\[
\frac{u_s(b+d_s)-(b+d_s)^2/2}{S_s}
+\log h(u_s-b-r_s)-\log h(u_s-r_s),
\]

静默时为

\[
\frac{r_sd_s-d_s^2/2}{V_s}.
\]

之后更新

\[
H_{k,s}=A(1-K_{\gamma_s})H_{k,s-1}+\gamma_sK_{1,s}.
\]

代码的顺序和符号与阶段三精确核一致。所有 \(H,K,P\) 的包络使用同一实际事件历史；未向候选传入真实攻击标签或隐藏状态。

参考 \(Q\) 使用固定健康质量0.5、等权三幅值和
\(w_k=1/[(k+1)(k+2)]\)。当前已见起点之外的总质量为

\[
\sum_{k=n}^{\infty}w_k=\frac1{n+1}.
\]

尚未开始的所有候选在当前历史上都等于健康密度，故把该尾质量乘以1加入参考似然完全正确。没有截断真实候选；分母搜索仍允许整个 \([0,b_{\max}]\)，即使分子只混合三个离散幅值。

## 5. 低污染约束、上界排除和非空见证

目标是排除全部 \(\theta_t(k,b)=bH_{k,t}\le z\) 的参数。若区间系数满足
\(H_{k,t}\in[\underline H,\overline H]\)，则在 \(\underline H>0\) 时，

\[
bH_{k,t}\le z\quad\Longrightarrow\quad
b\le z/\underline H.
\]

代码使用向上舍入的 \(z/\underline H\) 与 \(b_{\max}\) 取小值，得到真实低污染候选的**外包**区间。若 \(\underline H\le0\)，保留完整幅值区间，不能把未知系数当正值来删候选。

参考统计量 \(E_t\) 也用区间计算。排除区间的条件是

\[
\overline{\log\Lambda_{k,t}(B)}
<
\underline{\log(\varepsilon E_t)}.
\]

左端是候选似然上界，右端是阈值下界；只有此方向才能保证没有误删可行候选。对未启动起点及健康类，真实log似然为0、污染为0。因此阈值下界未严格大于0时立即返回零，正确保留了它们。

算法还通过某个参数点的似然下界严格超过阈值上界证明置信集合非空。这个有限点搜索仅用作存在性见证；它**不**用来上界连续幅值似然。未找到见证时返回零，不等于断言数学置信集合为空。

分支时两个子区间共用同一个中点，联合仍覆盖父区间。队列次序只影响效率，不能影响证书有效性。节点限额、最小宽度停止均返回 certified=false、lower_bound=0，没有把未解析区间删除。请求超过保守污染上限时也返回零。

## 6. 可以利用的额外结构：分段凹性

附件谨慎指出“幅值似然未必全局凹”。更精确的结论是：**对固定起点，在相邻发送零点之间，log似然是凹函数；只要该候选经历一次发送，它在每个此类开区间上严格凹。**

写 \(a=Z/2>0\)、\(x=av^2\)。当 \(v\ne0\) 时，

\[
\frac{d}{dv}\log h(v)=\frac{2av}{e^{av^2}-1},
\]

\[
\boxed{
\frac{d^2}{dv^2}\log h(v)
=
2a\frac{(e^x-1)-2xe^x}{(e^x-1)^2}<0.
}
\]

因为 \(F(x)=e^x(1-2x)-1\) 在0处为0，而
\(F'(x)=-e^x(1+2x)<0\)，分子在所有 \(x>0\) 上严格为负。

对固定事件历史和起点，\(H_{k,s-1}\) 不依赖幅值。令 \(q_s=A H_{k,s-1}\)，则发送高斯项的幅值二阶导为
\(-(1-q_s)^2/S_s\le0\)，静默项二阶导为
\(-q_s^2/V_s\le0\)。发送选择项是 \(\log h(u_s-r_s-b)\)，在
\(b\ne u_s-r_s\) 的每个平滑区间二阶导严格为负。因此将合法幅值区间在所有
\(b=u_s-r_s\) 的内部零点处分割后，每段最多有一个内部极大点。

这并不意味着跨零点全局凹：每个零点处log似然趋于 \(-\infty\)，不同区间可能各有峰值。也不能把粗网格最大值当成上界。可进一步用区间包络的导数符号定位单段极值，或利用凹函数切线给上包络；必须对每段都覆盖，并保留尚未认证的段。当前原型尚未实现这种加速，仍是通用区间分支定界。

## 7. API和验证限制

当前默认调用满足所有理论域条件。但可复用接口仍应显式拒绝非法输入，包括
\(\varepsilon\notin(0,1)\)、非正/非有限幅值上界、空候选字典、健康混合质量不在\([0,1]\)，以及不符合已证明污染不变区间的模型。参数校验不足不影响当前固定S1/U1检查，却意味着不能把函数标为对任意调用都认证有效。此建议已发给主代理。

201项现有检查主要包括100位独立标量递推的区间包含检查、有限点的区间上包络检查、未来起点恒等、固定输入正证书和负例/预算拒绝。有限网格验证不是一般区间算术正确性的机器证明；有效性还依赖上面逐操作的包络论证。

在本次读取的201项版本中，三个正证书请求均记录nodes=0，说明初始区间上包络已经足够排除；预算拒绝检查也没有执行分裂后成功的完整路径。应补充至少一个nodes>0且最终认证成功的固定记录，以及实际进入分裂后仍未排除候选的零动作记录，才能把分支定界的实现路径验证补齐。这项检查不需要任何随机性能样本。

正证书fixture为8次连续发送、\(r=0,u=10^{-5}\)。在理想连续模型中这些邻域有正密度，但健康发送概率极小，参考证据也极大。它检验认证代码能工作，不代表典型攻击中的统计效率。输出例如 \(L=0.05\) 意味着“固定记录上所有保留模型污染均超过此水平”的数值证书，不意味着已经测得真实恢复MSE改善。

原型目前显式枚举起点并重复扫描历史，参考分子计算及区间求值有随时域增长的成本；没有证明长期O(J)认证或512–2048拍内的运行/认证效率。将分段凹性、历史起点外包合并用于降低计算量，是后续可做的算法工作，但每次近似必须保留候选外包关系。
