# 第二篇投稿稿的查阅范围与校核记录

稿件来源为 [定稿 Markdown](../manuscript_submission_v1.md)。数字引文与正文中的比较对象按下表核对。读过各论文的模型、主要结果和实验结论，与独立验证对方全部证明是两件事。表中“摘要”只用于相应的摘要层次比较。

| 稿件编号 | 查阅依据 | 用于成稿的内容 |
|---|---|---|
| 1 | Han 等，作者公开全文，定理及滤波更新式 | 随机发送、静默和条件高斯更新。本文式（3）的触发后偏置项另由本文模型导出。 |
| 2 | 吴寒等，正式 PDF，第543–552页，定理1–3、算法和实车试验 | 核对量化编码、重构误差和带宽权衡，并参考该文先说明假设再给出递推和算例的次序。 |
| 3 | 王彩云、李芳菲，正式 PDF，第627–634页，第2–4节 | 区分信息权限、一般优化结论和标量特例。命题1明确规定比较双方拥有同一证书。 |
| 4 | 陈佳玲、杨文，正式 PDF，第671–680页，第3–4节、表2 | 核对参数不确定下的检测目标、辨识及工程成本比较。本文分别报告实际降损与条件保证。 |

| 6 | Li、Hu、Guo，JFI 出版者全文及既有逐式核读，定理3.1、4.1–4.2、5.1–5.2 | 二值新息篡改，已知策略补偿与未知参数辨识。 |
| 7–10 | IEEE Sensors Journal、Ad Hoc Networks、IEEE TSIPN 正式文本及本地来源核读 | 分别核对融合、传输调度、马尔可夫篡改、切换传感器下的识别与补偿。题录按各文 DOI 核对。 |
| 11 | IEEE TASE，题录及作者摘要 | 随机混合攻击下的概率椭球包含目标。全文概率量词、逐时与共同覆盖差异仍待全文验证。 |

另参照本刊余宏岩等（DOI 10.14135/j.cnki.1006-3080.20260203002）、张志祥等（DOI 10.14135/j.cnki.1006-3080.20260126001）的模型假设、定理和数值段落。两篇用于比较中文控制论文的叙述方式。正式文献表共15篇，按2022—2026五个自然年统计为11篇（含2022年），2025或2026年的本刊论文2篇。中文题目按作者指定保留24字，现有官方版式说明写“不超过20个字”。中文摘要在约200字的模板建议上保留作者指定的配对数字，英文摘要253词。

## 文件与复建

从稿件所在目录运行 `uv run --script code/build_submission.py`，需可用的 XeLaTeX、中文字体和西文字体。PDF使用矢量原图，Word的13个编号公式为可编辑数学对象。三图均配有矢量PDF和410 dpi位图。作者、单位、通信作者与基金按作者决定留空。按校正问题选用中图分类号TP273。投稿须知及模板以期刊官网为准。[投稿须知](https://journal.ecust.edu.cn/tougaoxuzhi) · [下载专区](https://journal.ecust.edu.cn/xiazaizhuanqu)
