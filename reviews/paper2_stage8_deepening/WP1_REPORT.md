# WP1 模型重构与精确夹具报告

## 范围

本工作包在独立目录中实现了支持任意状态维度的线性滤波递推、已知控制输入和双侧持续偏置。当前模型合同保留单个可信事件/量测通道，状态维度支持 2、3、4 及更高维矩阵。所有矩阵与测试输入在夹具中使用 `Fraction` 精确计算。

候选模型为

\[
x_{t+1}=Ax_t+Bu_t+w_t,\qquad y_t=Cx_t+v_t,
\]

发送拍接收 \(y_t+b e_i\mathbf 1\{t\ge k\}\)，静默拍使用可信中心和 \(R+Z^{-1}\) 等效量测噪声。Monitor 与候选条件均值使用相同的 \(Bu_t\)。

## 关键恒等式

若 \(T_t=I-K_tC\)，则预测时的污染响应满足

\[
H_{k,t+1}=A\left(T_tH_{k,t}+K_t e_i\mathbf 1\{t\ge k,\gamma_t=1\}\right),
\]

从而

\[
\widehat x^M_t-\mu_t^{k,b}=bH_{k,t}.
\]

控制项在两条递推中完全相同，因此在作差时精确抵消。夹具同时验证了正负幅值和镜像记录。

## 配置算例

`config/plants.json` 包含原 V2 回归系统、带已知泵流输入的二阶双容液位对象和四状态伺服模态对象。工业对象和伺服对象的单位、采样周期与物理解释写入配置元数据。原 V2 参数保留用于回归。

## 实际验收结果

运行入口为

```powershell
python code/check.py
```

三套对象、正负幅值、非零控制输入的最大精确差均为 0。正负镜像状态差均为 0。双侧区间夹具得到正方向 `[1/8, 1/4]` 和负方向 `[-1/4, -1/8]`。完整输出见 `results/wp1_checks.json`。

## 边界

本工作包当前实现单个可信事件/量测通道。多维状态和多维已知控制输入已支持，向量量测需要为每个事件通道定义独立的静默噪声合同和攻击通道编码，暂未作为本轮投稿模型扩展。双侧偏置已完成递推和区间几何夹具，尚未把它接入 Stage 7 的连续似然证书搜索。
