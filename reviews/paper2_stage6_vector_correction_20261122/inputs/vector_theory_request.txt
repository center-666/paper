对。我认为你的这个判断更准确。

**多维系统本身不是创新点。真正值得研究的是：当动力学从标量扩展到多维以后，原来关于攻击污染、历史遗忘和安全恢复的结论哪些仍然成立，哪些不再成立，以及能否由此设计新的恢复算法。**

我建议将下一阶段的重点从“增加系统维数”调整为：

# **多维动态系统中的攻击污染可认证性与安全恢复**

核心不是研究一个更大的矩阵，而是解决三个有实质内容的问题。

## **一、问题一：多维系统中，攻击历史的影响是否仍然会遗忘？**

考虑一般线性系统：

\\[ \begin{aligned} x\_{t+1}&=Ax_t+w_t,\quad x_t\in\mathbb R^n,\\\ y_t&=Cx_t+v_t,\quad y_t\in\mathbb R^p. \end{aligned} \\]

攻击仍然发生在发送之后：

\\[ y_t^a=y_t+\gamma_t\mathbf1\_{\\{t\ge k\\}}b, \qquad b\in\mathbb R^p. \\]

沿用已经建立的随机事件触发规则，并假设精确中心及发送载荷可见。

定义真实条件均值与受攻击 monitor 的偏差：

\\[ \theta_t=m_t^a-\mathbb E\_\vartheta[x_t\mid\mathcal I_t]. \\]

可以推导出精确的向量污染动力学：

\\[ \boxed{ \begin{aligned} \theta_t^+&=(I-K\_{\gamma_t}C)\theta_t^- +\gamma_tK\_{1,t}\mathbf1\_{\\{t\ge k\\}}b,\\\ \theta\_{t+1}^-&=A\theta_t^+. \end{aligned} } \tag{1} \\]

这说明我们不再研究一个标量误差，而是在研究**切换线性系统驱动下的攻击污染传播**。

### **可以建立什么理论？**

考虑攻击幅值相同、起点不同的两条污染轨迹。当两者均已进入持续攻击阶段，攻击输入相消，差值满足：

\\[ \Delta_t=F_t\Delta\_{t-1}, \qquad F_t=(I-K\_{\gamma_t,t}C)A. \\]

如果存在 \\(P\succ0\\)、\\(\rho<1\\)，使全部允许的切换矩阵满足：

\\[ \boxed{ F_t^\top PF_t\preceq\rho^2P, } \tag{2} \\]

则：

\\[ \boxed{ \\|\Delta_t\\|\_P \le\rho^{t-s}\\|\Delta_s\\|\_P. } \tag{3} \\]

进一步结合相同攻击幅值下的观测核 KL 数据处理界，可证明固定两个不同起点的全历史 KL 有限。

也就是说，在满足切换收缩条件的多维系统中，我们仍可得到：

**攻击起点未必能够一致准确识别，但它对当前状态污染的影响可以指数遗忘。**

与标量不同，多维情形下式(2)不一定成立。不同切换矩阵可能不交换，单独稳定也不保证任意切换稳定。

因此可以继续研究：

- 什么系统条件下存在统一的污染遗忘界？
- 如果无法保证任意事件序列都稳定，能否证明概率意义或均方意义的遗忘？
- 遗忘速度由系统矩阵、可观测性、事件触发参数如何决定？

这些可以形成实质性的理论命题。

## **二、问题二：多维污染是否一定存在安全校正方向？**

我认为这是整个多维推广中**最值得研究的问题**。

标量系统里，我们已经证明：

\\[ 0\le L_t\le\theta_t \\]

时，直接校正：

\\[ m_t^r=m_t^a-L_t \\]

可以保证条件 MSE 不增。

但多维系统中，污染的方向可能未知，而且不同攻击起点、不同攻击幅值能够造成完全不同的污染方向。

假设将阶段四的参数置信集合映射成向量污染集合：

\\[ \Theta_t = \left\\{ \theta_t(k,b):(k,b)\in C_t^\varepsilon \right\\}. \\]

我们不应该先从集合中选一个“最可能的攻击向量”，再直接减掉它。

因为点估计不准确时，校正可能反而增加 MSE。

### **1. 直接提出风险安全恢复优化**

令 \\(W\succ0\\) 为状态误差权重，选择校正向量 \\(c_t\\)：

\\[ m_t^r=m_t^a-c_t. \\]

条件风险差为：

\\[ \boxed{ R_t^a-R_t^r = 2\theta_t^\top Wc_t-c_t^\top Wc_t. } \tag{4} \\]

我们希望对所有与可信观测记录相容的污染向量，都能获得尽可能大的保证收益：

\\[ \boxed{ c_t^\star= \arg\max_c \inf\_{\theta\in\Theta_t} \left( 2\theta^\top Wc-c^\top Wc \right). } \tag{5} \\]

这里可以得到一个明确的数学结果。

### **定理：多维最优保守校正是污染凸包的最近点投影**

定义：

\\[ \mathcal K_t=\overline{\operatorname{conv}}(\Theta_t). \\]

那么：

\\[ \boxed{ c_t^\star= \arg\min\_{z\in\mathcal K_t}z^\top Wz. } \tag{6} \\]

并且在真实污染属于 \\(\Theta_t\\) 时：

\\[ \boxed{ R_t^a-R_t^r \ge \\|c_t^\star\\|\_W^2. } \tag{7} \\]

证明的关键是凸投影最优性条件：

\\[ (\theta-c_t^\star)^\top Wc_t^\star\ge0, \quad\forall\theta\in\mathcal K_t. \\]

代入式(4)即得式(7)。反向取凸包中的最近点，又能证明式(6)确实达到式(5)的最优值。

这并非全新的凸优化原理；真正需要研究的是如何从攻击观测记录中构造有效的 \\(\Theta_t\\)，并在线计算这个投影。

### **2. 多维系统会出现标量系统没有的新现象**

**情况 A：可安全校正**

污染集合的凸包不包含原点，存在共同的非零校正方向。

**情况 B：不能保证非零校正**

污染凸包包含原点，任何非零方向都可能使某个可信模型的风险增加。

于是出现一个非常明确的可恢复性判据：

\\[ \boxed{ \operatorname{dist}\_W \left( 0,\operatorname{conv}(\Theta_t) \right)>0. } \tag{8} \\]

只有这个距离严格大于零，才能通过上述极小极大准则认证严格正的风险改善。

这也意味着：

**攻击能够被检测到，并不代表当前状态就存在可保证收益的非零校正。**

在多维系统中，问题可能不在于我们不知道是否存在攻击，而在于可信候选的污染方向相互抵消。

这比简单研究“多维攻击检测是否有效”更有意义。

## **三、问题三：能不能不求出完整污染集合，直接计算安全校正？**

这关系到算法能否真正落地。

如果状态有 \\(n\\) 维，攻击幅值有 \\(p\\) 维，起点未知，那么直接构造：

\\[ \Theta_t=\\{\theta_t(k,b)\\} \\]

再计算它的凸包，可能非常昂贵。

但污染动力学有一个可以利用的结构：

\\[ \boxed{ \theta_t(k,b)=H\_{k,t}b, \qquad H\_{k,t}\in\mathbb R^{n\times p}. } \tag{9} \\]

即使动力学多维，只要攻击幅值恒定，污染依然对 \\(b\\) 线性。

因此，我建议研究一个**直接认证恢复方向**的算法。

### **方向性污染证书**

先选择某个候选恢复方向 \\(d\in\mathbb R^n\\)，定义：

\\[ \boxed{ s_t(d)= \inf\_{\theta\in\Theta_t}d^\top W\theta. } \tag{10} \\]

如果：

\\[ s_t(d)>0, \\]

那么我们就已经证明，所有可信攻击解释沿着方向 \\(d\\) 都有正的污染投影。

此时不需要知道完整污染向量。

直接选择：

\\[ \boxed{ c_t= \frac{s_t(d)}{d^\top Wd}\\,d } \tag{11} \\]

即可保证：

\\[ \boxed{ R_t^a-R_t^r \ge \frac{s_t(d)^2}{d^\top Wd}. } \tag{12} \\]

这是一类真正可以设计计算方法的恢复算法：不必识别完整攻击参数，只认证某个方向上的污染下界。

而且它与我们之前的阶段四算法完全衔接。

之前标量情况计算：

\\[ L_t=\inf\_{\vartheta\in C_t}\theta_t(\vartheta). \\]

现在计算：

\\[ s_t(d)=\inf\_{\vartheta\in C_t} d^\top WH\_{k,t}b. \\]

仍然可以通过排除低于阈值的复合攻击候选来实现。

更进一步，还可以优化恢复方向：

\\[ \boxed{ \max\_{d\ne0} \frac{[s_t(d)]\_+^2}{d^\top Wd}. } \tag{13} \\]

它与前面的凸投影问题等价。

这使得我们可以开发两种算法：

| 算法       | 思想                | 优势                  |
| -------- | ----------------- | ------------------- |
| 完整污染集合投影 | 构造可信污染集合的外包，再求最近点 | 风险保证清晰，适合低维系统       |
| 方向性证书算法  | 直接求共同污染方向及其下界     | 不需要完整恢复攻击参数，可利用优化结构 |

值得强调的是，如果 \\(\Theta_t\\) 是计算得到的**保守外包集合**，上述风险保证仍然成立，但可能更容易返回零校正。

如果采用有限候选点的内部近似，反而可能错误放大保证收益，因此不能随意用网格点替代完整候选集合。

## **四、二维状态与二维量测其实是两个不同的研究台阶**

这里我建议区分清楚。

\\(n\ge2,\ p=1\\)

**多维状态、单通道观测与攻击**

主要研究状态耦合、向量污染传播、方向性恢复。阶段五的标量发送似然分段强凹结构仍可以使用，是最可控的第一步。

\\(n\ge2,\ p\ge2\\)

**多维状态、多通道观测与攻击**

除了污染方向问题，还会出现向量触发条件下的非凸似然优化和攻击通道耦合，是更有挑战性的第二步。

尤其第二步存在一个容易忽略的数学变化。

如果采用整体向量随机触发：

\\[ h(z)=1-\exp\left(-\frac12z^\top Zz\right), \\]

令 \\(q=z^\top Zz/2\\)，那么：

\\[ \nabla^2\log h(z) = \frac{Z}{e^q-1} - \frac{e^q}{(e^q-1)^2}(Zz)(Zz)^\top. \\]

对于与 \\(Zz\\) 正交的非零方向，二阶曲率可以为正。

这意味着：

**阶段五的分段强凹性不再自然适用于多维攻击幅值。**

因此真正的多通道扩展会引出新的算法问题：如何对非凸向量幅值似然进行严格上界计算，保证不错误排除污染候选。

这不是增加状态维数就自动解决的事情。

## **五、我认为值得作为论文理论核心的三个结论**

| 目标结论            | 要证明的内容                                | 价值                   |
| --------------- | ------------------------------------- | -------------------- |
| **定理一：多维污染遗忘**  | 给出切换矩阵乘积收缩的可验证条件，以及攻击起点信息有限但当前污染遗忘的结果 | 解释为什么无需精确定位攻击历史      |
| **定理二：可认证恢复判据** | 证明非零最坏风险改善存在，当且仅当污染凸包与原点分离            | 从检测转向判断当前状态是否真的可安全恢复 |
| **定理三：最优安全校正**  | 证明污染凸包最近点投影实现最大最坏风险改善，并设计可信外包的计算方法    | 得到可以实施的恢复算法          |

其中定理二、定理三的纯凸几何部分已经能够直接证明，不应把它们本身包装成全新的数学理论。更值得深入的部分是**由事件触发攻击模型生成的动态污染集合是否会收缩、何时与原点分离，以及如何在有限时间计算出可信的正恢复收益**。

这一研究也需要与已有工作排重。多传感器高斯保持型随机事件触发估计早已有系统研究，例如 Multi-Sensor Scheduling for State Estimation With Event-Based, Stochastic Triggers。而2026年的 Remote estimation with binary-switching sensors under tampering attack: Identification-compensated method using quantized communication 已研究未知攻击识别及补偿，所以我们不能把多维事件估计或识别后补偿作为新颖性来源。

## **六、最终我建议怎样推进？**

不需要推翻阶段一至五，也不应该因为标量系统简单就重新开始研究。

我建议把原来的 S1/U1 保留为可验证的理论特例，随后以二维、四维状态系统开展以下研究：

1. 先证明向量污染动力学及不同起点的收缩条件，区分统一遗忘与概率意义遗忘。
2. 从参数置信序列构造多维污染集合，证明它的全时域覆盖性质。
3. 设计基于方向证书或凸投影的安全校正器，证明其条件 MSE 改善保证。
4. 研究有限时间内何时能产生非零安全校正，以及这种校正是否能在实际轨迹上降低 MSE。
5. 最后推广到多测量通道，研究非凸似然的可认证优化。

**我认为第二篇论文最终应该回答的核心问题是：**

> 对于遭受未知历史攻击的多维动态系统，能否不依赖精确攻击参数辨识，而是利用可信观测记录，直接判断当前状态中哪些污染分量可以安全消除，并设计具有可证明 MSE 改善的在线恢复算法？

这比“将标量滤波器推广到多维滤波器”更有研究内容。

而且它给我们一个非常明确的下一步：**先研究多维污染的可恢复性判据，而不只是证明多维系统仍然可以检测攻击。**
