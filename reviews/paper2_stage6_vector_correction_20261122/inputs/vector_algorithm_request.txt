# **阶段六：多维污染的可恢复性与在线安全校正**

我建议这一轮先确定一个能够证明、也能够实现的结果：

**对于多维状态、单通道量测的线性系统，即使攻击起点和幅值未知，也可以不先得到唯一的攻击参数估计，而是直接从参数置信集合构造污染集合，并计算具有条件 MSE 保证的校正向量。**

更进一步，阶段五已经证明的似然分段强凹性，可以让这个多维恢复问题转化为**一维区间求解＋有限维凸二次规划**。这使我们有了一条具体的算法路线，而不只是一个理论优化目标。

## **一、先固定真正要解决的主模型**

采用多维状态、标量测量：

\\[ \boxed{ \begin{aligned} x\_{t+1}&=Ax_t+w_t,\quad x_t\in\mathbb R^n,\\\ y_t&=Cx_t+v_t,\quad y_t\in\mathbb R,\\\ y_t^a&=y_t+\gamma_t b\mathbf1\_{\\{t\ge k\\}}. \end{aligned} } \\]

其中 \\(k\\) 和 \\(b\\) 未知，暂时保持 \\(b\in[0,b\_{\max}]\\)、持续发送后注入的攻击假设。

这个模型已经足够研究多维污染方向问题，也能保留阶段五中经过验证的一维发送似然结构。

对于真实攻击参数 \\(\vartheta=(k,b)\\)，攻击污染满足：

\\[ \begin{aligned} \theta_t^+&=(I-K\_{\gamma_t,t}C)\theta_t^-+ \gamma_tK\_{1,t}b\mathbf1\_{\\{t\ge k\\}},\\\ \theta\_{t+1}^-&=A\theta_t^+. \end{aligned} \\]

由于系统线性：

\\[ \boxed{ \theta_t(k,b)=b\\,h\_{k,t}, \qquad h\_{k,t}\in\mathbb R^n. } \tag{1} \\]

这里 \\(h\_{k,t}\\) 是由可信事件历史及估计增益决定的向量，不依赖未知幅值 \\(b\\)。

这有一个关键意义：**多维污染虽然方向复杂，但在固定攻击起点下，所有可能污染仍位于同一条射线上。**

## **二、本轮的第一个关键算法结果：可信污染集合可以化为有限条线段**

阶段五给出了固定起点 \\(k\\) 的精确对数似然：

\\[ \ell\_{k,t}(b) = A\_{k,t}b-\frac12B\_{k,t}b^2 +\sum\_{\substack{i=k\\\\\gamma_i=1}}^t \left[ \log h(v_i-b)-\log h(v_i) \right], \\]

其中：

\\[ h(v)=1-e^{-Zv^2/2},\qquad v_i=u_i-r_i. \\]

当候选起点以后至少发生过一次发送时，已经证明：

\\[ \ell\_{k,t}''(b) \le-\frac1{S\_{\max}} \\]

在不包含 \\(b=v_i\\) 的每个连续区间上成立。

设当前置信集合的对数门槛为：

\\[ \kappa_t=\log(\varepsilon E_t). \\]

对固定起点，保留的攻击幅值集合为：

\\[ \mathcal B\_{k,t} = \left\\{ b\in[0,b\_{\max}]: \ell\_{k,t}(b)\ge\kappa_t \right\\}. \\]

### **定理 1：固定起点的可信幅值集合是有限个区间的并**

将所有落在 \\((0,b\_{\max})\\) 内的发送零点

\\[ b=v_i=u_i-r_i \\]

排序。

这些零点把幅值范围分成有限个区间。由于每段上的 \\(\ell\_{k,t}\\) 严格凹，它的上水平集至多是一个闭区间。

因此：

\\[ \boxed{ \mathcal B\_{k,t} = \bigcup\_{j=1}^{N\_{k,t}} [\underline b\_{k,j},\overline b\_{k,j}]. } \tag{2} \\]

如果没有发送，则候选攻击尚未产生污染，应当作为零污染类保留，而不能强行应用严格凹性。

每个可信幅值区间都对应一段向量污染：

\\[ \left\\{ bh\_{k,t}:b\in [\underline b\_{k,j},\overline b\_{k,j}] \right\\}. \\]

所以整个多维污染集合可以表示为：

\\[ \boxed{ \Theta_t= \bigcup\_{k,j} \left[ \underline b\_{k,j}h\_{k,t}, \overline b\_{k,j}h\_{k,t} \right], } \tag{3} \\]

其中右边的方括号表示两端点之间的向量线段。

这一步很重要：我们不需要在整个 \\(\mathbb R^n\\) 空间内枚举所有可能污染。

**只需要计算每个起点对应的一维可信幅值区间，就能构造多维可信污染区域。**

在健康假设或未来攻击起点仍未排除时，集合还必须包含原点。

## **三、第二个关键结果：最优安全校正可以化为有限维凸二次规划**

定义：

\\[ \mathcal K_t= \overline{\operatorname{conv}}(\Theta_t). \\]

取状态误差权重矩阵 \\(W\succ0\\)。

我们希望选择校正向量 \\(c_t\\)，使所有可信攻击解释下的最坏条件风险改善最大：

\\[ \max\_{c_t} \inf\_{\theta\in\Theta_t} \left( 2\theta^\top Wc_t-c_t^\top Wc_t \right). \\]

该问题的最优解是：

\\[ \boxed{ c_t^\star= \arg\min\_{z\in\mathcal K_t}z^\top Wz. } \tag{4} \\]

现在利用式(3)的有限线段结构。

凸包中的每条线段可以由两个端点生成。因此整个 \\(\mathcal K_t\\) 恰好等于所有可信线段端点的凸包。

将这些端点记为：

\\[ V_t=[v_1,\ldots,v_M]\in\mathbb R^{n\times M}. \\]

那么：

\\[ \boxed{ \begin{aligned} \min\_{\lambda}\quad& \lambda^\top V_t^\top WV_t\lambda,\\\ \text{s.t.}\quad& \lambda\ge0,\qquad \mathbf1^\top\lambda=1. \end{aligned} } \tag{5} \\]

得到最优权重 \\(\lambda^\star\\) 后：

\\[ \boxed{ c_t^\star=V_t\lambda^\star, \qquad m_t^r=m_t^a-c_t^\star. } \tag{6} \\]

这就是一个可以编程实现的恢复算法。

它有三个特点：

- 无需先得到唯一的攻击起点或幅值；
- 不需要对多维污染区域做高维网格搜索；
- 有明确的凸优化目标以及条件风险保证。

而且，由 Carathéodory 定理，最优校正向量可以由至多 \\(n+1\\) 个端点的凸组合表示。虽然求解过程中仍可能需要检查许多候选端点，但最终校正本身具有稀疏表示。

这里的算法贡献不在于凸二次规划本身，而在于**如何从攻击历史似然精确地构造这些端点，并在有限计算误差下保持统计保证**。

## **四、第三个结果：不仅能证明安全，还能证明距离理想恢复有多远**

这是我认为应该保留在最终论文中的第二条风险定理。

给定真实攻击参数，定义理想条件估计器：

\\[ m_t^{\mathrm{oracle}} = \mathbb E\_\vartheta[x_t\mid\mathcal I_t]. \\]

这里的 oracle 是知道真实攻击参数的理论基准，而不是健康系统的反事实估计轨迹。

对于正定权重 \\(W\\)，定义：

\\[ R_t(m)= \mathbb E\_\vartheta[ \\|x_t-m\\|\_W^2\mid\mathcal I_t]. \\]

由于条件均值的正交性：

\\[ \boxed{ R_t(m_t^r)-R_t(m_t^{\mathrm{oracle}}) = \\|\theta_t^\star-c_t\\|\_W^2. } \tag{7} \\]

因此，恢复问题可以转化成一个很清楚的几何问题：

**我们计算出的校正向量，与真实污染向量之间还相差多少？**

设可信污染凸包在 \\(W\\) 范数下的直径为：

\\[ D_t= \sup\_{u,v\in\mathcal K_t}\\|u-v\\|\_W. \\]

由于真实污染 \\(\theta_t^\star\\) 与投影校正 \\(c_t^\star\\) 都属于 \\(\mathcal K_t\\)，在置信覆盖成立时：

\\[ \boxed{ 0\le R_t(m_t^r)-R_t(m_t^{\mathrm{oracle}}) \le D_t^2. } \tag{8} \\]

同时，凸投影保证：

\\[ \boxed{ R_t(m_t^a)-R_t(m_t^r) \ge\\|c_t^\star\\|\_W^2. } \tag{9} \\]

这给出了两种互补的恢复评价：

| 指标       | 公式                           | 代表什么                  |
| -------- | ---------------------------- | --------------------- |
| 保证改善量    | \\(\\\|c_t^\star\\\|\_W^2\\) | 至少可以安全消除多少风险          |
| 剩余污染风险上界 | \\(D_t^2\\)                  | 距离已知攻击参数的理想条件估计还可能有多远 |

这比只报告检测率或平均 MSE 更充分。

尤其重要的是：如果能够证明

\\[ \boxed{D_t\longrightarrow0,} \\]

那么即使攻击起点的置信集合始终没有收缩到一个点，我们仍然可以得到：

\\[ R_t(m_t^r)-R_t(m_t^{\mathrm{oracle}}) \longrightarrow0. \\]

这正好对应我们的研究目标：**实现状态恢复，并不要求先准确恢复攻击历史。**

这里的收敛是相对于同一攻击观测历史下的理想条件估计器，而不是保证动态估计误差本身趋于零。

## **五、如何证明多维污染集合会收缩？**

阶段四的连续幅值证明实际上可以作为基础。

对多维状态、标量攻击幅值，污染仍满足：

\\[ \theta_t(k,b)=b h\_{k,t}. \\]

假设存在 \\(H\_{\max}>0\\)、\\(M\ge1\\) 和 \\(\rho<1\\)，使：

\\[ \\|h\_{k,t}\\|\_W\le H\_{\max}, \\]

并且两个都已启动至少 \\(L\\) 拍的单位幅值响应满足：

\\[ \\|h\_{k_1,t}-h\_{k_2,t}\\|\_W \le2H\_{\max}M\rho^L. \\]

那么，对任何可信候选 \\((k,b)\\)，若：

\\[ |b-b^\star|\le\zeta \\]

且该候选和真实攻击都已经持续至少 \\(L\\) 拍，就有：

\\[ \boxed{ \\|\theta_t(k,b)-\theta_t^\star\\|\_W \le H\_{\max}\zeta+ 2b\_{\max}H\_{\max}M\rho^L. } \tag{10} \\]

定义右侧为 \\(r(\zeta,L)\\)。

假设精确似然已将幅值差大于 \\(\zeta\\) 的候选以及过晚起点候选全部排除，那么：

\\[ \mathcal K_t \subseteq \left\\{ z:\\|z-\theta_t^\star\\|\_W\le r(\zeta,L) \right\\}. \\]

由此直接得到：

\\[ \boxed{ \\|c_t^\star\\|\_W \ge [\\|\theta_t^\star\\|\_W-r(\zeta,L)]\_+. } \tag{11} \\]

式(11)提供了非零安全校正的充分条件。

当：

\\[ \\|\theta_t^\star\\|\_W>r(\zeta,L), \\]

就能保证存在正的条件风险改善。

更进一步，在上述候选排除成功时：

\\[ \boxed{ R_t(m_t^r)-R_t(m_t^{\mathrm{oracle}}) \le r(\zeta,L)^2. } \tag{12} \\]

因此，我们可以将阶段四的连续幅值统计收缩，与多维动力学的指数遗忘结合起来。

不过要正式证明式(10)能够以高概率最终成立，还需要验证三个条件：切换污染动力学的收缩性、向量响应的统一有界性，以及多维状态下标量联合观测核的统一统计分离性。

最后一个条件在当前模型下仍有希望沿用阶段四的移动零点证明；前两个条件需要针对具体多维系统重新证明。

**这是下一阶段最值得完成的完整定理，而不是简单地声称标量定理自然推广到了多维。**

## **六、一个更便宜的在线算法：不必完整求解污染凸包**

前面式(5)的完整二次规划很清晰，但计算全部可信区间和端点可能很贵。

我们还可以设计一个更适合先实施的算法。

选择一个非零恢复方向 \\(d_t\in\mathbb R^n\\)，并定义方向污染下界：

\\[ s_t(d_t)= \inf\_{\theta\in\Theta_t} d_t^\top W\theta. \\]

如果能够认证：

\\[ s_t(d_t)\ge z_t>0, \\]

那么直接设置：

\\[ \boxed{ c_t= \frac{z_t}{d_t^\top Wd_t}d_t } \tag{13} \\]

即可保证：

\\[ \boxed{ R_t(m_t^a)-R_t(m_t^r) \ge \frac{z_t^2}{d_t^\top Wd_t}. } \tag{14} \\]

关键是如何认证 \\(z_t\\)。

利用阶段五已有的区间似然优化器，只需验证：

\\[ \boxed{ \sup\_{\substack{k,b\\\ b\\,d_t^\top Wh\_{k,t}\le z_t}} \ell\_{k,t}(b) < \log(\varepsilon E_t). } \tag{15} \\]

如果式(15)成立，说明所有在方向 \\(d_t\\) 上污染不超过 \\(z_t\\) 的参数都已被置信集合排除。

对固定起点，记：

\\[ a_k=d_t^\top Wh\_{k,t}. \\]

若 \\(a_k>0\\)，约束简化为：

\\[ b\le\min\left(b\_{\max},\frac{z_t}{a_k}\right). \\]

若 \\(a_k\le0\\)，在 \\(z_t\ge0\\) 时应当检查完整幅值区间，不能擅自删去该起点。

这和我们阶段五的标量污染下界认证算法几乎完全相同。

因此，只需要增加一个向量污染方向接口，而不用马上重新实现整个高维置信区域求解器。

### **我建议的最小算法架构**

**多维事件触发状态估计器**

维持原 monitor、可信事件和精确似然记录

**攻击证据与候选污染响应**

\\(\ell\_{k,t}(b),\quad h\_{k,t}\in\mathbb R^n\\)

**提出候选恢复方向**

允许点估计或启发式提出方向，但不能直接当作校正保证

**方向性污染证书**

\\(s_t(d_t)\ge z_t>0\\)

认证成功

\\(m_t^r=m_t^a-c_t\\)

认证失败

\\(m_t^r=m_t^a\\)

有一个很重要的统计细节：候选方向 \\(d_t\\) 可以根据当前数据自适应选择。只要式(15)对最终选定的方向和全部相关参数进行了严格认证，风险保证仍然来自同一个全时域参数置信集合，不需要把方向点估计本身当作可信信息。

这使我们能够将学习型或估计型方法用于**提出可能有效的恢复方向**，再由严格证书决定是否实施校正。

## **七、还有一个可以直接降低计算成本的结构**

阶段五缓存了每个起点的二次似然系数 \\(A\_{k,t},B\_{k,t}\\)。

但我们还可以进一步利用发送选择项与起点之间的关系。

定义：

\\[ T_i(b)= \gamma_i [\log h(v_i-b)-\log h(v_i)]. \\]

那么：

\\[ \ell\_{k,t}(b) = A\_{k,t}b-\frac12B\_{k,t}b^2 +\sum\_{i=k}^{t}T_i(b). \\]

对于一个固定的幅值查询 \\(b\\)，后面的求和可以通过后缀和一次计算全部起点：

\\[ U\_{k,t}(b)=\sum\_{i=k}^{t}T_i(b). \\]

因此，若各起点的二次系数已经缓存，那么**对于一个给定的&#x20;**\\(b\\)**，所有起点的完整似然可以在&#x20;**\\(O(t)\\)**&#x20;时间内评分**，而不是对每个起点都重新扫描后续历史。

这不是整个认证器的 \\(O(t)\\) 总复杂度：连续幅值搜索仍需多次查询，在线维护全部候选响应也有成本。但它避免了重复计算完全相同的选择修正项，是可以直接实现的优化。

## **八、一个简单例子说明我们到底恢复了什么**

假设某时刻的可信污染集合是连接以下两点的线段：

\\[ \theta_1= \begin{bmatrix}0.2\\\0.1\end{bmatrix}, \qquad \theta_2= \begin{bmatrix}0.2\\\\-0.1\end{bmatrix}. \\]

取 \\(W=I\\)。

虽然第二个状态的污染方向不确定，但第一个状态的污染在所有候选下都等于0.2。

计算凸投影：

\\[ c^\star= \begin{bmatrix}0.2\\\0\end{bmatrix}. \\]

于是：

\\[ \boxed{ R^a-R^r\ge0.04. } \\]

这是一个确定性的几何示例，不是已完成的多维系统仿真。

它说明：**我们不必知道第二个状态究竟受到正向还是负向污染，也可以先安全修正第一个状态。**

反之，如果可信污染集合同时包含：

\\[ \begin{bmatrix}0.2\\\0.1\end{bmatrix}, \qquad \begin{bmatrix}-0.2\\\\-0.1\end{bmatrix}, \\]

那么它的凸包包含原点。即使所有候选都存在非零污染，极小极大意义下仍不存在保证正收益的非零校正。

这正是“攻击已确认”和“状态能够安全恢复”之间的根本区别。

### **我的研究判断**

现在已经可以把下一阶段具体定为：

**阶段六：多维污染集合的可认证恢复算法及理论保证。**

主线应当先采用 \\(n=2,p=1\\) 的耦合线性系统，而不是直接引入多测量通道、分布式网络或其他复杂机制。

阶段六最小成果应该是：实现向量污染递推与方向性证书，证明所采用二维系统的遗忘条件，并在冻结的性能实验中比较原 monitor、未知参数点估计补偿和证书校正三种方法。

如果这些结果成立，再加入完整污染凸包投影，证明其优势及适用条件。

**最值得追求的论文结论不是“我们能够估计未知攻击参数”，而是：即使攻击参数尚未唯一辨识，仍可证明当前某些状态污染方向能够被安全消除；无法认证时则拒绝校正，从而控制错误恢复的风险。**

这一目标已经能够对应明确的数学命题、可执行的算法和可检验的实验，而不只是一次常规的多维模型扩展。
