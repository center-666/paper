# 阶段六：二维耦合系统的污染可恢复性与方向校正

基准5738b644，2026-11-22。按用户最新指示暂停S1/U1统一时间常数优化，采用二维集中式、单通道、部分可观测模型，研究向量污染遗忘与安全恢复。未引入Yang分布式估计器，正式稿未修改。

**当前判断：理论可推广，首版工程原型的实用收益尚未证实。** 强攻击独立确认12条中9条曾有有用证书，但512拍实际累计降损均值仅0.0242，描述性95%区间[-0.0515,0.0998]包含0；强档端到端平均约244秒/562拍。不能把安全条件风险保证当作已经实现实用MSE收益。

## 已完成的理论与确定性结果

1. **精确向量污染递推。** 多维状态、单通道量测保留高斯条件核；污染为向量 \(H_{k,t}b\)，无需逐坐标非负。
2. **任意事件历史收缩。** 用最差静默Riccati上解和随协方差变化的度量，对规定V2模型取得
   \[
   \|F_t\cdots F_s\|_2\le5(\sqrt{19/20})^{t-s+1}.
   \]
   协方差包络通过精确有理数主子式验证，未从有限事件枚举外推全局结论。
3. **可恢复性几何判据。** 可信污染闭凸包不含0，当且仅当存在正的最坏风险改善。加权最近点投影实现最优值；方向支撑下界给可计算的保守动作。
4. **新增限制。** 向量失效风险惩罚一般为4epsilon T B²，标量的2倍系数不能直接迁移；多量测攻击幅值可出现正横向曲率，阶段五分段强凹不能直接沿用。
5. **可执行原型。** 外向区间维护全部起点和连续幅值方向认证；固定幅值查询用后缀和批量评分。有限线段集合的二维加权投影另以Fraction精确实现。

给定A包含1.02不稳定模态，C仅直接测第一状态，可观测矩阵行列式为1/10。补充参数为Q=.05I₂、P0=.8I₂、R=.2、Z=2。沿连续发送路径，第二状态的单位正攻击污染从第7拍起变负；单拍欧氏误差传播范数也可大于1，但协方差度量的乘积保证仍成立。

## 验证身份

确定性部分包含1,048项投影/风险检查、256条事件树上的1,792个精确度量不等式、独立后验/污染递推恒等式和69项向量缓存/方向接口检查。几何手工集合只是验证例，不冒称从通信记录计算的置信区域。

按端到端成本预检冻结了健康、b=.10、b=.25三组，分别4条初筛和12条独立确认，总48个episode。每条562拍，评价攻击后128/256/512拍；不能据该样本量验证0.1%置信失效概率。固定日历时刻尝试认证，间隔中传播半空间；不是逐拍完整凸包重算。全部零校正/求解未完成保留，初筛不调参。

首次运行的NumPy标量文本转换故障未产出完整轨迹；[freeze_v2.json](freeze_v2.json)记录仅改变输入表示后按同种子重跑，原冻结记录和失败start保留。算法、阈值、样本数未改。

## 尚未证明或验证

当前精确几何与全历史收缩不等于实际恢复已经有效。完整向量置信区间收缩时间、非零方向出现概率、模型失配/有限字长、四维运动和多传感器融合均需后续工作。单通道正幅值模型能出现负状态分量，但“相反候选凸包包含0”的几何例不自动就是该具体系统的常见事件。

用户给出的2026量化识别补偿论文DOI10.1016/j.adhoc.2026.104269仍待全文公式级比较。多维估计、凸投影、集合恢复和识别补偿都不是独立原创点；本轮候选价值在可信动态污染集合、可证明的方向证书及实际风险/成本之间的连接。
