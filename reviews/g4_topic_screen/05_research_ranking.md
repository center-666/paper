# G4研究排序与可直接执行的决定

基准提交：`ce5923164aee083769eb5f5b2bfb8af1c4585124`。日期：2026-11-13。本轮已完成五个问题的模型筛选、直接竞争核读、G3原计划pilot及B的小预算恢复价值检验。**没有一个候选目前同时具备已建立的新机制、相关理论和强基线性能增量，因此本轮不推荐立即立题。**

这不是要求TAC级原创：只要一个小机制有实际新增能力、有可证风险界、能在公平强基线下验证收益，就足够继续。当前阻碍是这些证据没有同时成立，而不是底层工具已有研究便一概否定组合创新。

## 1. 一页执行摘要

**已成立的结论。** 历史包退出后污染仍可存在；额外真实发送也可能把sender残余污染更快传播，因此“越新越好”和“多发必然恢复”不成立。固定日程的真实MSE目标及含交叉项风险证书可以严格推导，但它们是标准工具，不能当作本项目已建立的方法创新。完整推导见[03](03_theorem_feasibility.md)。

**G3的实际状态。** 已严格执行冻结模型、48+48正常校准及24seed pilot。原Yang正常有限窗资格通过，协作信息价值很大；但没有证实预设的“门控保护收益与至少5%正常信息代价”同时出现。Zhou的正常代价点估计4.79%D，同时区间[1.13%,9.80%]；空间门控为−0.57%D，区间跨零。按计划停止，未运行后续证据Gate B或confirm。不能写成“原估计器不稳定”“合作无益”“现有方法全部解决”或“未来信息无用”。详见[G3执行报告](../g3_partial_observability/execution_report.md)。

**B的核心性能检验。** 在原G2满秩模型上，复用8个已有seed、两条固定Replay、4个原有基线，只枚举11个预先定义额外广播机会中的至多2次广播，共67日程。额外状态载荷预算64字节。强保护下，离线理想日程的网络恢复累计MSE改善仅1.69%—1.91%，预定固定/随机发送平均不足0.5%；oracle改善大部分在健康同日程也出现，攻击特异恢复量很小。原被动receiver误差平方全时域及network恢复段与G2存档核对一致。未达到预先10% oracle/5%简单策略的探索门槛，**停止这个B实例，不实现残差调度器**。该门槛不是期刊要求；这项有限网格结果也不否定所有预算或网络。详见[04](04_minimal_value_of_recovery.md)。

**文献排重的实质结果。** Nasiri已有主动状态恢复；Xu已有安全请求、允许重传仍被攻击的历史重传/校正；del Nozal已有再信任滞回及可观子空间重配置；VoI已有发送收益—成本的最优决策。因此仅用“恢复、重传、信息价值、重新接入”命名不能立题。缺少Gao/Hu/Ye等全文的部分明确降级为待核查，不把缺全文当作文献空白。

**唯一执行建议。** 本轮不立项新算法；归档G3停止结果及B负筛选。最多保留A、B两张问题卡，均不获算法开发许可。下一项低成本动作优先补读Gao2026全文，核对其质量评价、子空间/多跳融合能否直接替代A；B仅在外部新增实际系统证据显示强防御后仍有显著恢复余量时重开，不继续搜索本模型参数。C/D/F及备用协同验证不另开开发。

## 4. 两张条件保留卡及真正不可省略的步骤

### 保留卡A：有辨识证据时的方向信息保留

- **具体问题：** 不是“部分观测下加权”，而是某必要方向无法被本地单次量测核查时，能否在可信证据有限的前提下，比整包拒绝/既有子空间observer保留更多有用信息且不增加指定风险。
- **潜在改动：** 只改变Yang邻居一致性项的方向权重；当前不实施。不能默认不可观方向安全，也不能把健康原包视为已知。
- **不可省略的新步骤：** 合法可用证据确能区分信息价值和攻击风险，并给出可计算的方向风险约束；不能只做可观测SVD或引用共同LMI。
- **理论目标：** 在真实缓存模式下，得到方向权重的有限窗MSE/误拒绝代价证书。现在OPEN；标准Lyapunov框架不算已实现增量。
- **重开所需新证据：** Gao/del Nozal等不能直接解决的明确协议缺陷，以及独立且预先定义的实际系统中同风险强基线确有可重复的信息损失。G3目前未给出该证据；不允许重调其门槛或复用confirm作新pilot。
- **最小下一任务：** 仅逐式补读Gao，给“直接适用/需要标准映射/确有缺步骤”的对照。若直接替代，终止这张保留卡；不先写方向融合代码。

### 保留卡B：真实污染刷新价值的低成本证书

- **具体问题：** 同一额外字节预算下，判断“哪些真实新包会减少而非传播历史污染”，而非自动在报警后多发包。
- **潜在改动：** 只改变额外发送时刻/节点；真实sender估计允许已污染。不添加UIO、trust、clip模块来挽救收益。
- **不可省略的新步骤：** 用合法局部信息构造足够紧的后攻击误差联合矩界，使刷新价值证书非平凡；全网真误差、健康反事实和未来噪声不能上线使用。
- **理论目标：** 03的有限预算无劣化/相对最优损失界可作为标准支架，但其可部署紧不确定集、近似误差与通信成本的联系仍OPEN。
- **重开所需新证据：** 外部实际网络在强保护后仍有明显累计恢复损失，且独立预定义的小预算oracle/标准VoI确有显著可恢复空间。目前满秩、64字节实例未达到，不再在同一实例追加budget/grid搜索。
- **最小下一任务：** 归档本轮负结果和字节—损失表，不实现残差候选。若以后出现上述独立证据，再先设强VoI/定频基准和预算，而不是先提出复杂调度器。

这两张卡是对未来新证据的接收标准，不是两个获批课题；没有用“保留”绕过G3/B的停止条件。
