# 论文路线决策：部分观测推广是否值得继续

日期：2026-11-12。决策输入依次为[独立数学审计](theorem_audit.md)、[定理级文献与旧稿排重](novelty_audit.md)。面向研究负责人的[一页中文执行摘要](executive_summary.md)单独保存，便于审阅。

## 1. 明确推荐

**推荐路线A：将结果作为旧稿的一个有条件推广命题候选，限量补强；不按路线B另立独立论文。** 正式旧稿目前保持原样，是否并入由负责人审阅后决定。本轮已经完成的是审计和复现，不是正式论文修订。

理由有三个。第一，固定协议下的充分上界成立，没有必要因一个尚未出现的反例丢弃它。第二，相对旧稿的新增主要是“攻击可达子空间上的可见性”替代全空间假设，而所需证明是OLD+STANDARD的短接合。第三，逐历史秩条件不是安全性必要条件，本轮已给出反证；若据此构建独立“可检测性边界”论文，核心叙事会不成立。

如果并入后需要大量篇幅，却没有一个解释力明显的新部分观测例子，或常数过大没有实质信息，转路线C收口旧稿。路线B只有在原问题内部获得实质性、非旧推论的新定理后才重新评估，不因“再多跑一些实验”而自动升级。

## 3. 路线A：并入旧稿

### 3.1 需要增加哪些内容？

**定义。** 在原问题说明末尾或补充材料中给y=Cx+v的扩展版本；明确G_t是分析用真实发送历史，h仅是事件串；定义B_h、R_{k,h}=rangeB_h、全静默指示Y_L、精确P标签及常数的依赖。说明R_h为线性外包，不能逐历史任意指定一套事后攻击。

**引理。** 保留原条件高斯与MSE分解的证明骨架，写清一般C与退化P时仅求逆CPCᵀ+R_i；新增多拍静默核的陈述，并引用本项目已有推导而不称首次；再给kerG∩R_h={0}与受限正定性等价的短引理。

**命题及证明。** 以“部分观测下的充分上界”呈现(A17)，给h_*、B_*、q_*、M_*、Ω_k的统一量词。用同一f(P,Y)=Y/s_L(P)处理整体分布；不能以条件TV的平均替代整体TV。将协方差迹变化计入，而非把J直接当E||D||²。

**限制。** 只扩大上界适用范围，不宣称旧双预算匹配下界已覆盖所有部分观测系统；不宣称秩条件必要、标签最小、窗口越长越好、受攻击长期稳定或有限样本检测改善。附注说明条件失败可能只是该路径证书保守，而非系统存在有害隐蔽攻击。

**最少实验。** 不再堆480个类似随机模型。保留四种解析结构中两个正例和两个边界：全局不可观但攻击受限于可见坐标；动态耦合需要更长窗；奇异A使瞬时损伤被擦除；相关先验的因果分支例说明秩非必要。附一项固定峰值的近不可观参数扫描，报告实际J/TV与证书常数，不只画MSE好看曲线。已有480/16结果作为补充复核表，不作为样本统计结论。

## 4. 路线B：独立论文

### 4.1 当前为什么不通过？

当前上界的大部分链条已经在正式旧稿或20261009历史推导中。为每个h构造线性矩阵、取正交基、算最小特征值、再代旧TV界，属于标准理论工具。外部文献已经有攻击信息结构、严格/近似隐蔽、长期损伤界及达到策略；单靠有限时刻、部分观测和TV换口径不能抵消内部重复。

本轮新补的因果分支例(A24)–(A30)说明现有秩证书保守，具有审计价值；但它只是一组n=2、k=1的反向例子。把一个反例写成“发现新几何”会夸大。它既未给任意k的闭合判据，也未给最优常数和匹配攻击。

### 4.2 至少还缺一个什么结果？

以下是原候选内部的门槛，不是已实现成果或自主另立新主题：

- **共同因果策略的尖锐刻画（OPEN）。** 判定何时存在C使全部合法策略满足期望偏差能量—记录TV控制，处理分叉之前动作一致、未来发送/静默随机性，以及零输出方向在不同历史间的实现限制。不能把逐路径rangeB_h条件直接当答案。
- **匹配而非形式性的下界（OPEN）。** 要在部分观测及相同完整日志/标记记录口径下，构造合法策略达到与上界相同的系统/窗口退化阶数，或刻画条件失败时何时能有零TV正损伤。只在一个可见增益方向复制旧私有±η攻击，可能仍是旧下界的常规适配，未必够独立论文。
- **非枚举证书（OPEN）。** 给无需枚举2^{k+1}历史的可计算判据，并严格说明保守性、复杂度与收益；不能只把所有历史的最大/最小值计算隐藏到一个函数名中。

本轮没有开始这些一般化证明，更没有把它们列入成果。它们有可能不成立、不可计算，或被现有随机系统/因果控制工具直接覆盖。

### 4.3 代价和停止条件

| 评价项 | 判断 |
|---|---|
| 数学可行性 | 未定：充分条件已有；一般必要性与因果可实现性尚缺核心证明 |
| 创新性 | 当前低；只有上述未完成结果通过严格排重后，才可能提高 |
| 重叠风险 | 高，尤其与用户旧稿；“部分观测版”不自动成为另一篇 |
| 代码与实验 | 中至大：需因果策略验证、可计算判据/内外界，而非更多普通MSE轨迹 |
| 投稿风险 | 高：现稿若按独立主贡献提交，容易被认为标准推论或重复研究 |

若负责人以后选择尝试，先设**5个有效工作日的理论门槛**：只证明一个对k>1仍非平凡且信息合法的一般性新引理，并核对近邻是否已含；没得到就停止独立立题。不是先花数周画图或写引言。若确有新引理，后续完整证明、匹配构造及论文实验预计另需数周，具体3–8周只能作为不确定的人力量级，不能作为可发表承诺。

**路线B停止证据。** 关键引理被化为旧有限窗见证的标准受限谱界；必要性构造使用未来事件；可计算性仍靠全部历史；或与新增2026全文直接重合。任一项成立，回到A/C。

## 5. 路线C：停止推广，优先补旧稿薄弱环节

路线C不是停止整个项目，而是不再把当前推广当新论文。停止的现有证据是：内部技术重叠已明确；秩条件仅充分；部分模型常数很松，定性可观并不保证实用证书；外部最近邻已覆盖广泛隐蔽损伤理论。

最值得回查的旧稿环节依次为：

1. **同一记录与同一权限下，证书有多松、能否在可承受数据量下认证损伤。** 旧稿证明的是固定常数的阶数；若C很大，统计误差放大后可用性可能弱。应报告常数、真实J/TV、目标损伤尺度、独立重复样本数与置信余量，而非只展示有限模型上界不违反。旧稿已含有限样本章节，需核对其数值是否足以支撑应用措辞，不将重新核对当新算法。
2. **完整联合日志下界策略的因果性与预算核验。** 旧私有符号加下一拍补偿是主定理匹配阶数的重要环节；确认下一拍补偿发生在目标误差形成之后、峰值仍满足、联合连续/静默核未漏项。不能用仅事件TV替代完整日志TV。
3. **精确协方差标签与可信反馈的现实角色。** 标签可能编码接近全部历史，可信实际反馈已给源端确定性一致性检查的机会。旧稿可以定位成受限记录下的损伤分析，但不能暗示它优于同权限源端检查；不人为禁止强基线。
4. **文献精度和前后版本一致性。** 本轮已发现报告卷页错误、Guo事件位含义混淆、P正定性的退化边界；应在审阅修订清单中处理，不在未授权时改正式稿。

| 评价项 | 判断 |
|---|---|
| 数学可行性 | 高：问题和旧结果已有明确入口；可能发现需要修正的表述 |
| 创新性 | 通常低，但直接提高已有论文的可靠性与评审可核查性 |
| 重叠风险 | 不作为独立论文发布则风险可控；应明确是修订与审计 |
| 代码与实验 | 小至中：对既有主例做常数/联合分布积分复核，保留失败与不支持结果 |
| 投稿风险 | 相对低于路线B，仍取决于旧主贡献本身与期刊要求 |

**最小计划（预计2–4个有效工作日）。** 选旧稿一个最关键的标记记录主例和一个完整日志主例，冻结参数；输出真实损伤、TV、证书及置信余量规模的同口径表；对联合核与攻击权限逐步审查；写一页问题清单供负责人决定是否修订。无需新研究主题、网络结构或检测模块。

## 7. 什么新证据会改变建议？

**会把A降为C的证据：** 找到满足第1节全部假设和(A16)却违反(A17)的合法策略；发现旧稿已明确写出完全相同的部分观测命题；新增直接近邻全文已含该命题且无需不可省略步骤；或新增常数核验显示该推广只产生极松、没有解释力的例子。

**可能把B重新打开的证据：** 负责人仍选择原候选范围内继续，并得到一般共同因果策略类的尖锐新定理/匹配构造，或严格非枚举证书；同时通过旧稿和最近邻全文排重。当前小型非必要性例子、更多随机模型、另取题目、把KL换TV或把单拍改多拍，都不足以满足。

**不会改变建议的证据：** 只有某个有界固定方向攻击的仿真曲线更平滑；某些秩检查通过；或一篇旧论文的摘要没有出现同样方法名称。论文贡献由保证对象、假设和不可省略证明步骤决定。
