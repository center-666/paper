# D审查代理对合并证明的回读

读取对象：01_pair_theorem_assessment.md（2026-11-20，约14:38写入版本）。

## 需要修正的公式排版

第3.1节式(9)的Markov核缺少两支之间的加号。当前文本把反射Dirac测度和自环Dirac测度连写，数学上不是概率核。应为
\[
\kappa_\delta(dz\mid u)
=\alpha_\delta(u)\delta^{\rm Dirac}_{T_\delta(u)}(dz)
+[1-\alpha_\delta(u)]\delta^{\rm Dirac}_u(dz).
\]
后续式(10)事实上使用的是这个正确的混合核。因此这是必须修正的公式笔误，不是证明策略失效。

## 一处可改进的依赖说明

第2节式(4)后句“第二式要求时间1不修改物理测量”不够准确。物理测量 \(y_1\) 的条件分布只要求物理过程外生，原模型攻击也不能直接修改物理 \(y_1\)。时间1不攻击是式(21)把收到的 \(\zeta_1\) 认作物理 \(y_1\) 所需，不是式(4)本身所需。建议改为：“(4)描述真实物理量测，与时刻1载荷动作无关；后文从(4)得到接收载荷子密度时才使用时间1无动作。”

## D部分最终回读结论

第5节已经正确包含联合子测度、目标发送载荷边缘、正则条件核、Radon–Nikodym/Fubini满测集、选择因子的单点零集和特征函数唯一性等步骤。没有把污染载荷条件后验直接假定为高斯，也没有依赖攻击有密度。得到 \(\nu_z=\delta_z\) 只对 \(\eta\)-几乎处处成立，积分回联合测度再推出动作几乎处处为零，这一量词也准确。

另可作独立代数复核而不另加定理：因峰值有界，给定 \(Z_0=z\) 时 \(|U-z|\le b\)，条件一二阶矩有限。式(22)蕴含混合密度具有均值 \(\lambda z\)、方差 \(S_1\)。混合模型给
\[
\lambda\mathbb E[U\mid z]=\lambda z,\quad
S_1+\lambda^2\operatorname{Var}(U\mid z)=S_1.
\]
由于 \(\lambda\ne0\)，再次得到 \(U=z\) 条件几乎处处。这与特征函数证明一致，能检查没有遗漏额外方差项。正文保留特征函数证明即可，无须增加理论篇幅。
