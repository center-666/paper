# 文献边界与下一道验收门

恢复方向已有强近邻，不能将检查点、回滚、检测后切换、UIO重构或软融合单独称为新算法。

本地核查显示：

- Kong 等，*Cyber-Physical System Checkpointing and Recovery*，ICCPS 2018：已有检查点、滑动窗口、检测延迟和物理状态恢复；
- Deghat 等，Automatica 99 (2019)，DOI 10.1016/j.automatica.2018.10.052：已有原估计与弹性估计之间的阈值切换；
- Khazraei 与 Pajic，*Attack-Resilient State Estimation with Intermittent Data Authentication*，2022：已有间歇认证与有界估计误差条件；
- Tabatabaei 等，Automatica 180 (2025)，DOI 10.1016/j.automatica.2025.112460：已有检测、隔离、UIO重构和恢复控制链；
- Gupta 等，Signal Processing 244 (2026)，DOI 10.1016/j.sigpro.2026.110516：已有历史相关攻击后验与最优停止阈值方向；
- Mao 等，Control Engineering Practice 175 (2026)，DOI 10.1016/j.conengprac.2026.107102：已有多模型分歧、后验模式平均和软融合方向。

因此最窄的候选贡献是：在同一量化反馈、发送后攻击和本地可信事件权限下，把后置相位事件审计残差转换为可计算的污染风险预算，并证明该预算约束硬回滚或风险加权软融合的累计估计损伤。这个组合仍需逐式排重，全球新颖性保持 OPEN。

## 下一道验收门

先做标量 S1 的小规模工程验证，固定同一攻击和同一随机输入：

1. 原始普通估计；
2. 随机相位审计但不恢复；
3. 审计后直接丢弃当前可疑载荷；
4. 报警后硬回滚到可信检查点；
5. 风险加权软融合。

指标为攻击期间累计 MSE、报警前污染能量、检测延迟、误报正常 MSE 代价、攻击结束后的恢复时间、通信与检查点成本。不能使用真实状态、未来量测、真实攻击标签或未认证原始包做在线决策；这些只能用于离线评价。

如果硬回滚不能改善累计 MSE，先检查检查点新鲜度和报警延迟；如果软融合只是在使用真实状态调参后有效，则判定算法不合格。只有在同权限基线下，恢复策略在健康代价可控时降低累计 MSE，才考虑把它发展为方法论文主线。
