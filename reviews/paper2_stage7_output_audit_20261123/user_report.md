## **二、数学保证与程序核对**

这次使用的核心方法是：从已认证的方向约束

\\[ d\_\tau^\top W\theta\_\tau\ge z\_\tau>0 \\]

推导每个候选起点的攻击幅值区间：

\\[ b\in\left[\frac{z\_\tau}{d\_\tau^\top WH\_{k,\tau}},\\,b\_{\max}\right], \\]

只保留分母为正且区间非空的起点。未来继续按照**同一固定攻击幅值**传播这些候选，再通过污染线段凸包的最近点计算校正量。



只要初始证书有效、模型正确，且所有计算外包可靠，这种传播就保留原来的全时域置信保证。多次认证还可以对每个起点的幅值区间取交集，而不必重新分配置信失效预算。



本轮新增的验证包括：

- **27条成功认证记录**与阶段六原始 GitHub 文件逐条核对，指纹一致。
- **12条旧算法逐轨迹收益**在回放中全部复现，误差小于 \\(10^{-8}\\)。
- **256种确定性事件历史、3,584次精确有理数核对**通过，涵盖候选包含、半空间传播、二维凸投影和风险不等式。
- 在12条数值回放中，没有发现真实参数被错误排除或条件风险改善为负的情况。

新旧算法的配对累计降损差均值为：

\\[ \boxed{1.5447} \\]

描述性95%区间为 \\([0.2194,\\,2.8701]\\)。



但这些是已经用于研究设计的同一批轨迹，**不能将该区间当作新算法的独立统计确认**。

## **三、仍然存在的三个限制**

首先，虽然新方法比旧传播明显有效，但平均降损1.5689只相当于原 monitor 累计误差的约 **0.48%**，仍小于阶段六强攻击下点估计补偿的约9.00。



其次，新回放使用双精度计算，没有把新的区间传播和凸投影全部实现为严格外向数值算法。因此，目前是数学方法有保证、精确代数核对通过、数值性能回放有进展，还不是一套完成了端到端数值认证的恢复程序。



第三，阶段六约244秒/562拍的全流程成本主要来自首次及后续似然认证搜索。本次回放复用了这些认证结果，不能宣称已经解决在线计算成本。原有统一置信失效风险预算也仍不足以给出正的无条件期望累计 MSE 下界。

## **五、下一步研究决策**

我认为现在已经找到了一条值得继续推进的算法路线：



**从只保存一个污染半空间，改为保存攻击起点与恒定幅值之间的约束关系。**



这次同轨迹对照支持一个明确判断：阶段六的主要问题之一确实是**证据信息在恢复传播阶段被过度放松**。



下一轮不应再增加系统维数或攻击类型，而应完成严格区间算术在线实现，冻结算法后用新随机种子对健康、弱攻击和强攻击进行独立确认，并统计包括首次认证搜索在内的完整计算时间。

> **在攻击历史未知的多维动态估计系统中，通过保留可信证据所约束的固定攻击参数集合，实现具有全时域安全保证、且实际恢复收益明显优于传统保守证书传播的在线校正方法。**
