## 1. 研究问题与取舍

暂题：随机事件触发通信下基于可信历史记录的状态估计恢复方法。
核心问题：在攻击停止后，能否利用可信通信历史形成选择性重处理方向，并在攻击参数不确定时，用一个闭式恢复权重改善状态估计风险？

保留 V2、可信事件、共享量化预测中心、连续上行载荷、输出端恢复。暂停有限比特上行精确后验、Gaussian mixture、完整凸包计算、一次幅值切换、分布式迁移。与 S11 有限码字协议不同，旧有限码字数值结论不能当作本协议验证。华理 IEQ/REFQ 只作贡献组织参照，不复现。

## 2. 系统与权限

复用 ../paper2_stage6_vector_correction_20261122/model.json：A=[[1.02,0.10],[0,0.97]], C=[1,0], Q=.05 I, R=.20, P0=.8 I, Z=2, W=I, delta=.011628232298833967。x0~N(0,P0)，monitor prior=0。每拍真实物理系统 x_{t+1}=Ax_t+w_t，y_t=Cx_t+v_t。
中心 c_t=C m_t^-+r_t，r_0=0，以后 r_t 独立均匀于 [-delta,delta)，等价于完整周期随机相位预测量化的理想偏移模型。先生成中心，后按 g(y-c)=1-exp(-Z(y-c)^2/2) 产生可信发送位 gamma，再对已发送连续载荷注入 b*1_{k0<=t<k1}。攻击者不能改事件、中心、时间、记录完整性或传感器上游。保留实际中心，恢复输出不回写反馈。不声称浮点仿真已完成严格数值认证或有限比特总带宽优化。

候选：一次预先确定的常值有限攻击窗口 [k0,k1)，D=k1-k0∈{1,...,60}，b∈[-.25,.25]，含零幅值/健康解释。未来起点在当前前缀与健康等价，绝不能无依据剔除。先在固定 D=20,60、k0=80 的主实验做理想能力诊断；随机起点和变幅攻击以后再扩展。真实攻击参数、物理真值、未发送量测只在仿真评价器和明确标记的 oracle 接口使用。

## 3. 共享 monitor 与污染动力学（已有结构）

令 R_1=R, R_0=R+1/Z；K_{gamma,t}=P^-_t C^T/(CP^-_t C^T+R_gamma)。发送使用实际受攻击载荷 y^a；静默使用 c_t 作为虚拟测量。共同 Riccati 标签由实际事件序列更新。
F_t=(I-K_{gamma,t} C) A，d_t^theta=m^M_t-m_t^theta，其中 m_t^theta 是给定固定真实候选及同一完整记录的条件均值。连续载荷下 d_t^theta=F_t d_{t-1}^theta+gamma_t K_{1,t} b 1_{[k0,k1)}(t)，初始零。健康候选 d=0。停止后仅传播已有偏差，不能把 d 置零。
H_t(k)=F_t H_{t-1}(k)+gamma_t K_{1,t}1_{t>=k}，H_{-1}=0。有限窗口响应 H_t(k0,k1)=H_t(k0)-H_t(k1)，因此 d=b H_t(k0,k1)。这允许复用永久起点单位响应，无需为每个幅值重复滤波。

沿用 Stage6 共同协方差收缩证明的条件（需核对实现使用同一标签）：||F_t...F_s||_2 <= M rho^{t-s+1}, M=5,rho=sqrt(.95)。故攻击停止前最后一拍 d_{k1-1} 的后续污染平方有指数包络；从 k1+L 到无穷的 oracle 条件风险改善总量不超过 M^2 rho^{2(L+1)} ||d_{k1-1}||^2/(1-rho^2)。这只是保守上界，不是实际 MSE、检测或恢复速度结果。它说明审计延迟可能使恢复机会消失，必须测量延迟敏感性。

## 4. Recovery 方向生成（新增，简单递推）

保存后验 checkpoint (t,m^M_t,P^+_t)，默认每10拍，另有初始先验 checkpoint t=-1。记录每拍 gamma、c、实际收到 y^a（静默为空）、增益/协方差标签和时间；禁止读取真值或未发送量测。
给定候选集合，取可疑窗口 [l,u)，l=min started k0，u=max started k1，截取已发生时刻；若无已启动候选或不存在有效前置 checkpoint，返回 monitor。若候选仍在攻击，不宣称已停止；恢复权重仍可在覆盖所有候选的风险条件下计算，不使用真实 stop 作为在线开关。停止认证只作诊断（所有已经启动的可能攻击窗口结束）；健康/未来代表仍进入风险约束。
从最新 s<l 的完整性可信且在覆盖事件上无攻击污染的 checkpoint 逐拍重放到 t：
- 预测 m^R_-=A m^R_prev，P^R_-=A P^R_prev A^T+Q；
- 可信静默：以当时 c、R+1/Z 更新；
- 可疑窗口内发送：不使用载荷，仅预测；
- 窗口外发送：用当时 y^a 和 R 正常更新。
Recovery 采用自身工作 Riccati 增益，不称 P^R 为真实条件后验协方差；发送被主动擦除仍携带事件选择信息，预测-only 是工程提议而不是精确 Bayes 递推。可疑发送的事件位保留在审计日志。
检查点年龄只影响重放代价；只要检查点无污染、完整日志全部重放且运算一致，更早/更新的攻击前检查点应产生相同恢复结果（误差容限内）。不能把这一存储优化冒充估计精度创新。若删去正常历史或不完整重放，才可能出现年龄导致的性能差异；不允许把旧不完整回滚与完整重放混称。

## 5. 核心算法与可证明结论

h=m^M-m^R，q=h^T W h。对固定候选 theta 与同一完整记录，输出 m^F=m^M-lambda h，0<=lambda<=1。条件平方风险差严格为
G_theta(lambda)=2 lambda h^T W d^theta-lambda^2 q。
无需独立支路假设，无需 P^R 是后验协方差。定义 g=min_{theta in C_t} h^T W d^theta，或其可靠下界。固定窗口和幅值区间 [b_lo,b_hi] 的支撑值由两个端点取最小；跨窗口再取最小。lambda*=clip(g/q,0,1)，q=0 时 lambda=0。用实际输出动作 a=m^M-m^F 复核 min_theta(2a^T Wd^theta-a^T Wa)>=0，未决则回退 monitor。
若置信集对每一固定真候选具有全时域覆盖 1-epsilon，且支撑下界可靠，则在同一覆盖事件上所有发布时刻的真实条件风险均不高于 monitor；不是逐样本损失或无条件 MSE 必然改善。健康或零当前污染解释存在时，g<=0，拒绝恢复。不得将健康假设无条件永久加入已排除后的集合，否则方法恒零。
新增理论诊断：已知真 d 时，oracle 沿 h 的无截断最优改善（内积为正）为 (h^T Wd)^2/q；相对直接 oracle 校正 ||d||_W^2 的效率为加权方向余弦平方。内积非正则最优不动，lambda<=1 还会进一步限制。由此可解释恢复方向失败。
重要限制：Stage6 任意向量的稳健校正优化包含本方案的线段动作，故其精确最坏改善最优值不可能低于 TRSR。本方案不能宣称理论风险优于无约束投影；潜在增量是历史重处理提供实际方向、简单标量权重、降低求解开销，以及比传统回滚更可靠的实际恢复效果。必须与直接污染校正对照；若重放方向没有独立实用价值，放弃该模块。

## 6. 审计模块的后置接入（R5，暂不实现）

优先 R1-R4，不从头做 R4a。连续载荷下每个候选对同一记录有解析高斯/静默核。令 u=y^a-Cm^M_-, r=c-Cm^M_-, S=CP^-C^T+R, V=S+1/Z, eta=C A H_{t-1}(k0,k1), I_t=1_{k0<=t<k1}, v=u-r。逐拍 log likelihood ratio:
send: b(I_t-eta)u/S - b^2(I_t-eta)^2/(2S) + log g(v-b I_t)-log g(v)
silent: -b eta r/V - b^2 eta^2/(2V).
参考混合采用固定合法物理候选模板 D∈{20,60}, b∈{-.25,-.10,.10,.25} 等权，onset w_k=1/((k+1)(k+2))，未来余额 1/(t+2)。R_t=sum w_k mean_template L_t + future mass；C_t={theta:L_t>=epsilon R_t}，alpha=epsilon=.01。精确模型下可继承非负似然比鞅覆盖。永久起点向量响应可以做差，但旧累计似然不能简单做差（平方项和选择项）。需要单独验证有限结束后的似然继续传播。
先用离散候选与人工含真区间做机制实验；离散集合不能声称连续参数覆盖。连续认证仅在实验显示恢复有效后开发，可先用简单的一维区间似然保守界和端点支撑；不得将网格最小值冒充全区间下界。报警/置信排除数值保证依赖可靠算术；本阶段仅测试机制。

## 7. R1-R4 最小开发及对照

代码建议独立放本目录 code/：model_and_record.py（绝对物理轨迹及共享 monitor），replay.py（checkpoint 与重处理），risk_weight.py（闭式权重），test_deterministic.py，run_oracle_pilot.py。可复用旧 NumPy 物理/随机子流、精确 Riccati 夹具，旧文件不改。

R1 确定性：全静默、全发送、混合事件、正负幅值、有限窗口前后；直接候选滤波与 bH 误差 <=1e-10（浮点夹具目标）；H差分与显式窗口响应一致。R2：恢复不读真值；健康 checkpoint 等价；空窗口、全擦除、部分擦除、真实中心重放；更早完整 checkpoint 与最新完整 checkpoint 一致。R3：q=0、g<=0、0<g<q、g>=q、候选区间异号；解析权重与一维密网格对照；真实条件风险差与展开式一致。R4 才启动 oracle pilot。
同一记录配对：M0 monitor；M1 固定长度/不完整回滚（明确丢失哪些数据）；M2 真窗口选择性重放 lambda=1；M3 同重放 lambda=.5；M4 真窗口+真 d 的 TRSR 权重；M5 真参数直接 d 校正（同记录条件均值 oracle）；M6 有限候选区间直接污染校正（后续不确定性实验，参照 Stage6）；M7 普通检测后预测替换在实用审计阶段加入。所有 oracle 明确标记，不用于实际部署声明。
R4 主模型 8 cell：b=±.10,±.25，D=20,60，k0=80；每 cell 200 条探索性独立轨迹，健康配对 sham 窗口，独立物理/事件/相位 RNG 子流。建议 seed root 202611240731（运行前核对不与旧独立确认种子重叠）；首次动作在真实 k1（oracle）后延迟 0,5,20,60,128 拍做敏感性，同轨迹重复而非独立样本。主指标真实 stop 后前64拍累计 W-loss 配对差；512拍为补充，避免长健康尾掩盖短暂恢复机会。另记录条件累计风险改善、相对 oracle 可恢复能量、方向余弦、非零动作比例、健康代价、重放耗时。主统计单位为 episode；完整样本（包括失败/无动作）进入统计。Oracle pilot 不当正式确认实验。
随后人为构造含真参数范围（起止各±5、±15拍，幅值半宽 .025,.10，截到合法域）用于诊断；真值构造范围仅是 oracle-assisted stress，不是审计成功证据。
进入 R5 的建议门槛：在至少一个预先指定强幅值 D=60 cell，M4 相对 M0 的平均配对损失下降，且捕获 M5 的平均条件风险改善至少20%（若 oracle 改善近零则停止）；同时报告全部 cell 和不确定性，不得只选成功记录。20%是研发筛选阈值，不是显著性声明。若延迟20拍/窄人工范围就基本消除收益，优先停止；若 M6 直接校正在风险/耗时上占优且重放无独立实用收益，不以 TRSR 作为论文主方法。
正式确认在 R5 通过并完成近邻查新后另立协议，预注册实用比较器、样本量、独立种子及效应阈值；不混用 pilot。主要对照须包含相同审计信息的直接校正，不能只比很差的旧回滚。
