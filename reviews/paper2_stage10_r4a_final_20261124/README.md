# R4a-Final　中心来源、完整字母表与溢出尾界

审查基线为 b15782ab。本轮覆盖 R4a-Final 提出的三个缺口。结果限定于 Model A：物理量测连续高斯，事件由真实连续量测和当前共同中心生成，发送的受偏移载荷只做一次 IEEE-754 binary64 round-to-nearest-ties-to-even 舍入。

## 1. 中心来源链

新增 [center_source_audit.py](center_source_audit.py) 对 Model A 生成了六拍确定性因果记录。当前中心由上一拍公开 monitor 均值预测和事件前产生的外生相位唯一确定：

\[
j_t=\left\lfloor\frac{Cm_t^--s_t+\delta_q}{2\delta_q}\right\rfloor,\qquad
c_t=\operatorname{RN}_{64}(s_t+2\delta_qj_t).
\]

相位来自固定的外生测试序列，独立于隐藏物理状态和当前事件。传感器和接收端共享其值。每拍记录先验均值、预测测量、相位、整数码、中心位模式、当前事件和载荷码，并逐拍重放中心生成。源码断言中心生成只读当前公开先验与本拍外生相位，且位于量化半宽内。[六拍来源记录](center_provenance.json)

同一次源码审查了冻结的阶段九 run_episode。它从独立 SeedSequence 子流产生相位偏移 r，发生在当前事件抽样之前，并将 r 写入 EvidenceRecord。以程序的 monitor 先验为共同公开状态，绝对中心可在数学模型中重构为 c=C m^-+r；32 拍已有位模式记录也复算了对应中心并检查量化半宽。因此，**中心的可预测性条件在阶段九的理想残差模型中有可追溯来源**。代码没有把绝对中心位模式单独实例化或保存，报告将其明确标为派生中心。

信道模型仍有差异。阶段九以 binary64 创新 y-r 生成事件，发送载荷通过浮点 y+injection 得到，再用十进制 repr 传给连续载荷似然。它没有执行 Model A 的精确连续量测事件核与一次 RN64(Y+b) 载荷映射。因此，阶段九原实验不能直接充当 Model A 的统计性能验证。新增六拍 Model A 因果记录则直接由共同预测、已知相位、舍入中心和有限接收码生成，未重写阶段九历史或随机实验。源码路径、行号语义和 SHA-256 见来源记录。

## 2. 有符号零与浮点分割边界

采用精确阈值

\[
T_\infty=2^{1024}-2^{970}
       =\text{maxFinite}+2^{970}.
\]

正溢出码的原像为 \([T_\infty,\infty)\)，负溢出码为 \((-\infty,-T_\infty]\)。有限非零码使用相邻 binary64 数的中点；有符号零分别使用 \([-2^{-1075},0]\) 和 \([0,2^{-1075}]\)。相邻码端点的归属只影响零测度平局。

数值测试核对了 11 对邻接边界，覆盖正负最大有限数及溢出转换、正负零和最小次正规数、0.5 与 1.0 附近的 binade 转换。测试确认两侧有符号零胞元恰好相接，最大有限码胞元与对应溢出尾胞元恰好相接。

## 3. 发送总质量的独立数值核验

所有有限码字胞元的并集严格为 \([-T_\infty,T_\infty]\)。对偏移 \(b\)，有限发送码的总质量因此等于
\[
\int_{-T_\infty-b}^{T_\infty-b}
\phi_S(y-d)\bigl[1-e^{-Z(y-c)^2/2}\bigr]\,dy.
\]
这里没有逐个枚举约 \(2^{64}\) 个位模式，而是依据每个 binade 上相邻舍入胞元由相邻浮点中点首尾相接的结构，把全体有限码胞元合并成该积分区间。然后用独立的区间中点积分计算有限码聚合质量，不从 1 减 silence 反定义它。静默质量由闭式公式单独计算。

本次使用三个预测均值、方差与中心组合，分别对三个参考偏移 \(b\in\{0,0.05,0.25\}\) 检查，共 9 组。每组把独立有限码积分、静默闭式值和正负溢出质量区间相加，区间均包含 1。另用 SciPy 自适应积分对 \(\pm12\sigma\) 的发送密度独立交叉核对，结果落入区间积分外包内。每组的局部 Lipschitz 积分误差上界不超过约 \(1.71\times10^{-3}\)，因此这是明确的归一化实现核验，精度低于 R3b 的概率外包精度。Riemann 积分公式与逐项数据见 [final_checks.json](final_checks.json)。

## 4. 正负溢出码概率

若接收码为 \(+\infty\)，一次舍入的物理载荷满足 \(Y+b\ge T_\infty\)。若为 \(-\infty\)，则 \(Y+b\le-T_\infty\)。发送触发因子始终在 \([0,1]\) 内，因此相应的未触发高斯尾概率给出严格上界：

\[
0<q(+\infty)
 \le \bar\Phi\!\left(\frac{T_\infty-b-d}{\sqrt S}\right),\quad
0<q(-\infty)
 \le \bar\Phi\!\left(\frac{T_\infty+b+d}{\sqrt S}\right),
\]
当相应标准化阈值为正时使用 Mills 上界 \(\bar\Phi(x)\le\phi(x)/x\)。若阈值未能证明为正则返回 1 作为安全上界。

在 Model A 的 V2 参数范围，Decimal 50 位运算无法解析这些极小尾概率。程序返回下界 0 和上界约 \(10^{-1000048}\)，并将概率数值下界标为未决。数学上概率严格为正，数值区间没有假装证明正下界。参考单步核 reference_step 已接入这项溢出质量外包。候选后验经过半无限溢出单元的多拍传播仍未实现，属于 R4b 的积分与压缩问题。
