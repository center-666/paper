# G1 Task 1.1：历史Replay集合、年龄与几何

## 1. 有限性与SoD真正施加的限制

**DERIVED。** 固定有限r时，带时间标记的候选至多r个；向量集合的基数不大于真实广播数，可能有重复值或δ=0。时刻0强发保证r>0时至少有历史包，但固定lag8策略还要求至少8个前序广播。Replay的可选输入是数据依赖的有限集，不能放宽为任意实向量，也不能假设其服从均匀分布。

设连续两个真实发送时刻为tₗ<tₗ₊₁，ρ=√θ，发送值pₗ=hat xⱼ(tₗ)。按真实触发规则：

- tₗ<t<tₗ₊₁时，‖hat xⱼ(t)−pₗ‖≤ρ且t−tₗ<10；
- tₗ₊₁−tₗ≤10；若小于10，则‖pₗ₊₁−pₗ‖>ρ；
- 若间隔等于10，可由timeout触发，值差可大可小或为零；
- 若r自身为下一次发送且未触发timeout，对**最近一个**历史包有‖δ‖>ρ。它不约束更早包到当前值的距离。

**证明。** 静默同时要求两个OR标志为0；小于timeout的发送只能满足严格阈值；达到timeout必须发送。发送后参考重置为pₗ₊₁，故约束是相邻发送值之间的局部约束。不同跳跃方向可抵消，不能将它累积成远期距离下界。此结论确实利用SoD采样机制，但适用于所有正常广播日志，不是Replay特定安全定理。

## 2. 年龄不单调及无有限幅值包络

**DERIVED：模型支持反例。** 节点0估计在时刻0、1、2的第一分量为0、0.6、0.1，第二分量0。三个时刻均真实发送（时刻0强发，随后平方差.36、.25>.12）。在r=2：
\[
s=0:\ a=2,\ \|\delta\|=.1;\qquad
s=1:\ a=1,\ \|\delta\|=.5.
\]
较老包污染更小，且两个候选都合法。它不是手工仿真记录：给定任一所需有限估计序列，若Ki(k)可逆，可以解出使Yang单拍更新满足它的本地量测
\[
y_i(k)=H_i\hat x_i(k)+K_i(k)^{-1}
[\hat x_i(k+1)-A\hat x_i(k)-\epsilon A\sum_{j\to i}(c_{ji}^{+}(k)-\hat x_i(k))].
\]
Rᵢ正定使这些有限量测值在健康高斯模型支撑中；严格发送不等式及范数反转在开邻域中保持，所以不是依赖零概率等号的单调反例。攻击者不控制y；这里是检验健康模型允许什么，不是扩张攻击权限。

**FACT。** 已保存nominal_gains全部400拍、5节点的最小奇异值0.42240936899>0，最大1.17101449275；本轮只读核验，不生成增益。支持论证仅用于该有限域；不推出无限时域可逆性。

**DERIVED。** 固定年龄1时也无路径外有限‖δ‖上界：第一拍估计可在高斯量测支撑上任意大，r=1是真实阈值发送，s=0是合法历史包。A不改变“量测噪声支撑无界”这个事实。timeout允许反复发送相同值；即使δ≠0也可任意小（例如平缓变化并由timeout发送），故年龄本身不提供非零污染的统一下界。

若另有逐步增量界Lₜ，可得
\[
\|\delta_{s,r}\|\le\sum_{t=s}^{r-1}L_t,
\]
若统一L则≤La。这是一般总变差界；冻结高斯模型未给确定L。高概率包络并非逻辑上不可能，但需明确条件律、选择规则与风险水平，本轮未证明，不能用“高斯无界”否定一切概率定理。

## 4. 几何描述能提供什么

**DERIVED。** Dᵣ有限，但其形状、方向和半径随历史变化，没有预先给定的椭球或各向同性。固定C和健康触发向量e时，穿越取决于
\[
q(\delta)=2e^TC\delta+\delta^TC^TC\delta.
\]
有限min/max、支持投影及与阈值区域的交集可以精确计算；但仅有方向统计或凸包不等于新保证。q为凸函数，在有限集凸包上最大值等于有限点最大值；最小值却可能落在两包之间，给出**不可合法Replay的混合载荷**。因此不能用凸包最小化的候选冒充某个真实历史包。

Dᵣ与触发敏感方向的交集确实可能为空，排除某次离线快照的一拍分叉；这属于有限动作字典的可达性限制。它不说明Replay比一般FDI更容易检测，不给在线攻击标签。
