# P4.5 ACK-V1：独立长任务验收

## 验证计划与独立性

新增 ack_theory/test_independent_audit_regressions.py，不导入旧attack_oracle。它用独立的全历史窗口合法性函数、遍历每个S对应的全部阻断/放行二进制向量，判断是否存在合法全阻断；另写独立递归极大极小博弈覆盖逐拍wait/send和攻击阻断/放行；对连续后缀按每个m另行枚举，比较前沿。它调用被审model计算结果用于对比，因此不是独立证明；时间和集合语义仍共同继承任务定义。

执行：
~~~powershell
python -B reviews/ack_budget_v1_theory/ack_theory/test_independent_audit_regressions.py --write-summary
~~~
不调用simulate、generate_data或随机数；--write-summary仅输出本分支data/p45_long_horizon_independent.json。

## 实际覆盖和结果

| 项目 | 独立验证 |
|---|---|
| 物理窗口L | 2、3、4 |
| 预算B | 对每个L覆盖0…L−1，包括两端 |
| 起点和历史 | k=L+1；穷举{1,…,L}全部子集，过滤非法历史 |
| 任务长度 | 2L+1及2L+2，均严格大于2L |
| 发送机会 | 对每个合法历史/长度穷举所有机会子集，包含空、连续、稀疏 |
| 单任务历史—截止组 | 96 |
| 机会集合总数 | 54,144（L2:384，L3:4,608，L4:49,152） |
| T1 | 全阻断决策向量枚举与窗口判据全部一致 |
| T2 | 所有机会最小安全基数、独立因果极小极大博弈与公式全部一致 |
| T3 | 所有等待、逐m全攻击枚举与函数前沿、不可行/成本中性边界全部一致 |
| 回归 | 5项通过：不可行None、可行边界0、非法输入、稀疏机会、长任务预算两端 |

历史集合包括空、近预算耗尽、靠窗口边缘和任务期间逐次过期的情况。以物理窗口为单位，攻击向量中若任何时刻违法则剔除；对每个S判断是否存在合法的全阻断。结果见data/p45_long_horizon_independent.json。完整数值脚本可再生结果；未将各相关时隙误作统计独立样本。

## 较大参数的定向验证

**PASS。** 独立脚本另外对L=5,…,10、B∈{0,L−1}、任务长度2L+2做定向核验；空历史、近期及窗口边缘饱和历史去重后共24个历史—截止组，144个空/全/稀疏/端点/前缀/后缀机会集合。使用独立全阻断窗口扫描和只保留最近窗口状态的动态博弈核对T1/T2，并逐m核对T3。此部分为**定向测试**，不是所有机会集合或所有B的穷举；结果与前述小参数完整穷举保存在同一JSON的targeted_larger字段。

基线原有data/long_horizon_boundary_cases.jsonl.gz含720个L=2…10的定向案例，任务跨度约一个窗口，非本轮新穷举，作为补充证据；其独立性和结果不能替代本轮>2L穷举。

建议额外扩展时保留：输入参数/完整H/S、逐窗口U/N、所有可导致任务失败的攻击结果、Bellman值、首成功计数、可行与不可行s_safe和结果SHA；不可只记录总通过数。本次数学验收所需具体长任务范围已完成，但这并不意味着任意L、D或估计性能已被穷举证明。
