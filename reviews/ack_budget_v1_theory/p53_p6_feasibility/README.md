## 本轮实际得到什么、没有得到什么

**DERIVED。** 物理概率可达性补齐了P5.2接口；另一方面，Gaussian全支撑使逐历史条件风险可能很大。二者不矛盾：无条件均方有界并不限制每个历史纤维的条件风险都低于同一个常数。

**DERIVED。** 在原模型第一拍，合法阻断全部初始尝试，沿常见量测参数族 y_i,0=t 的正则条件律，有
\[
E[\|e_1\|^2\mid Y_0=t\mathbf1]
=\frac{17403}{17600}+\frac{15305933}{3097600}t^2.
\]
这是矩阵和Gaussian条件公式的解析计算，不是新生成轨迹。它说明旧公共上界不能直接升级为逐历史条件常数。零概率等值纤维的解释及正概率邻域见02§4；没有否定旧无条件证书。

**OPEN。** 未取得历史ACK信息对条件误差矩的可计算、足够紧、策略一致认证，因此没有实际MSE改善定理、长期通信优势、全局最优性或投稿GO。停止继续扩张计数、后验树或经验权重；等待负责人审核此处具体缺口。
