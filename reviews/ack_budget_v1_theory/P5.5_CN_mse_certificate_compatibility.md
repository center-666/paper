# P5.5-CN 均方证书兼容性审查

## 裁定

**DERIVED：在原稿明确分析的 B=2 固定 Yang 参数域内，C1 满足共同均方有界证书的协议接口。** 手稿的证书以锚点年龄界为通信侧接口，并声明对任何满足该界的通信协议成立。其误差递推和缓存偏差界逐路径建立；后续使用逐坐标三角不等式和 Minkowski 不等式，没有要求攻击、估计误差、当前偏差及缓存相互独立。因此 C1 根据当前估计触发和 ACK 历史选动作，不会仅因这种自适应性超出证书假设。

证书兼容只表示 C1 继承同一个保守的全时刻 RMS 上界。它不证明 C1 的实际 MSE 更低、证书更紧、相同资源下精度更好或长期通信成本更低。正式稿没有用 C1 替换原最大安全等待策略，也没有 C1 闭环仿真实验。

## 原定理及假设

来源：[paper.tex](../../papers/paper2_ack_budget_deadline/manuscript/paper.tex)，公共网络均方误差保证一节。

令网络误差为 e_k、缓存偏差为 d_k、节点更新增量为 upsilon_k。手稿的精确反馈递推为：

```
d_ji,k = A d_ji,k-1 + upsilon_j,k-1
e_k+1 = F e_k + D_c d_k + eta_k
upsilon_k = J e_k - D_c d_k + K v_k
```

成功接收令相应 d_ji,k=0。若每个锚点的残差范数不超过 theta、锚点年龄至多 B，且 A 对角、对角元 a_r >= 1，则逐路径有：

```
|d_ji,k(r)| <= a_r^B theta
              + sum(l=0..B-1) a_r^l |upsilon_j,k-1-l(r)|
```

共同均方证书进一步假设 B=2、估计器增益固定、噪声二阶矩上界已知，并要求构造的非负比较矩阵 M 满足 rho(M)<1。它据此推出全时间 RMS 上界。比较状态只保留两拍 innovation stack。

## 条件映射

| 证书条件 | C1/原模型 | 审查 |
|---|---|---|
| 锚点残差 <= theta | 低偏差触发形成锚点；成功包同步发送端与接收端缓存，偏差归零；初始化为零锚点 | FACT，满足 |
| 相邻锚点间隔 <= B+1 | C1 在固定任务内保持 minimax 值；失败使剩余值减一；截止 D=tau+B+1 时必须尝试，预算迫使成功。低请求可更早锚定 | DERIVED，满足 |
| 原估计器与缓存反馈递推 | C1 只选等待或发送，不改载荷、cache update、Yang 更新或当拍同步顺序 | FACT / DERIVED，递推不变 |
| 通信策略可随状态和 ACK 自适应 | 缓存偏差界逐路径成立；RMS 比较允许估计误差、攻击动作与缓存相关 | FACT，满足 |
| 任意 B 的误差比较矩阵 | 原定理具体取 B=2，按两拍历史构造 M | OPEN / 不覆盖 B>2 的证书推广 |

**DERIVED。** C1 使用的 s_cost 只依赖当前决策时已知的锚点 tau、过去失败时间戳 H_k、B、L、D 及当前高请求，不读取真实状态、未来量测或攻击者私有信息。当前估计决定触发高低本来就是 Yang 通信机制的信息。Minkowski 界不要求这个动作与噪声独立。

**FACT。** 正式稿当前在线规则 eq:policy 用的是最大安全等待条件，即高请求且 n_k>b_k+1 时延后，对应 s_safe>0。P5.2 的 C1 改用 s_cost>0。C1 尚未写入 paper.tex，也没有被原50组或校准实验评价。证书的“任一协议”量词允许做数学兼容性映射，但不等于已有 C1 性能数据。

该映射要求仍使用原定理的阈值锚点、成功缓存重置、固定增益及时序。如果改动消息载荷、缓存递推、估计器、增益或通信延迟，则需重新核对。

## 可写与不可写的结论

**FACT / DERIVED。**

- 原稿参数 B=2 下，C1 满足年龄不变量，因此原共同均方有界证书可复用。
- 该证书不比较 C1 与原策略的实际 MSE；它给两者同一保守界。
- 对 B != 2，现有证书不能仅凭同一年龄界直接推广。
- 原稿实验并未评价 C1；其 MSE、实际尝试分布和长期均值均为 OPEN。

**不得推出：** C1 保持与原策略完全相同的误差轨迹；均方有界等于满足任意指定 MSE 阈值；最坏首次成功尝试数不变等于总尝试数、能耗或 MSE 不变或降低。
