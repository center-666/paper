# 一、项目总体目标

## 1.1 研究背景

在分布式状态估计系统中，各节点需要通过通信链路交换局部状态估计，以维持网络估计的一致性。

在 DoS 攻击下，部分通信尝试可能被阻断。发送端通过 ACK 获得实际通信结果，并据此维护历史阻断记录。

现有 ACK 研究主要关注通信失败后的重传、动态事件触发、通信资源管理和估计误差控制。

本研究不再简单研究如何利用 ACK 减少发送次数，而是考虑一个更基础的数学问题：

**当攻击者受到物理滑动窗口内有限阻断预算约束时，发送端利用历史 ACK 信息，究竟能够安全地推迟多少次通信？如果要求进一步降低最坏通信尝试次数，系统又必须付出多少等待时间？**

我们希望建立一套完整的安全通信理论，明确：

1. 任意发送机会安排是否能够保证截止前成功通信。
2. 完成一次通信任务所需的最小最坏发送尝试次数。
3. 在不增加最坏发送次数的前提下，允许的最大初始等待时间。
4. 增加等待时间后，最坏通信成本如何变化。
5. 上述通信理论如何与分布式估计器的误差有界性联系。

## 1.2 最终研究目标

形成以下理论链条：

\[
\boxed{
\text{历史ACK信息}
\rightarrow
\text{滑窗攻击预算}
\rightarrow
\text{安全发送机会}
}
\]

\[
\boxed{
\text{最小最坏通信成本}
\leftrightarrow
\text{最大安全等待}
}
\]

\[
\boxed{
\text{通信调度}
\rightarrow
\text{缓存年龄}
\rightarrow
\text{分布式估计误差}
}
\]

最终不仅给出一个 ACK 发送规则，而且回答通信安全、资源代价和估计性能之间的数学关系。

# 二、研究对象与范围锁定

本节是整个项目的边界约束。未经重新讨论，不允许在研究过程中随意改变。

## 2.1 单链路基础模型

第一阶段采用单条有向通信链路：

\[
j\rightarrow i
\]

时间为离散整数：

\[
k=1,2,\ldots,D
\]

定义：

| 符号 | 含义 |
|---|---|
| \(a_k\) | 实际发送尝试，0 或 1 |
| \(\beta_k\) | 实际有效阻断，0 或 1 |
| \(r_k\) | 成功接收标志 |
| \(B\) | 攻击者在滑动窗口内的最大阻断次数 |
| \(L\) | 物理滑动窗口长度 |
| \(D\) | 当前通信任务截止时间 |
| \(S\) | 计划发送机会集合 |
| \(\tau\) | 最近一次有效锚点 |
| \(\theta\) | 事件触发阈值 |

基本关系：

\[
0\leq \beta_k\leq a_k
\]

\[
r_k=a_k-\beta_k
\]

攻击者满足：

\[
\boxed{
\sum_{t=\max(1,k-L+1)}^k\beta_t\leq B
}
\]

并且：

\[
0\leq B<L
\]

每条链路每个时隙最多尝试发送一次。

## 2.2 攻击者权限

必须明确以下条件：

1. 攻击者只能阻断真实发生的发送尝试。
2. 攻击者不能修改发送端的事件触发判据。
3. 攻击者不能伪造可信 ACK。
4. 攻击者不能修改真实发送载荷。
5. 攻击者必须遵守所有物理滑动窗口的硬预算。
6. 攻击者可以根据过去的实际发送、ACK 和自身动作选择下一次阻断。
7. 攻击者可以选择对发送端最不利的合法阻断安排。

第一阶段采用确定性因果发送策略和逐路径最坏情形保证。

随机发送策略、私有随机数以及攻击者是否能够获知发送随机数，暂不纳入核心定理。

## 2.3 通信时序

固定采用：

1. 预测邻居缓存。
2. 计算当前发送偏差。
3. 判断是否产生发送请求。
4. 决定是否实际发送。
5. 攻击者实施阻断。
6. 接收端形成接收结果。
7. 发送端获得可信 ACK。
8. 更新历史阻断记录。
9. 更新缓存及有效锚点。
10. 使用当前量测更新分布式估计器。

不得将发送决策之后才能获得的信息提前用于本拍发送决策。

## 2.4 第一阶段明确不研究的内容

- 不研究攻击检测器。
- 不研究攻击后的主动恢复。
- 不研究水印和密码学认证。
- 不研究攻击者修改载荷的情况。
- 不研究通信时延与 ACK 丢失。
- 不研究随机攻击概率模型作为核心约束。
- 不研究长期平均通信率最优。
- 不研究全局共享信道最优调度。

这些方向不是没有价值，而是会改变当前研究问题，破坏理论主线的集中性。

# 三、核心理论任务

这是项目最重要的部分。所有理论任务均按照定义、假设、命题、定理、证明、反例、数值核验的顺序开展。

## 任务 T1：任意发送机会集合的安全必要充分条件

### 研究目的

现有稿件主要针对特定 ACK 规则，证明固定截止条件下的最大安全等待时间。

现在要把问题推广到任意发送机会集合。

不再预先规定必须连续发送，也不预先规定 ACK 规则。

### 具体任务

定义历史阻断集合：

\[
\mathcal H_k=\{j<k:\beta_j=1\}
\]

定义当前时刻 \(t\) 的历史阻断占用：

\[
U_k(t)=
\sum_{j\in\mathcal H_k}
\mathbf 1_{\{t-L+1\leq j\leq t\}}
\]

定义未来发送机会集合：

\[
S\subseteq\{k,k+1,\ldots,D\}
\]

定义未来发送机会在物理滑动窗口中的数量：

\[
N_S(t)=
\sum_{s\in S}
\mathbf 1_{\{t-L+1\leq s\leq t\}}
\]

注意：这里的 \(N_S(t)\) 只统计当前窗口中的未来发送机会，不包含历史阻断。

### 待证明定理 T1

在上述模型下，证明：

\[
\boxed{
S\text{ 能够保证至少一次成功接收}
\iff
\max_{k\leq t\leq D}
\left[U_k(t)+N_S(t)\right]>B
}
\]

这里的保证针对持续存在发送请求的任务。

### 必须完成的证明

**充分性：**

证明只要存在一个物理窗口，使历史阻断与计划发送机会之和超过攻击预算，那么攻击者不可能阻断全部发送机会。

**必要性：**

若所有物理窗口均满足：

\[
U_k(t)+N_S(t)\leq B
\]

则构造一个因果攻击策略，在每次实际尝试时进行合法阻断，并证明该策略不会违反任意滑动窗口的攻击预算。

由此证明不存在成功接收。

### 必须进一步完成

- 任务跨度小于窗口长度时的特例。
- 任务跨度大于窗口长度时的完整形式。
- \(B=0\) 的边界情况。
- \(B=L-1\) 的边界情况。
- 初始窗口不足 \(L\) 时的处理。
- 多个发送机会重叠窗口的处理。

### 验收标准

T1 必须是对任意确定性发送机会集合成立的必要充分条件，而不是只针对连续发送或某个特定策略成立。

同时提供独立穷举程序，验证所有小规模历史与发送集合。

## 任务 T2：最小最坏发送尝试次数定理

### 研究目的

回答一个比最大等待时间更基础的问题：

在给定历史阻断记录和截止时间的条件下，完成一次成功通信任务，最少需要准备多少次发送尝试？

### 定义

首先定义：

\[
t^\star=
\min\left\{
t\in[k,D]:
U_k(t)+t-k+1>B
\right\}
\]

若不存在满足条件的时刻，则当前截止任务不可保证完成。

若存在，定义：

\[
\boxed{
m^\star=t^\star-k+1
}
\]

### 待证明定理 T2

在确定性因果调度、每拍最多一次发送及逐路径保证的条件下，证明：

\[
\boxed{
m^\star=
\min_{\pi\in\Pi_{\mathrm{safe}}}
\max_{\beta\in\mathcal A}
N_{\mathrm{try}}(\pi,\beta)
}
\]

其中：

- \(\Pi_{\mathrm{safe}}\)：保证截止前成功接收的合法因果发送策略集合。
- \(\mathcal A\)：满足滑动窗口预算的合法攻击集合。
- \(N_{\mathrm{try}}\)：成功之前的实际发送尝试次数。

### 证明分为两部分

**上界：**

立即连续发送，直到 \(t^\star\)。

证明该策略最多使用 \(m^\star\) 次尝试即可保证成功。

**下界：**

对任意合法发送策略，利用 T1 的必要充分条件证明：

任何保证成功的策略都不能将最坏尝试次数降低至 \(m^\star-1\) 以下。

### 必须特别注意

原稿现有定理证明的是安全等待边界，并没有完整建立所有因果调度策略上的 minimax 最优性。

因此，不能直接将原稿的定理当作 T2 的完整证明。

必须独立证明其对任意发送机会集合的下界。

还要区分：

- 成功前最坏发送尝试次数；
- 总发送次数；
- 成功 ACK 数量；
- 实际能耗。

T2 只直接解决第一项。

## 任务 T3：完整延迟—最坏通信成本前沿

<badge color="success">本项目第一核心深化点</badge>

### 研究目的

现有工作主要回答最多可以安全等待多少时间。

现在要回答：

等待时间增加后，为保证成功通信，最坏情况下需要增加多少次发送尝试？

### 定义

设初始等待时间为 \(s\)，第一次发送发生在：

\[
q=k+s
\]

随后逐拍尝试发送，直到成功或截止时间 \(D\)。

定义：

\[
m_{\min}(s)=
\min\left\{
m\geq1:
U_k(k+s+m-1)+m>B
\right\}
\]

同时要求：

\[
k+s+m-1\leq D
\]

若不存在满足条件的 \(m\)，则：

\[
m_{\min}(s)=+\infty
\]

这里由于 \(B<L\)，且连续发送达到保证所需的尝试次数不会超过 \(B+1\)，相关尝试机会能够包含在一个物理窗口中。

### 待证明命题 T3-1

证明：

\[
m_{\min}(0)=m^\star
\]

并证明 \(m_{\min}(s)\) 随 \(s\) 非递减。

### 待证明命题 T3-2

定义：

\[
t_{\mathrm{last}}
=
\max\left\{
t\in[t^\star,D]:
U_k(t)+m^\star>B
\right\}
\]

定义成本中性最大等待：

\[
\boxed{
s_{\mathrm{cost}}
=
t_{\mathrm{last}}-t^\star
}
\]

证明：

\[
s\leq s_{\mathrm{cost}}
\iff
m_{\min}(s)=m^\star
\]

### 待证明命题 T3-3

定义最大安全等待：

\[
\boxed{
s_{\mathrm{safe}}
=
D-k-B+U_k(D)
}
\]

在当前任务可行的条件下，证明：

\[
s\leq s_{\mathrm{safe}}
\iff
m_{\min}(s)<+\infty
\]

并证明：

\[
\boxed{
s_{\mathrm{cost}}\leq s_{\mathrm{safe}}
}
\]

### 最终需要得到

完整离散延迟—成本曲线：

\[
\boxed{
s\longmapsto m_{\min}(s)
}
\]

必须证明它的：

1. 可行域。
2. 单调性。
3. 初始值。
4. 最小值。
5. 阶梯变化性质。
6. 成本中性区间。
7. 安全边界。
8. 不同历史阻断分布下的差异。

### 重点研究问题

相同的历史阻断总数，是否会产生不同的延迟—成本前沿？

如果会，具体由哪些阻断时间戳决定？

能否构造两组历史，使得：

\[
|\mathcal H_k^{(1)}|
=
|\mathcal H_k^{(2)}|
\]

但：

\[
m_{\min}^{(1)}(s)
\neq
m_{\min}^{(2)}(s)
\]

如果可以，这将直接说明简单的历史失败计数不足以刻画安全等待空间，必须保留时间戳信息。

### 验收标准

T3 必须提供一般性证明和至少三个解析例子：

- 历史阻断集中在近期。
- 历史阻断分散在窗口边缘。
- 历史阻断在截止前逐步退出窗口。

不允许仅靠绘图或随机仿真支持单调性。

# 五、与分布式状态估计的结合

## 任务 T5：建立通信安全与估计误差之间的接口

### 5.1 现有基准必须保留

当前 ACK 稿件采用五节点二维系统：

\[
x_{k+1}=Ax_k+w_k
\]

参数包括：

\[
A=\operatorname{diag}(1.02,1.01)
\]

\[
Q=0.02I_2,\qquad R_i=0.2
\]

节点量测矩阵交替观测两个状态分量。

估计器为：

\[
\hat x_{i,k+1}
=
A\hat x_{i,k}
+K_i(y_{i,k}-H_i\hat x_{i,k})
+\sum_{j\neq i}C_{ji}(c_{ji,k}-\hat x_{i,k})
\]

其中：

\[
K_i=0.6H_i^\top
\]

\[
C_{ji}=0.0102A
\]

每条有向边独立维护预测缓存。

注意：这是 Yang 型估计结构的具体改编，不是 Yang 2014 原始随机激活最优滤波器。

### 5.2 第一项任务：通信等待如何影响缓存年龄

建立：

\[
d_{ji,k}=\hat x_{j,k}-c_{ji,k}
\]

的递推。

利用锚点年龄上界，推导：

\[
\|d_{ji,k}\|
\leq
\text{历史锚点误差}
+
\text{期间估计增量累积}
\]

重点回答：

- 为什么 ACK 安全规则可以保证锚点年龄有界？
- 历史失败记录为什么能够增加等待空间？
- 等待时间增加后，缓存偏差如何增长？
- 低偏差自然锚点与成功接收锚点有何区别？

### 5.3 第二项任务：改善均方误差证书

现有比较矩阵为：

\[
Z_{k+1}\leq MZ_k+g
\]

现稿给出的：

\[
\rho(M)=0.99664509
\]

虽然满足 Schur 条件，但证书非常保守。

需要研究：

1. 三角不等式是否造成过大的保守性。
2. 能否利用节点之间的交叉协方差。
3. 能否利用 ACK 历史的确定性年龄约束。
4. 能否使用块矩阵或 Lyapunov 方法得到更紧的界。
5. 能否对不同边的缓存年龄进行异质分析。

**验收标准：** 不仅要证明均方有界，还要明确证明条件、适用参数和实际 MSE 指标之间的关系。

不允许把理论上界直接称为实际平均 MSE。

### 5.4 第三项任务：是否迁移至原始 Yang 2014 滤波器

此项暂列为后续研究，不与 T1—T3 同时开展。

需要重新研究：

- 随机激活变量。
- 最优增益递推。
- 节点交叉协方差。
- ACK 失败与随机激活的联合关系。
- 受攻击时的协方差递推。

如果迁移导致模型和证明复杂度大幅增加，优先保留当前 Yang 型固定增益系统完成第一篇论文。

# 六、共享通信资源与多链路扩展

## 任务 T6：条件性扩展，不进入第一阶段关键路径

### 研究目的

考虑五节点网络中多条有向边同时通信的情况。

理论上可以加入：

\[
\sum_{e\in\mathcal E}a_{e,k}\leq C
\]

其中 \(C\) 为每个时隙的总发送能力。

各条边拥有不同的：

\[
B_e,\quad L_e,\quad D_e,\quad \mathcal H_{e,k}
\]

# 八、实验任务与基准设置

## 8.1 第一阶段：理论验证实验

不进行大规模 Monte Carlo。

主要进行：

- 精确整数穷举。
- 历史阻断时间戳解析计算。
- 最坏攻击构造。
- 定理边界反例搜索。
- 前沿函数绘制。

实验的主要目的是验证数学实现，而不是展示漂亮曲线。

## 8.2 第二阶段：分布式估计实验

在理论通过后，沿用五节点系统。

至少保留以下对照：

| 方法 | 目的 |
|---|---|
| Immediate Event Sending | 立即发送基准 |
| Persistent Retry | 持续重试基准 |
| Reset ACK Memory | 成功后重置历史 |
| Full ACK Memory | 完整历史记忆 |
| Calibrated Threshold | 独立校准普通触发强基准 |
| Dynamic EDF | 仅在共享资源扩展时使用 |

必须保持相同的系统、攻击权限、初始条件和噪声输入。

## 8.3 攻击场景

至少保留：

1. 因果贪心攻击。
2. 逐边异相阻断日历。
3. 无攻击场景。
4. 小规模可枚举的最坏攻击。

所有攻击必须满足同一硬滑窗预算。

## 8.4 评价指标

**通信指标：**

- 实际尝试次数。
- 成功发送次数。
- 失败发送次数。
- 成功 ACK 数量。
- 单次任务最坏尝试次数。
- 最大安全等待。
- 成本中性等待。

**估计指标：**

- 全网平均 MSE。
- 节点级 MSE。
- 最大节点误差。
- 误差峰值。
- 缓存偏差。
- 最大锚点年龄。

**安全指标：**

- 截止任务违约次数。
- 攻击预算违约次数。
- 最坏攻击下的成功保证。
- 理论预测与实际动作的一致性。

不允许将不同统计单位混在一起。

独立样本数按独立原始噪声样本或独立攻击场景计算，不能把节点数、时刻数和方法轨迹数直接当作独立样本数。

## 8.5 结果解释约束

当前稿件已经记录：

- 相对立即发送，完整记忆在指定攻击下减少总尝试。
- 同时伴随一定 MSE 增加。
- 独立校准普通触发基准在异相日历下获得了更少尝试和略低误差。

这些负面结果必须保留。

后续论文不能只展示有利于 ACK 的同阈值消融，而忽略校准强基准。

本研究的核心价值首先是安全保证和理论刻画，不是预设 ACK 必然获得更优的经验通信—精度折中。

# 十一、研究停止条件与风险控制

以下条件具有强制性。

## 11.1 T1 停止条件

如果发现：

- 任意发送集合判据存在反例；
- 对攻击预算的时间窗口径不一致；
- 历史阻断与未来发送机会存在未考虑的重叠问题；

则暂停后续定理，先修正 T1。

## 11.2 T2 停止条件

如果只能证明连续发送策略最优，而不能证明任意因果策略的下界，则只能称为连续发送策略下的最坏尝试次数，不允许称为全局 minimax 最优。

## 11.3 T3 停止条件

如果 \(m_{\min}(s)\) 的单调性或成本中性边界无法在现有假设下成立，则必须寻找反例、增加必要假设或缩小定理适用范围。

不得为了保持预期结论而修改反例。

## 11.4 论文创新性停止条件

如果文献已经给出完全等价的安全机会判据、minimax 次数和延迟—成本前沿，则不能把这三项简单并列为创新。

应转向寻找：

- 更一般的攻击预算结构；
- 更弱的可行性假设；
- 更紧的最坏成本界；
- 与估计误差之间的新理论联系。

如果没有真正增量，则收缩论文贡献，而不是强行包装。

## 11.5 实验停止条件

如果 ACK 机制无法在公平的强基准下体现经验资源优势，不影响已经证明的安全定理，但必须删除通信成本优越性相关主张。

# 十四、项目执行总原则

本项目始终坚持以下五条原则：

**第一，数学先行。** 不先开发复杂算法，再寻找理论包装。先确定问题、定理和证明，再决定算法实现。

**第二，严格排重。** 不以模型组合、符号变化或增加几个实验作为独立创新。

**第三，公平比较。** 不能只与立即发送比较，还必须与重置记忆、普通触发校准和适用的强调度基准比较。

**第四，理论与工程分离验收。** 穷举验证证明实现与定理一致，但不代替一般数学证明；Monte Carlo 展示统计行为，但不代替最坏情形保证。

**第五，研究范围逐步扩展。** 先完成单链路安全机会、minimax 成本和延迟—成本前沿，再讨论估计器扩展。多链路共享调度必须通过独立创新性门槛后才能重新启动。

**项目最终目标不是提出一个看起来更聪明的 ACK 发送算法，而是建立一套可以回答安全发送、最坏通信成本和等待自由度的严格数学理论，并将其应用于分布式状态估计。**
