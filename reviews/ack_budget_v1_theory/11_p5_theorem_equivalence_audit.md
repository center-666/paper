# ACK-V1 P5：T1–T3 定理逐项等价审计

## 前提及标签

参照P4.5：整数1≤k≤D，0≤B<L，H_k只含k之前的合法有效阻断；S是固定机会表或确定性策略的全失败路径；每时隙最多一次实际尝试，攻击者见到尝试后可因果阻断，ACK可信即时。T2进一步要求请求持续且每拍允许尝试；T3限定等待后连续尝试。论文和本项目定义域、信息和结果必须同时匹配才能说EQUIVALENT。

## T1：降为基础引理

\[
\max_{k\le t\le D}[U_k(t)+N_S(t)]>B.
\]

| 依据及定位 | 映射/判断 |
|---|---|
| Badr2017 PDF2 §II，C(N,B,W)，令 N=B、W=L | **EQUIVALENT（仅信道约束）**：每个长度L窗口允许至多B个任意擦除；不是与ACK策略优化等价 |
| Badr2013 PDF2 §II C(N,B,K,W)，令K=0,N=B | **SPECIAL CASE**：其允许集合退化成同一每窗≤B擦除类 |
| Krishnan2018 PDF1–3 C(N,B,W)；2020 PDF1–3 a/b/w定义 | **COROLLARY**：同样令任意擦除数等于突发上限，窗口预算退化为每窗最多B次 |
| Dey2025 PDF2式(2)(3)、PDF3 Thm1–2 | **ANALOGOUS / OPEN**：AVC窗口约束与容量不等于本事件/机会可行性；具体蕴含不能仅据表层名称 |
| Dolk2015/2017及Sun2024 | **ANALOGOUS**：MANSD与触发阈值/稳定性，不是物理时隙滑窗计数 |

**详细推导。** 假设每个真实S机会全部擦除/阻断，非尝试不发生有效阻断，记 \(E=H_k\cup S\)。任一窗 \(W_t=[\max(1,t-L+1),t]\) 中
\[
|E\cap W_t|=|H_k\cap W_t|+|S\cap W_t|
=U_k(t)+N_S(t),
\]
因为H_k与S分处过去与未来、互不重叠。既有滑窗信道定义保证 \(E\) 合法当且仅当所有窗计数≤B。历史本已合法，D后没有新增擦除，故仅需检查k…D。若满足，见真实尝试即阻断的因果守卫无需预知S；若不满足，全阻断违反某窗预算，故至少一个实际尝试成功。对原稿不限起始H的编码定义，H的给定前缀和ACK信息是本项目附加语义，不是原文显式引理。

**判断。** T1是标准信道定义的直接集合推论，宜降为基础引理/证明工具，不能作为独立首创定理。它的因果ACK表述和长任务索引仍需写清，但不构成对整个文献的“首次”证明。

## T3：逐项比较

\[
m(s)=\min\{m\ge1:\ k+s+m-1\le D,\
U_k(k+s+m-1)+m>B\},
\]
取空集为∞；原式只对首次满足的m使用窗口装载意义，该m≤B+1≤L。令 \(t_{last}=\max\{t\in[t^\star,D]:U_k(t)+m^\star>B\}\)，则 \(s_{cost}=t_{last}-t^\star\)；可行时 \(s_{safe}=D-k-B+U_k(D)\)。

| 文献/资产 | 判断 |
|---|---|
| Dolk2017 PDF6 Condition2式(26)、Sun2024 PDF6式(26) | **ANALOGOUS**：都定量研究间隔/阈值与连续失败条件下稳定性；不构成同一逐路径首成功尝试前沿 |
| Ding2016 PDF4–5式(14)(21)–(23) | **ANALOGOUS**：先等后按年龄随机/确定发送的阈值结构已存在；其最优是平均能量和误差，不是硬滑窗 \(m(s)\) |
| Hashemi–Maity2026 PDF3式(12)–(16)、PDF4 Thm1、PDF5 Thm2 | **ANALOGOUS**：有限时域尝试数影响i.i.d.生存概率及LQG成本；不是对抗性路径硬约束/已知失败时间戳 |
| 项目内部2026-11-09《核心定理链》§4式(C)(D) | **EQUIVALENT于 n≤L 的 \(s_{\rm safe}\)、\(s_{\rm cost}\)**；当时已用U平台长度解释同一最坏次数下等待，不是P4.5新首创 |
| 同一内部旧文《安全等待与单次最坏通信成本》§1–4 | **部分EQUIVALENT**：已讨论阻断时间戳而非总数及单任务最坏次数；当前明确给出所有s的离散 \(m(s)\)，并补 n>L 情形。是否形成足够理论增量是**OPEN** |
| Lu2026正文、Dolk博士论文Ch.5 | **OPEN**：正文缺失，不可排除相同前沿或等价推论 |

**同失败数不同时间戳的最小反证。** L=5,B=2,k=4,D=10：H={1}和H={3}都仅1个失败。依窗口过期，
\[
m_{\{1\}}(s)=[2,3,3,3,3,\infty,\infty],\quad
m_{\{3\}}(s)=[2,2,2,3,3,\infty,\infty].
\]
因为旧时间戳在不同t退出窗口，U(t)不同。这是基本滑窗状态信息的具体算术例；既不能作为“首次发现时间戳有用”，也不能说明其实际通信节省。外部全文是否已有相同完整前沿仍OPEN。

## 控制相关性

原ACK稿 paper.tex §III 的固定deadline证明及跨成功记忆，已经与有限锚点年龄和共同均方界连接。P5没有证明新的估计误差界。若去掉这个接口，剩下单链路纯计数结果的控制论文适配性和理论增量存在较高风险；如果保留接口，仍须与原稿已有界逐项排重，不能把复用原界说成新贡献。
