# 可信遥测记录的信息限制、工程合理性与论文贡献价值验收

**裁决为 CONDITIONAL GO。推荐将量化结果放在正文的“反馈精度与审计信息限制”一节，证明放附录。** 外部审计者只订阅部分字段，有工业协议和实际审计政策可作依据。项目目前缺少一份目标系统的接口材料，能说明传感器确实使用量化预测、审计者也确实只能从该接口复核。因此暂缓将量化结果列为与精确反馈定理并列的工程主贡献。

基准为 Git 提交 b95a0c2a52aa593080eec291a789ca7966cbdf72。本文继承一般固定有限 $k$ 的标量数学 PASS，评估它能回答的工程问题。下文分别标明规范事实、项目证据、条件推论和仍待核实的事项。

## 一、谁拥有原始数据，谁只拥有记录

考虑一种**假设性运行安排**。运行方负责实时估计并保管生产量测，另一个职责域的只读审计服务仅订阅设备已经产生的事件和反馈码。审计服务要回答的是“只凭允许留存的记录，能否排除超过容许值的期望损伤”。这给 B 一个可以核对、也可以被实际配置推翻的用途。

| 角色 | 可用信息与动作 | 对保证生效的条件 |
|---|---|---|
| 传感器及可信触发模块 | 读取真实本地量测、实际交付的反馈中心和私有随机数，生成发送位，发送时输出量测 | 量测进入触发模块的路径、触发逻辑及事件时间可信 |
| 远端估计器 | 读取实际收到的载荷，保存未量化预测及内部状态，生成反馈码。B 中静默更新使用与传感器相同的量化中心 | 它能记录采用了哪个值。该记录的真实性与载荷是否等于源端原值是两个问题 |
| 载荷修改者 | 仅在真实发送之后接触已发送量测，按既有因果信息和幅值预算修改上行载荷 | 不能改事件、反馈、审计导出或估计器内部计算 |
| 独立审计者 | 读取与设备、时隙、会话绑定的事件和传感器实际采用的反馈码。已知模型、初始化和完整事件序列时可自行计算 $P_k^+$ | 若订阅身份无载荷字段、原始库和内部状态的读取权，且没有可重建它们的其他输出，则适用 B。若能常规调阅这些信息，应按 C 评价 |

**访问限制的依据应是职责、授权或留存规则。** 即使载荷不可信，运行方仍可以将其原样记录并提供给审计者。一份含字段选择的导出策略，还需要配套的账号访问范围和旁路查询范围，才能解释观察者为何只有 B。网络限速也不能单独说明为什么偏偏选这一组字段。

要让记录中的“静默”具有数学模型所需的含义，须能识别缺失时隙，例如通过有时隙编号的声明或认证的批次完结记录。缺号、验签失败、模型版本不一致或反馈未送达应记为不完整。把这些情形填成静默会改变观测规律。精细时间戳、额外诊断信息或原始值摘要若随记录一起导出，也须计入实际观测。

这一定理能改变一项明确的审计决定。若容许的期望损伤为 $\tau$，且 B 的已证最坏损伤下界超过 $\tau$，即使知道总体日志分布与健康同律，也不能凭该接口为所有允许策略签发“损伤不超过 $\tau$”的保证。采集更多相同字段不会填补这个信息缺口。反过来，下界小于 $\tau$ 并不足以签发保证，还需要相应的上界和统计证据。

## 三、比较 A、B、C 时固定什么

用 $\theta$ 标识**实际控制协议**，用 $R$ 标识审计记录。三种设置共享下述统计定义：

$$
\Delta_{\theta,R}(\pi)=\operatorname{TV}(\mathcal L_{\pi,\theta}(R),\mathcal L_{0,\theta}(R)),\qquad
V_{\theta,R}^{(k)}(b,\varepsilon)=
\sup_{\pi:\, |a_t|\le b,\ \Delta_{\theta,R}(\pi)\le\varepsilon}J_{k,\theta}(\pi).
$$

$J_{k,\theta}$ 的两个期望属于同一协议。下表取 $\varepsilon=0$。同律是总体分布性质，无法从单次日志外观直接读出。

| 设置 | 传感器实际使用的触发中心 | 审计记录 | 已证结论及未知项 |
|---|---|---|---|
| A 精确反馈 | $m_t^-$ | 可信事件、精确反馈及 $P_k^+$ | 仅 $(P_k^+,\gamma_{k+1})$ 已足够推出零 TV 时 $V_A=0$。表列记录含此子记录。[原稿定理](../../papers/latex_ecust_20261102/ecust_typeset/theory.tex) |
| B 量化控制遥测 | $c_t=Q_\delta(m_t^-)$ | $(\gamma_{0:k+1},c_{0:k+1},P_k^+)$，或较小的 $(P_k^+,c_{k+1},\gamma_{k+1})$ | 在固定有限 $k$、标量、均匀无饱和格及已证参数范围内，两者都有 $V_B=\Theta_k(\min\{b^2,\delta^2\})$。[匹配界](../paper1_quantized_k_general_audit/02_uniform_probability_and_bounds.md) |
| C 增强审计 | 与 B 相同的 $c_t$ | B 的全部字段，加远端实际接收的连续载荷或未量化内部预测 | $0\le V_C\le V_B$。两种增强均能区分已证的独立随机符号见证。全策略最坏损伤是否严格下降、改变阶数或降为零，均为 **OPEN** |

在同一量化控制协议中，B 是 C 的投影，故 $\Delta_B(\pi)\le\Delta_C(\pi)$。在相同预算下 C 的可行策略集合包含于 B 的集合，给出表中的单调性。A 与 B 改变了触发中心和静默更新，甚至健康运行的事件规律也会改变，不能用同一个投影论证比较 A 与 B。

**可以单独排除“只因日志精度降低才出现地板”的解释。** 让传感器仍收到精确预测，仅在向审计者导出时把预测舍入。只要审计者仍有 $P_k^+$ 和下一事件，A 的小记录定理就能给出零 TV 时零损伤。由此可见，B 的结果依赖两个条件同时成立：量化中心进入物理运行的触发决策，审计接口又不能读取区分已有见证的连续信息。这也是论文中 A、B 比较的科学意义。

**C 对既有见证的作用可以直接核对。** 对一般 $k$ 已保存的独立符号见证，记其行动事件为 $E$、幅值为 $\eta$、当拍发送增益为 $K_h$。接收载荷的可测统计量 $\gamma_k\tilde y_k^2$ 在两种运行下的期望差为 $\eta^2\Pr(E)>0$。未量化下一预测平方的期望差为 $A^2\eta^2 E[K_h^2\mathbf1_E]>0$。两式都用独立、均值为零的符号消去交叉项。有限二阶矩与期望不同足以判定分布不同。这给出对该见证的判别，不给 C 下全体策略的零损伤定理。[见证及其量词](../paper1_quantized_k_general_audit/01_general_k_attack_proof.md)

增强字段要注明时标。固定标量模型、已知初始条件，且 B 包含完整事件与反馈历史时，记录所有 $m^-_{1:k+1}$ 可在发送拍恢复截至 $k$ 的实际接收值：
$$
\tilde y_t=m_t^-+\frac{m_{t+1}^-/A-m_t^-}{K_{1,t}},\qquad 0\le t\le k .
$$
这里 $A\ne0,\ K_{1,t}>0$。反向地，知道 B 与截至 $k$ 的所有实际接收载荷，也可逐步重建这些预测。只增加一个单拍字段，或将连续载荷多记到 $k+1$，要分别比较。上述重建恢复的是估计器采用的值，源端真实已发送量测的独立副本仍属于另一种信息资源。

## 四、其他同等精度的可信摘要

1. **同一输入。** 若摘要只读 B，且对两种运行使用同一确定性映射或随机核，则 B 同律必使新摘要及其与 B 的联合记录同律。重新编码不能消除已有见证。原稿附录的有界得分或随机一位在 A 上确能形成损伤证书，在 B 上重用时也遵循这条结论。[精确反馈下的得分命题](../../papers/latex_ecust_20261102/statistical_extension.tex)
2. **同一数值精度，不同输入。** 在固定 B 的实际控制协议上，令 $M=m^-_{k+1}$。上一节证明该见证下 $M$ 的两个边缘分布不同。仅考虑被动审计字段，从精确 $M$ 计算一个同样步长 $2\delta$、最大误差仍为 $\delta$ 的均匀舍入码，格点原点可固定平移 $s$。若对所有 $s\in[0,2\delta)$ 码字分布均相同，在各格边界累加码字概率即可得到两边相同的半直线概率。所有平移覆盖整条实线，在两分布的共同连续点取边界即可避开平局，遂推出 $M$ 同律，矛盾。因此**对此固定见证，存在一个固定偏移可区分它**。这只改变审计字段，不改变传感器的触发器。生成者必须能读精确 $M$，仅凭既有反馈码不能计算。额外导出要计新字段，替换原码则要重评记录的信息包含关系。“每个见证可能有区分它的摘要”不能交换量词为“一个摘要消除全部见证”。
3. **同样少的输出，额外的信任资源。** 作为理想上界对照，若可信验证端能把每次源端原值与远端实际采用值作无漏项、无漏报的跨端比较，可只向审计者输出一个累计一致性标志。健康标志恒为一致，标志严格同律意味着初始化至目标时刻的采用值与原值几乎处处相符，按原递推得到零损伤。虽然输出只需一位，生成它要有两端证据、正确的时隙与值绑定及可信验证。实际短标签提供计算安全保证。该对照不能充当 B 或被动增强 C 的定理。

因此，评估可信摘要时，应分别核算数值精度、输入权限、位数和总成本。B 的下界对既有字段的后处理有效。它没有证明所有同精度或同成本的审计设计都有该地板。

## 五、部署与成本

| 成本对象 | 实际需要核算的项目 | 作用 |
|---|---|---|
| 控制反馈与事件认证 | 两个方向的传输频率、序列化字段、时隙和防重放信息、认证标签、密钥维护、对静默的确认 | 建立真实事件与实际交付的反馈中心之间的对应。逐拍确认和批次确认的开销与时延不同 |
| 独立审计导出 | 字段生成端的可信性、订阅权限、独立导出消息、访问原始库的权限、留存天数及查询成本 | 决定 B/C 是否为可审计的信息限制。可以观察收到的污染载荷，并核实运行方当时实际采用了什么 |
| 端到端载荷保护 | 由可信源绑定载荷、设备和时序，远端在采用前验证。计每次真实发送的消息扩展、计算与失败处理 | 端点可信且绑定有效时可直接拒绝中间传输改写。验证失败产生的拒收与可用性代价需另评。只在中继终止的认证只覆盖相应一跳 |

各方向线传字节可用实际报文数乘以每条报文的“头部＋字段＋认证扩展”计算，再计 CPU、留存、密钥管理和拒收代价。认证的字段长度与附加标签长度不是一比一关系，已有受保护通道也可能使新增完整性保护的边际成本很低。按记录实施认证加密的规范即区分了明文长度和算法带来的记录扩展。项目尚无同口径的成本数字。[TLS 1.3 §5.2](https://www.rfc-editor.org/rfc/rfc8446#section-5.2)

无饱和格 $2\delta\mathbb Z$ 约束的是最大舍入误差。Gaussian 预测通常无界，格点索引没有统一的固定字长。若现场只提供固定位宽，必须另查值域、溢出字段、尾部平方损失及缺失处理。现有结果既不能核定每拍字节预算，也不能证明“仅认证控制通道”比认证全部载荷便宜。

## 六、论文位置与验收门槛

| 放置位置 | 这一位置要回答的科学问题 | 当前判断 |
|---|---|---|
| 第二个并列主定理 | 对一类有独立依据、字段和权限固定的外部审计接口，反馈精度如何决定可认证的残余风险？ | **暂缓。** 数学已有匹配阶数，目标系统为何受限于 B 仍缺项目级证据 |
| 正文的鲁棒性与信息限制章节 | 精确反馈定理依赖哪一环？当只有量化预测参与触发，且审计者只能保存控制遥测时，会失去哪一项损伤保证？ | **推荐。** 正文比较 A、仅粗化日志的精确控制、B 以及 C 的已知边界，将较长的固定 $k$ 证明放附录 |
| 附录 | 若外部审计并非论文的实际使用场景，一种指定压缩记录为何不再享有原保证？ | 若目标系统可常规访问 C，且正文仍以远端估计器自身为评价者，采用此定位 |

**唯一尚需的工程证据**是一份可核验的目标接口材料，最好含脱敏字段表及审计角色的访问、留存说明。它应显示传感器用哪个值触发、反馈码由谁认证、审计者是否有权取得或重建连续载荷与内部预测，以及如何识别缺失时隙。若材料确认 B，应再评价并列主贡献的价值。若显示评价者常规拥有 C，B 只能支持受限导出条件下的结论。一般固定 $k$ 的数学 PASS 继续有效，工程主贡献维持 CONDITIONAL GO，非零 TV 三预算命题仍为 OPEN。
