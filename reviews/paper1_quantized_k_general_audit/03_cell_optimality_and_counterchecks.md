# 逐路径格内攻击可行域与反方检查

FACT为定义，DERIVED为限定类优化，OPEN为未证明。本报告不把受限优化说成全体零TV攻击的全局最优。

## 1. 单次码字不变动作的精确可行半径

固定历史h和当前已发送创新u，健康下一预测M位于格 \(I_j=[2j\delta-\delta,2j\delta+\delta)\)，中心c=Qδ(M)，写r=M−c。反馈码不变的位移区间是
\[
M+AK_ha\in I_j.
\]
两边界距离为δ−r和δ+r。向较远的边界方向移动，点态最大可行幅值上确界为
\[
\boxed{a_{sup}(h,u)=\min\left\{b,\frac{\delta+|M-Q_\delta(M)|}{|AK_h|}\right\}.}
\tag{12}
\]
若到达量化边界时的并列码字归属使端点可行则最大值取得，否则只是上确界；取(1−ε)倍始终在内部。r=0时方向可任取；r≠0时选远离最近边界的一侧。A<0时把预测位移方向换算为载荷a的符号即可。

该规则依赖M，M可由本拍发送前历史、真实已发测量、固定模型及当前接收预测重建；在发送事件形成后选择a，没有使用未来量测或触发随机数。严格量化边界需采用已知的tie-breaking规则。

## 2. 受限点态可行类的精确期望损伤

在固定k无早期攻击的下界构造子类中，给定 \(\mathcal G_k^-\)、真实当前y和发送事件，健康条件估计误差均值为0。任意以这些信息选择的攻击a满足
\[
E[(x_k-m_{k,healthy}^+-K_ha)^2-(x_k-m_{k,healthy}^+)^2\mid\mathcal G_k^-,y_k,\gamma_k=1]=K_h^2a^2.
\tag{13}
\]
因此在**仅允许用目标时刻一次攻击，并要求每条路径下一量化码字不变**的受限类中，逐点最大化得到
\[
J^{cell,sup}_{k,\delta}
=E\left[\mathbf1_{\{\gamma_k=1\}}K_h^2
\min\left\{b,\frac{\delta+|M-Q_\delta(M)|}{|AK_h|}\right\}^2\right],
\tag{14}
\]
端点不可达时为上确界。攻击符号依赖y不会破坏式(13)，因为条件于真实当前y后的健康后验残差均值为零；不需要再用独立随机符号消交叉项。

式(14)可以精确计算此**受限攻击子类**，但没有优化所有事件分布同律策略：攻击可改变码字再通过多个历史分支在分布层面抵消，也可使用早期攻击和随机混合。故(14)不是 \(V_m\) 的已知精确值。首拍特殊情形若量化相位/预测分布可积，是否能闭式求期望另属计算问题，不影响上述点态可行域结论。

## 3. 潜在反例和边界检查

| 检查 | 结果 |
|---|---|
| 量化误差相位随连续历史变化 | 不破坏(6)：Gaussian乘积的导数对中心e一致有界；e并不需独立或均匀 |
| 目标前历史可能被攻击 | 上界允许任意前史；下界选无攻前缀子类。不能将某个条件前缀概率当无条件常数，必须对所有健康历史统一并已按(6)证明 |
| P是否连续取值 | 在固定k下P只由有限事件字递推，因此有限；c和m连续历史不改变P集合 |
| 事件是否用当前连续攻击载荷 | gamma_k先产生、攻击后改已发载荷；本构造不影响gamma_k。gamma_{k+1}因反馈码相同而路径相同 |
| 系统反馈闭环 | 原稿物理状态不受估计输出影响；若有控制反馈，x/y耦合须重证 |
| 完整接收日志 | 连续载荷包含接收值，通常立刻区分本构造；全同律结论仅针对明确的事件/量化反馈审计记录 |
| 有限k推广 | 常数可依k；没有时间一致的统一k界 |
| 三预算TV+幅值+量化地板 | 未审成定理，保持OPEN |

已检查的方程中未发现一般固定k下界构造反例。若允许的“扩充历史”不含攻击者实际可见的当前已发y或无法重建M，则指定策略权限需相应缩小；本结果按冻结G域成立。
