# 阶段 3：联合检测模型与实施合同

基准 8c02c07b；2026-11-21。用户要求联合读取可信事件、实际收到的连续载荷、已知相位或反馈中心，在原量化远程估计场景研究持续同方向攻击检测。本轮只检测，不实施恢复，不改正式论文。

## 联合观测和合法输入

攻击者仍只能在真实发送后修改当前载荷，不能改变可信事件或预知下一相位。发送/静默由实际monitor反馈中心产生；所有检测器比较共用这条运行轨道。接收端可计算当前反馈中心相对自身预测的偏移r，以及真实发送时收到的载荷创新u。静默时不存在可访问载荷，不把未发送量测送给检测器。

本轮接收端日志权限已明确为不单独记录原始随机相位phi，但会记录量化中心或码字。冻结模拟核心向检测器提供的是中心残差 \(r=c-m^-\)，因此现有性能结果属于“精确中心可见”接口；不要求单独读取phi字段。若硬件实际只保留整数码字索引而不保留中心数值，则属于更弱的投影接口，须用[相位可见性补充](11_phase_visibility_addendum.md)中的索引区间核重算，现有数值性能不能直接归属该接口。

当前已公开相位的条件分布在健康与候选模型下相同，其自身似然比为1；相位通过已知中心r进入当前事件与载荷条件核。这里不能再使用阶段2的相位平均Bernoulli概率，随后又把同一拍连续载荷当独立样本乘一次。

## 候选状态与未知起点

每个固定幅值候选从时刻0按公开事件和增益更新自己的偏差假设。候选强度为0.05、0.10、0.25，全部预先固定。候选状态不读取真实攻击开始时刻、实际幅值、状态、误差或未发送量测。

每一拍候选核都正规化，故其相对健康核的倍率在健康下条件均值为1。不同起点混合共用当拍倍率，能精确用O(J)状态更新，不需要截断起点质量。但这不是每个未知起点下精确物理攻击模型的贝叶斯混合；它是使用已有候选状态的可预测检验。对匹配幅值，候选偏差与真实攻击偏差的差在起点后几何衰减，并有可证明的累计条件KL失配上界。

所有方法从时刻0启动，起点混合权重为1/[n(n+1)]，未启动尾质量保持为1/(n+1)。联合检验的n对应当前动作时刻t=n−1。旧事件型E0在事件t审计动作t−1，保留原索引，不互相混淆。

## 同轨道对照

| 名称 | 信息和规则 |
|---|---|
| E0 | 阶段2相位平均事件混合，作为既有基线 |
| E1 | 当前已知相位下的条件事件混合 |
| R0 | 发送创新指数倾斜，按真实选择机制精确校正MGF |
| R1 | 在R0基础上，用候选持续偏差校正预测的创新均值方向 |
| P1 | 仅对发送条件下载荷密度取比，静默不下注 |
| J1 | 事件与载荷完整联合核、起点和强度混合 |
| J0 | 同一联合核，仅强度混合，从监测起点累积 |
| Oracle | 已知真实起点、幅值及其候选递推的完整联合LR，仅离线参考 |

P1和J1使用同一批已发送载荷，P1仍需可信事件历史来确定条件分布和候选状态；“载荷条件信息”并非把事件位从系统信息中删除。R0/R1是有严格选择校正的创新基线，不把一般离散时Kalman高斯创新公式生搬到选择性发送数据上。

所有部署方法分别使用1%全时域误报预算；不能把多方法报警并集当作仍有1%保证。比较是相同误报上限，并非一定相同的实测误报率。

## 实验计划

S1/U1模型、三档攻击幅值及50/100/200/随机起点沿用阶段2。24组先各5,000条初筛，再全部进入各50,000条独立确认。四档攻击后观察窗128/512/1024/2048共用episode，但不当成独立样本。

另用候选网格外幅值0.075、0.15和起点137作四组各20,000条独立压力测试，不据此调参。两模型另做各5,000条初筛和50,000条独立8192拍健康试验。模型、阈值、候选、起点权重和随机种子均在性能样本生成前冻结。

主工程门为S1和U1各自b=0.25、起点200、512拍：J1条件检出概率95%下界至少80%，受限平均延迟不超过256拍。与R1/P1的比较完整报告配对差，不预设J1一定更好；即使J1通过主门，也不能据此宣称联合设计优于所有已有方法。

本轮使用误差坐标保持U1长时域数值精度。零密度点不添加epsilon伪造正规化；若出现真正无法判定的浮点0/0，明确报告数值失败。联合对数倍率无界，不能沿用阶段2有界Bernoulli增量的Hoeffding延迟界。

## 指标与贡献边界

总MSE由实际monitor决定，所有方法逐路径相同。报警前MSE只是暴露长度；本轮没有实际恢复收益。事件t0在攻击提交前产生，E0/E1若在该事件报警仍计攻击前误报；当前载荷型方法可在t0获得首个受攻载荷。延迟按观察拍数计数，首次受攻载荷及时报警对应1拍，并保留未检出的右删失。

信息增益来自更丰富的合法记录与发送选择结构，不应全部归功于量化或随机相位。当前联合核对固定可信中心同样成立；阶段2事件型O(b⁴)限制不覆盖当前已知相位或载荷记录。标准混合检验、选择性观测模型和创新倾斜不单独声称新颖；新增价值需由本场景的精确模型、信息分析和工程效果共同支撑。
