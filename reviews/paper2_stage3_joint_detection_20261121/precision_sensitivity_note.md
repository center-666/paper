# 冻结实现的确定性精度与输入敏感性检查

本检查在冻结核心之后追加，只读调用核心公式，未改变协议、阈值、候选、种子或性能样本。复算代码为 [check_precision_sensitivity.py](check_precision_sensitivity.py)，结果为 [precision_sensitivity_checks.json](precision_sensitivity_checks.json)。

## 算术精度

在 S1/U1、三档候选幅值、三个中心残差上，检查距健康/候选发送密度零点 \(10^{-12},10^{-10},10^{-8}\) 的正负两侧，共 216 个确定性输入。参考值采用 80 位 Decimal，并将传入的 binary64 浮点输入视为精确数；因此比较的是公式计算误差，不混入输入本身的舍入误差。

五个对数因子的最大绝对计算误差为 \(1.42\times10^{-14}\)。这支持当前 expm1/log 实现在这些近零点上的算术稳定性，不构成所有输入的区间算术认证。结果文件记录本机 float64 与 longdouble 的实际机器精度；若二者相同，不把 longdouble 当作独立高精度验证。

## 输入和模型敏感性

同一近零点输入只增加一个浮点 ULP，对数因子最大变化约 \(1.11\times10^{-4}\)。把反馈中心残差人为增加 \(10^{-6}\)，最大变化约 27.63。后者是**不同条件模型**的确定性敏感性探针，不是计算错误，也不是发生频率或检测性能估计。

原因是发送密度在规定位置有二次零点，故对数密度局部导数可无界。精确核可归一化、Fisher 信息有限，并不意味着对任意中心失配或数字化载荷具有统一稳定性。模型失配、饱和与实际载荷舍入仍未被当前健康鞅保证覆盖。

若部署载荷采用有限字长，正确似然应使用每个量化区间上的概率积分；不能把连续密度直接代入舍入后的数据、随意夹密度下界后继续沿用原证明。这里没有修改通信协议，也没有启动有限字长或失配性能试验。

## 旧事件通道的相位 CDF 精度

原有 S1/U1 量化步长下，核心 CDF 差与直接相位积分的概率最大绝对差为 \(5.33\times10^{-15}\)。另取不在实验协议中的更小步长进行纯确定性数值压力检查；当半步长缩至 \(10^{-8}\)，CDF 相减误差可达 \(8.50\times10^{-9}\)。

这些较小步长不是新增实验档位，也未用于调参。当前冻结步长没有该精度问题；将来若极大缩小步长，应重新选择稳定的积分/级数表达式并重新验证。

## 对最终统计报告的限制

匹配联合对数似然及其事件/条件载荷分量的跨 episode 平均，可作为相应总体 KL 贡献的 Monte Carlo 估计；对数增量无界，不能沿用上一阶段有界累计条件 KL 的经验 Bernstein 上界。有限标准误仅是样本不确定性描述，不是有限样本全局认证。

当前最终分析已保留这一限制。报警前 MSE 是停止前暴露指标；检测不改变 monitor 时，不存在由此已实现的恢复降损。
